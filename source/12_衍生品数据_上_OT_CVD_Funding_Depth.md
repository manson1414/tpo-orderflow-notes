# 衍生品数据要点（上）：OI / CVD / Funding / Orderbook Depth

**目标**：掌握四个核心"流动指标"，理解加密市场价格的底层驱动力。

> **核心观点**：理解价格是如何被推动的，不只是看 K 线这么简单。
> 要做出更有把握的决策，你需要理解"**推动价格的底层资金流（flow）**"，而不仅仅是结果（K 线长什么样）。
> **好消息**：在加密市场里，这些数据基本都是免费的，因此传统金融（TradFi）里那种**信息不对称问题并不突出**。

---

## 一、加密衍生品基础

### 1.1 什么是衍生品？

**衍生品是这样的合约：它跟踪某个资产的价格，但你并不真正持有这个资产本身。**

**市场中大多数交易发生在永续合约（perpetual futures）上。** 它看起来像常规期货合约，但**没有到期日**。

永续合约通过一套机制让价格与现货保持一致，主要包含：

- 合约的**计价货币（quote currency）**
- **标记价格（mark price）**
- 通过**资金费率（funding）**强制执行的定价机制

### 1.2 计价资产 vs 保证金资产

每个衍生品合约都有两面：

1. **被交易的资产**：也就是标的，例如比特币（BTC）
2. **作为保证金的资产**：也就是你用来开仓抵押的东西

**多数交易所使用 USDT 或 USDC 作为保证金**，因为这样保证金价值更稳定。有些平台提供"**币本位合约**（coin-margined）"，用标的本身作为保证金。

**所以，BTCUSDT 永续合约意味着**：

- 你交易的是 BTC 的价格波动
- 盈亏（PnL）用 USDT 结算
- 保证金也以 USDT 持有

> **这很重要，因为合约的价格并不是只跟随现货价格本身，而是跟随交易所采用的那套定价机制。**

### 1.3 标记价格（Mark Price）与预言机（Oracles）

**为了防止操纵，交易所不会用自己的"现货价格"来计算清算（liquidations），而是用标记价格（mark price）**，它包含：

- **外部预言机价格**（通常是多个大交易所现货价格的加权混合）
- 合约的**资金费率与溢价（premium）**
- **平滑机制**（防止单个跳动或操纵造成的剧烈波动）

> ⚠️ **因此，你被触发清算时参考的是 mark price，而不是你看到的"图表价"。**
> 这让跨交易所的清算机制更一致。

### 1.4 两种主要合约类型

| 类型 | 保证金/结算 | 特点 |
|---|---|---|
| **线性合约（Linear）** | 用**稳定币**作为保证金与结算货币 | PnL 相对更稳定、更直观；**如今成交量占主导** |
| **反向合约（Inverse）** | 用**标的币**作为保证金 | PnL 会随币价变化；**保证金要求波动更大** |

### 1.5 衍生品会带来什么影响？

**如今市场大部分成交量都在衍生品上**，这意味着衍生品的"机制"越来越重要。**价格会更敏感地响应**：

- **杠杆进入/离开**（Open Interest）
- **激进的市价单**（CVD）
- **拥挤的持仓**（Funding）
- **流动性厚薄**（Depth）

## 二、未平仓量（Open Interest, OI）

### 2.0 定义

**OI 衡量的是：衍生品合约当前"尚未平掉"的总量。** 它反映了市场在某一时刻**有多少杠杆正在参与**。

- **OI 上升**：新的仓位正在被开出来
- **OI 下降**：仓位在被平掉，或被强制平仓

> ⚠️ **但关键点是：OI 并不告诉你这些仓位是多还是空，因为每一个多头都必须对应一个空头。**
> **OI 真正展示的是：市场的"总敞口（exposure）"有多大。**

- **敞口越大** → 行情背后的"**潜在能量**"越多
- **敞口越小** → 市场正在**去杠杆/去风险**，整体更稳定

### 2.1 OI 会怎么变化？（只有三种情况）

| 情况 | OI | 含义 |
|---|---|---|
| 双方都**开新仓** | **上升** | 更多杠杆进入市场 |
| 双方都**平仓** | **下降** | 杠杆退出市场 |
| 一方开仓、另一方平仓 | **大致走平** | 敞口在参与者之间"**轮换**" |

> **因此，最好把 OI 与价格一起看：你关注的是 OI 相对价格变化的"关系"，而不只是 OI 的最终数值。**

### 2.2 OI 与价格的组合解读

| 价格 | OI | 含义 |
|---|---|---|
| **↑** | **↑** | 新的多头敞口进入，**趋势通常更强** |
| **↑** | **↓** | 多为"**空头回补**"，走势看起来强但**其实更脆弱** |
| **↓** | **↑** | 新的空头进入，**下跌趋势通常更强** |
| **↓** | **↓** | **多头平仓或被清算**；强制卖出/恐慌性出逃 |

> **这些模式在加密市场尤其适用，因为杠杆高、反应快。**

### 2.3 OI Delta（未平仓量变化率）

**OI Delta 展示的是 OI"每根 K 线之间的变化速度"，而不仅是绝对值。**

- **OI Delta 上升**：杠杆在**快速流入**
- **OI Delta 下降**：杠杆在**快速出清/去杠杆**

**它有助于识别**：

- 追涨杀跌的**冲动入场**（Impulse entries）
- **反转前的突然减仓**
- **大规模清算事件**
- **缓慢但持续的建仓**（往往是突破前奏）

### 2.4 为什么 OI 重要？

> **在加密市场里，OI 是最干净的领先指标之一**，因为衍生品成交量占主导，而大行情通常伴随：
>
> - **OI 大幅上升**（新杠杆推动价格）
> - 或 **OI 大幅下降**（清算或大规模平仓）

| OI 环境 | 特征 |
|---|---|
| **低 OI** | 通常更容易**震荡、来回割** |
| **高 OI** | 要么**趋势更明显**，要么会出现剧烈的"**机械式出清**"（squeezes / 强制去杠杆） |

### 2.5 一个关键区分：OI 是「存量」，成交量是「流量」

**这个区分经常把人绊倒，但它决定了你什么时候该用哪个。**

| | 成交量（Volume） | 未平仓量（OI） |
|---|---|---|
| **性质** | **流量（flow）** | **存量（stock）** |
| **数什么** | 一个周期内**成交**了多少 | 某一时刻**存续**着多少合约 |
| **时间行为** | 下一周期开始时**归零重算** | 从上一周期**带过来，累积** |
| **什么时候变** | 一直在变 | **只在仓位被创造或消灭时才变** |

**所以存在两种看起来矛盾、其实完全合理的市场：**

- **成交量巨大，OI 却纹丝不动** → 同一批合约在参与者之间**来回倒手**，**敞口零增长**
- **成交量平平，OI 却稳步抬升** → **交易不多，但风险在悄悄堆积**

**这两种是完全不同的市场。** 只看成交量，你分不出它们。

### 2.6 OI 的四个坑（读之前必须知道）

| 坑 | 说明 |
|---|---|
| **它没有方向** | **OI 数的是合约，不是方向。** 上升只告诉你「仓位被开了」，**不告诉你是多头还是空头开的**。方向是靠和价格对照推出来的 —— **而那是推论，不是事实** |
| **它是分交易所的** | **每家交易所只报自己的合约。** 一个交易所的 OI 在跌，另一个可能在涨（仓位在两地之间搬家）。**跨交易所聚合才能得到总敞口的可靠画面** |
| **各单位不同** | 有的以**合约**计，有的以**标的币**计，有的以 **USD** 计。**以币计的数字会因为价格波动而变，哪怕一个仓位都没动** —— **只能同类比同类** |
| **它不区分意图** | **一个对冲现货风险的套保者，和一个做方向性投机的交易者，在 OI 上的贡献完全一样** |

### 2.7 OI 最好的用法：给突破定性

**OI 很少单独产生一笔交易，但它会改变一波行情该被赋予多少权重。**

| 情形 | 解读 |
|---|---|
| **价格突破一个价位 + OI 上升** | 买的人是**在承担新风险** —— **突破更可能延续** |
| **价格突破同一个价位 + OI 下降** | 买的人是**在退出旧风险** —— **突破更可能是假动作** |

**另一个高价值用法是看杠杆堆积**：
**OI 长时间爬升、价格却横在区间里，就是敞口在累积** ——
**而这是「区间最终破掉时会产生瀑布」的前置条件。**

## 三、资金费率（Funding Rates）

### 3.0 定义

**资金费率是永续合约多空双方之间的周期性支付，用来让永续价格贴近现货。**

- **永续高于现货**：**多头付费给空头**
- **永续低于现货**：**空头付费给多头**

> ⚠️ **资金费率本身不会"推动"市场。真正重要的是：谁在付、付多少、能付多久。**

### 3.1 为什么需要资金费率？

**先看普通期货是怎么锚的：普通期货有到期日，到期必须对现货结算。**
**这个「必然收敛」就是它的锚 —— 价差一旦拉开，套利者敢去做，因为他知道它一定会闭合。**

**永续没有到期日，所以它没有这个锚 —— 放任不管，它可以无限期地相对现货升水或贴水。**

**资金费率就是为「替代那个缺失的收敛」而被发明出来的机制**：通过**经济压力**让合约回到均衡。

- **永续高于现货** → 多头付费给空头 → 激励多头减仓
- **永续低于现货** → 空头付费给多头 → 激励空头减仓

**大多数交易所每 8 小时结算一次**，足以把合约锚在现货附近。

> **钱在多空之间走，不交给交易所** —— 这一点很重要：**资金费率是一种「持有成本」，不是「手续费」。**

### 3.2 正/负资金费率意味着什么？

**正费率（Positive Funding）**：

- 多头付费给空头
- 永续高于现货
- 市场**偏多/多头拥挤**
- **买盘更主动**

**负费率（Negative Funding）**：

- 空头付费给多头
- 永续低于现货
- 市场**偏空/空头拥挤**
- **卖盘更主动**

> ⚠️ **注意：资金费率并不意味着多头或空头"人数更多"。每个多必有空。**
> **资金费率衡量的是"主动性与失衡"，而不是方向。**

### 3.3 把资金费率放进价格语境里

| 价格 | Funding | 含义 |
|---|---|---|
| **↑** | **↑** | 多头在主导，**通常趋势延续**；除非拥挤度极端 |
| **↑** | **↓** | 多为"**空头回补**"，走势往往**偏弱** |
| **↓** | **↓** | **空头在主导** |
| **↓** | **↑** | **多头被套**，常出现被迫出清/**清算针** |

### 3.4 极端资金费率

> **高/低资金费率并不会自动导致反转。** 真正重要的是：
>
> - **极端持续多久**
> - **OI 在上升还是在下降**
> - **现货是否支持或否定永续流**

- **资金费率极端，但 OI 走平或下降** → 往往**意义不大**
- **资金费率极端且 OI 上升** → 说明市场在**极度单边地"装载仓位"**，会形成**不对称风险**

### 3.5 资金费率的"预测性"用法

> **资金费率本身不指向方向，它提供的是"持仓压力"的信息。** 它更适合用来识别：
>
> - 多头/空头**拥挤，可能被挤压**
> - **流动性很薄时，单边持仓更不稳定**
> - **永续流与现货流脱节的阶段**

### 3.6 现货 vs 永续语境

**资金费率只适用于永续。现货交易者不付也不收。**

> **如果现货趋势很强，而永续一侧出现极端资金费率的反向信号，永续那一侧通常会输。**

- **例**：现货持续买入，同时资金费率为负（空头拥挤）→ **空头人群被套**
- **反之**：现货持续卖出，同时资金费率为正（多头拥挤）→ **多头人群被套**

### 3.7 穿过零轴（Zero Flip）值得单独记一笔

**费率从正翻负，意味着升水消失了** ——
**原来是多头在付钱，现在轮到空头付钱。**

**「谁在拥挤」发生这种切换时，往往是一次真正的控制权易手，而不只是中途歇一口气。**

| 现象 | 解读 |
|---|---|
| **费率在零轴附近反复摆动** | 市场**没有明确拥挤的一边** —— 通常是区间/平衡环境 |
| **费率干脆地穿过零轴并站稳** | **控制权换手** —— 值得重新评估方向 |

### 3.8 比较费率时的三个注意

**这一条很容易被忽略，但搞错了就会得出完全相反的结论。**

| 注意 | 说明 |
|---|---|
| **它是「利率」，不是「扳机」** | **极端费率可以持续数周。** 它只描述当下状态，**给不出「什么时候解开」的时间点** |
| **它是分交易所的** | **每家交易所在自己的合约上设自己的费率**，有自己的周期、公式和上下限。**跨交易所的费率不能直接比较** |
| **周期不同，数字不可比** | **「每 8 小时报一次」和「每小时报一次」不是同一个数字。** 同类比同类，**并且在判断成本前先年化** |

## 四、订单簿深度（Orderbook Depth）

### 4.0 定义

**订单簿深度展示的是：簿子两侧（bid 与 ask）有多少"静态挂单"在等待成交。**

> **不同于 CVD（主动性），深度展示的是"被动流动性"**——也就是有多少挂单愿意在附近价格接单。
> **你可以把它理解为：价格在当前环境里到底"稳不稳"。**

- **簿子厚（thick book）** → 价格移动会**更慢**
- **簿子薄（thin book）** → 价格移动会**更快**

**范围**：订单簿深度通常显示到距离现价 **+/-10%** 的范围，意味着你能看到这一区间内所有可见挂单的堆叠情况。

### 4.1 深度到底告诉你什么？

> **深度讲的是"流动性"，不是"方向"。**

它回答的问题包括：

- **推动价格到底有多容易？**
- **大额挂单都在哪些价位？**
- **新闻/事件前流动性是否在枯竭？**
- **哪一侧的挂单更厚？**
- **哪些区域可能让价格减速/加速？**

> 当交易者讨论"稳定性"或"薄簿子"时，本质上说的就是深度环境。

### 4.2 两种主要显示模式

#### 1) Bid & Ask
展示簿子两侧的**绝对流动性**：

- **Bid 侧**：价格下方等待买入的挂单
- **Ask 侧**：价格上方等待卖出的挂单

**适合用来识别**：

- **大墙（walls）**
- **流动性集中在哪里**
- **两侧是否明显失衡**
- **哪些区域会让价格减速或加速**

> 这是最直接、最简单的视图。

[[img:ob-depth-hero]]

**买卖两侧的挂单分布一眼可见**：哪个价位厚、哪一侧整体更厚，都在这一张图里。

#### 2) Delta（深度差）
**展示的是：每个价位 bid 流动性与 ask 流动性的差值。**

- **Delta > 0**：bid 更厚
- **Delta < 0**：ask 更厚

**更适合快速看**：

- **压力区（pressure zones）**
- **流动性倾斜（liquidity skews）**
- **哪一侧在某个深度百分比上明显占优**
- **簿子更像"支撑"还是"阻力"**

> 它把大量信息压缩成单一渐变，让你一眼更容易看出流动性偏向。

[[img:ob-depth-heat]]

**颜色深浅 = 该价位的挂单密度。** 亮带就是流动性集中的地方。

### 4.3 如何读深度环境？（四种状态）

| 状态 | 特征 | 影响 |
|---|---|---|
| **厚簿子（Thick Book）** | 两侧流动性都高 | 推动价格需要真主动性；**波动会被压缩** |
| **薄簿子（Thin Book）** | 两侧流动性都轻 | **更小的市价单也能推动更大的价格位移**；波动更容易扩张，尤其在新闻/高波动催化剂附近 |
| **Bid 更厚（Bid-Heavy）** | 价格下方挂单多于上方 | 下跌时更像"**缓冲垫**"；有助于识别**吸收或吸筹区域** |
| **Ask 更厚（Ask-Heavy）** | 价格上方挂单更多 | 上涨时更像"**摩擦力**"；常与**派发/抛压**一致 |

### 4.4 墙与流动性簇（Walls and Liquidity Clusters）

**大额挂单会形成"墙（walls）"。它们可能表现为**：

- **磁铁（magnets）**：价格会慢慢漂向它
- **屏障（barriers）**：价格靠近时会停滞
- **假流动性（fake liquidity）**：诱骗单（spoofs），价格靠近就撤

> ⚠️ **你永远不要在价格还没靠近时就"假设"某个墙是真的。**
> **在加密市场里诱骗（spoofing）非常常见**：有人挂出巨量订单，等价格接近就撤掉，用来误导市场参与者对真实供需的判断。

### 4.5 「距离」这个参数为什么重要

**深度图总是显示「距离现价一定百分比」范围内的挂单**（常见是 ±10%）。

**这个参数不是随便设的，它直接决定你看到的是哪种市场：**

| 距离设得 | 你看到的 | 风险 |
|---|---|---|
| **太近**（如 ±2%） | 只有眼皮底下的挂单 | **看不到真正的墙在哪**，容易把噪音当结构 |
| **太远**（如 ±25%） | 把远处的挂单也拉进来 | **尺度失真**，看起来处处是墙，失去区分度 |
| **合适**（通常 ±5%~±10%） | **当前价格真正会碰到的流动性** | —— |

> **一条实操建议**：**跟着你的止损距离设**。止损放在 1%，深度就该覆盖到 2–3%，
> **这样才能看出「价格走到止损位时会撞上什么」。**

### 4.6 深度失衡和热力图有什么不同

**两者都画挂单，但回答的问题不同：**

| | 订单簿深度（Depth） | 热力图（Heatmap） |
|---|---|---|
| **看的是** | **此刻**两侧挂单的**分布与比例** | 挂单**随时间**的分布（历史切片） |
| **时间维度** | **一个瞬间** | **一段历史** |
| **最擅长** | **「现在哪一侧更厚」** | **「墙是怎么出现又怎么消失的」** |
| **看不到** | 挂单的演变过程 | 此刻的实时队列 |

**所以：判断「现在」用深度，判断「墙是不是真的」用热力图。**
**两者结合才能同时回答「哪里厚」和「厚得可不可信」。**

### 4.7 深度如何与其他指标配合？

| 组合 | 能看出什么 |
|---|---|
| **Depth + CVD** | 主动订单是在**被吸收**，还是在**切穿流动性** |
| **Depth + OI** | 在 OI 上升时，如果簿子很薄，容易形成"**机械式出清**"的条件：挤压与大规模清算 |
| **Depth + Funding** | 如果某一侧在**薄簿子里支付高资金费率**，走势可能会**很快反向出清** |

---

## 五、结语

> 以上就是要点。所有这些指标都会让你更深入地理解市场的**持仓与脆弱性**——但它仍然**不是全部**。还有很多其他因素也很重要，比如**清算、基差（basis）、成交量**等。
>
> **它们都不是"信号"。即使组合起来，它们也只是提供语境（context）。**
>
> **把洞察转化为优势（edge）的唯一方式，是构建一个结构清晰、并且经过回测的系统，这样你才知道自己决策背后的期望值（expected value）。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **OI（未平仓量）** | 未平掉的合约总量，反映总杠杆敞口 |
| **OI Delta** | OI 的变化量，配合价格判断新增还是平仓 |
| **资金费率（Funding Rate）** | 永续多空之间的周期性支付，衡量持仓压力 |
| **Orderbook Depth（订单簿深度）** | 距现价一定范围内所有可见挂单的堆叠情况 |
| **Taker CVD / Maker CVD** | 按主动方 / 被动方拆分的累计成交量差 |
| **Spot / Perp / Aggregated CVD** | 现货 / 永续 / 聚合口径的 CVD，用途不同 |
| **深度距离（Depth Range）** | 深度图显示的「距现价 ±N%」范围，决定看到的尺度 |
| **流动性倾斜（Liquidity Skew）** | 一侧挂单明显厚于另一侧 |
| **清算簇（Liquidation Cluster）** | 相似杠杆 / 止损位置扎堆形成的爆仓带 |
| **z-score** | 衡量本次清算相对近期有多极端的标准分 |
| **多空比（Long/Short Ratio）** | 按账户数统计的多空比，弱信号 |

## 自测

> 覆盖原「学习路径」用衍生品判断脆弱性。
> **答案默认折叠** —— 先自己想，再点开对答案。

**U11.1 未平仓量（OI）**

- ⚠️ **常见错误**：以为 OI 能告诉你多空方向。**每个多头必然对应一个空头**，OI 只反映总敞口。
- **自测**：价格上涨但 OI 下降，这个上涨健康吗？
- **答案**：不健康。这是空头回补推动的，一旦回补结束，上涨就失去动力。

**U11.2 资金费率（Funding）**

- ⚠️ **常见错误**：以为极端费率会自动导致反转。**高 / 低费率本身不会导致反转** —— 要看极端持续多久、OI 在升还是降。
- **自测**：现货持续买入，同时资金费率为负，哪一边会被套？
- **答案**：空头。「现货趋势很强，而永续一侧出现极端资金费率的反向信号，永续那一侧通常会输。」

**U11.3 清算（Liquidations）**

- ⚠️ **常见错误**：追清算瀑布的第一根。正确做法是**降低仓位，或只做确认后的回踩 / 反转**。
- **自测**：清算瀑布需要哪五个条件同时具备？
- **答案**：深度低 + 点差扩大 + 高杠杆 + OI 上升 + 参与度低。
- **延伸阅读**：`13_衍生品数据_下_清算_Delta_多空比_Taker.md`

**U11.4 多空比与 Taker Flow**

- ⚠️ **常见错误**：单独用多空比做方向判断。它只是「温和的反向指标」。
- **自测**：多空比极高，但 OI 走平。这个信号强吗？
- **答案**：弱。说明只是很多小散户在做多，**规模不大**。需要 OI 快速上升配合，才说明真有杠杆扎堆。
- **延伸阅读**：`13_衍生品数据_下_清算_Delta_多空比_Taker.md`
