## 三、核心原则（贯穿全部内容的 7 条）

1. **系统给的是优势，不是结果。** 任何交易系统只能在**概率和 EV** 上给你优势，不能保证单笔赢。**交易本质是付费试错**，亏损是成本不是失败。（见 `17`）
2. **市场是拍卖场，不是赌场。** 价格不是被谁「定」出来的，是被一次次竞价「拍」出来的。所有判读都从这个前提出发。
3. **语境优先于形态。** 任何形态（P 形、弱高点、单印）脱离语境都会把你带进陷阱。先定市场结构 → 再定关键水平 → 再看形态。
4. **时间确认不可省。** Market Profile 的全部优势在于把「时间」显性化。没有时间确认（至少 1 个完整时段站稳），等于在猜。**一个单印不算确认。**
5. **所有数据提供的是语境，不是信号。** OI、CVD、Funding、Depth、清算 —— 没有一个能单独作为开仓依据，必须共振 + 回测验证期望值。
6. **节奏（Tempo）= 信念。** 价格在已知水平附近降速、在未知区域加速。节奏加速配合方向 = 确认；节奏衰竭 = 止盈信号。
7. **不交易也是决策。** 市场横盘、看不懂、或出现没写进情景的走势 → 不交易。

## 四、关键数字（供建立预期用）

| 数字 | 含义 |
|---|---|
| 70% / 15% / 15% | VA / VAH / VAL 的标准切分 |
| 68% | 落在均值 ±1 个标准差内的数据比例 |
| 90%+ | 每日交易中由算法机器人与散户完成的比例（其中算法可能 >70%） |
| 80% | 开盘在 pdVA 外、被接受回 VA 内后，走到 VA 另一侧的概率 |
| 0.36% | 2019 年以来市场趋势反转的概率（2513 天里 9 天） |
| >75% | 伦敦时段在统计上跟随亚洲时段的概率 |
| 5–6 天 | 失败的拍卖点通常被回访的窗口 |
| 10:1 | 足迹图默认的不平衡（imbalance）判定比例 |
| ±10% | 订单簿深度显示范围 |
| 8 小时 | 主流交易所资金费率结算周期 |
| 30 分钟 | 判定拍卖确认的最短"站住"时间（1 个时段） |
| **1 / (1 + 盈亏比)** | **盈亏平衡胜率**：R:R = 1 时 50%，2 时 33.3%，3 时 25% |
| **−50% → +100%** | **亏掉一半后，需要翻倍才回本** |
| **7.8%** | 胜率 40% 时，**连续 5 笔亏损**的出现概率 |

> ⚠️ 上表数字是**经验值 / 历史统计值，不是本知识库的实测结论**。使用前应按自己的标的与周期重新验证。
