# 03 · 市场参与者、流动性构成，与"普通人为什么会亏"

**目标**：理解流动性的来源，以及为什么"大多数人的止损位置"本身就是可利用的信息。

---

## 一、没有人在"盯着你"

**常见误解**：很多交易者相信存在"止损猎杀（stop loss hunt）"，相信做市商开着热成像追踪模式，铁了心要把单子挂在你那 150 美金仓位的止损下方。

**真相**：
- 多数人**高估了自己的重要性**
- 不是你不重要，而是说：**在市场这个大尺度里，你的相关性非常小**
- **你是浮游生物（plankton）**。你可能"意外"成为鲸鱼的食物，但鲸鱼就算想找你也看不见你——**你只是挡在它们路上**

**结论**：不要坐在"铲勺"的运行轨迹上。要学的是**如何闪开**，最好还能顺便和大型鲸类一起游。

> 这条不是安慰，是操作前提：**你无法对抗流动性，只能读它、避开它、或顺着它。**

---

## 二、流动性构成（Liquidity Composition）

**每天超过 90% 的交易由算法机器人与散户完成**（其中算法可能 **>70%**）。

| 参与者 | 特征 |
|---|---|
| **算法机器人** | 主要由机构管理，生成成千上万笔高频交易：几跳以内开仓、几跳以内平仓，为市场提供流动性。**它们设定每日的 IB，并制造我们赖以呼吸的空气：流动性。** |
| **日内交易者** | 市场参与者里的主要成分 |
| **波段交易者（swing traders）** | 持仓周期通常从几天到几周 |
| **鲸鱼 / 做市商** | 更高时间框架、更大体量的动作：大额买单或卖单。**这种大额订单并不常见，通常对应罕见的高时间框架事件。** |

**关键推论**：
- 当做市商**一次性撮合/记账大额订单**时，**一定是有原因的**
- 热力图可以展示大额订单（如 50–115 手 BTC）的集中区域（颜色由冷到暖）
- **把关键订单的集中区以及其绝对位置画出来**——这是可操作的动作

> 一根长下影线，往往就是一次彻底的爆仓清算。

## 三、你行为里的谬误（The Fallacy in Your Behaviour）

**大概率：大多数人的止损都设在那些"高流动性区域"。**

推理链条：
1. 我们的猴子脑会识别模式
2. 如果你既不是完全的蠢货，也不是绝对的天才，**那么你大概率会和多数人一样移动**
3. **你。很。可。预。测。**
4. 你画着同样的支撑线：线下方一点点就是"失效"，再下面一点就是你的止损
5. 蜡烛刚好向下扎一下，把你止损打掉，然后价格反转，把你甩在原地——你直接少了 1.5%（还不算杠杆）

**这叫做"千刀万剐式的死亡（Death by a thousand cuts）"。**

**怎么破？**
> **你不需要理解高智商是怎么思考的；你只要把你剩下不多的脑细胞当成镜像神经元，去模仿那些巨脑在做什么就行。**

即：**不要试图变聪明，要试图模仿真正的大资金。**

## 四、尾巴（Tails）——用批发商类比理解

**类比故事**：

一个批发商用 **$1/瓶** 进了 10,000 瓶汽水。
- 想以 $2 卖掉 → 没人买
- 降到 $1.5 → 还是卖不动
- 到 $1.2 时有人买了几瓶，但生意依然很慢
- 临近保质期，店主害怕亏损 → 降到 **$0.90**
- 这时一家大型连锁零售商的老板走进来，**买走了剩余库存中的大部分**——他会尝试以 **$1 卖出**（恰好是上一次大成交发生的价格，也就是**人们认为的公平价格**）
- 小店老板把价格提回 $1，剩下的库存很快被小买家扫光

**映射到市场**：
1. 纽约时段在 **IB 高点出现快速拒绝（卖出尾）**，打击买方信心，价格开始往 106,000 低位走
2. 然后**大买家在那个区间强势介入，开始激进地吸收卖单**，速度快到直接形成一个**买入尾**
3. **（为了更有意义，至少要有 2 个单印）**
4. 第二次回测前一时段低点时，**买方反应更激烈**

**核心结论**：
- **尾巴 = 大资金在极端位置表态的痕迹**
- 尾巴的意义在于"**拒绝**"——某个价格被市场拒绝
- **一个单印不算尾巴；至少 2 个单印才够看**

## 五、经典案例：普通人 vs Profile 交易者

### 普通画线选手（average line guy）的操作

- BTC 4 小时图：两条一眼就能看到的支撑/阻力线
- 脑回路：阻力几天前已经翻成支撑了，10/10 那些插针基本可以忽略
- 价格靠近支撑线时，卖方被大幅拒绝；成交量下降；一根大阳线吞没，表示卖方衰竭
- **于是普通人在 108,500 到 110,500 买入**
- **止损放在 106,800**（2:1 的盈亏比之类）
- 结果：价格直接把你按进水里，**106,500 附近开始出现暴力扫货（scooping）**

### 用 Market Profile 的人会注意到什么

在**日线 session 图**上，会看到：

1. **早在数周之前，日线 session 上就出现了两个弱低点（poor lows）**
2. **下跌趋势中的不平衡**（偏斜轮廓、分布很差）→ 提示靠近支撑时其实**很弱**
3. **VRVP（可见区间成交量轮廓）上的低成交量节点（LVN）**，就在成交量轮廓 VAL 下方
4. **如果真的存在"支撑"，它其实在更下方**
5. 还存在：
   - a) 第一个轮廓里有**单印**，表示在那些低点附近存在**激进竞价**
   - b) **每次低点被回测（又两次）都会登记出一个弱低点**——把视角缩到 session profiles，证据更充分

**结论**：**就在普通人支撑线的下方，才是放买单的完美区域。**

> 普通人的选择是在 POC 买入。但那是公平价值——我们要的是更便宜的位置，也就是 VAL 下方。

## 六、核心方法论：模拟普通人，然后推翻他

> **如果你在 Market Profile 图上识别出一些有意思的点位，试着模拟"普通人会怎么做"。**
> **你要做的，是把他那套逻辑里每一个点都推翻/失效（invalidate）。**
> **然后再据此把你的订单摆在更聪明的位置。**

**为什么有效**：
- **这里 90% 的人亏钱**
- 如果你做得不一样，同时又基于"**市场自己生成的信息**"做决策，那么你大概率是对的

**行动纲领**：
> **忘掉价格行为（price action）。看价值（value）。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **流动性（Liquidity）** | 挂单深度。价格移动需要它，薄的地方走得快 |
| **算法机器人（Algo / Bot）** | 机构管理的高频程序，提供流动性并设定每日 IB |
| **波段交易者（Swing Trader）** | 持仓周期几天到几周 |
| **鲸鱼 / 做市商（Whale / MM）** | 高时间框架的大额订单，罕见但影响大 |
| **止损猎杀（Stop Hunt）** | 大众想象中「专门打你止损」的行为；实际是止损扎堆被顺带扫掉 |
| **普通人谬误（The Fallacy）** | 多数人止损位置高度相似，因此可以被预测 |
| **千刀万剐式死亡** | 反复被扫小止损、缓慢亏光的过程 |
| **尾巴（Tail）** | 大资金在极端位置表态的痕迹，代表「拒绝」 |
