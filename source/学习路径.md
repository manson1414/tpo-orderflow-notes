## 二、顺序为什么这样排

**拍卖理论在最前面**，因为它是订单流交易的地基：
不先接受「市场是拍卖场」这个前提，后面所有的轮廓、形态、订单流数据都没有落脚点。

之后的顺序是一条**从粗到细的链**：

```
市场怎么运作（00–06 理论）
  → 数据怎么读（07–12 理论）
    → 怎么下注（实战 01–03）
      → 怎么每天执行（实战 04–07）
```

每一步都依赖前一步。跳过「语境」直接学形态，你会把 P 形在趋势里和区间里用成同一个结论；
跳过「心态」直接学策略，你会在连亏 5 笔之后推翻一套本来正确的系统。

## 三、核心原则（贯穿全部内容的 8 条）

1. **系统给的是优势，不是结果。** 任何交易系统只能在**概率和 EV** 上给你优势，不能保证单笔赢。**交易本质是付费试错**，亏损是成本不是失败。（见 实战 `17_交易心态与铁律.md`）
2. **市场是拍卖场，不是赌场。** 所有判读都从这个前提出发 —— 详见理论 `00_拍卖理论.md`。
3. **语境优先于形态。** 任何形态（P 形、弱高点、单印）脱离语境都会把你带进陷阱。先定市场结构 → 再定关键水平 → 再看形态。
4. **时间确认不可省。** 没有时间确认（至少 1 个完整时段站稳），等于在猜。**一个单印不算确认。**
5. **数据是语境，不是信号。** OI、CVD、Funding、Depth、清算、GEX —— 没有一个能单独作为开仓依据，必须共振 + 回测验证期望值。
6. **节奏（Tempo）= 信念。** 节奏加速配合方向 = 确认；节奏衰竭 = 止盈信号。节奏本身怎么读，见实战 `09_日内流程_Profile版.md`。
7. **不交易也是决策。** 什么情况算「看不清」，实战 `09_日内流程_Profile版.md` 给了判据。
8. **位置型工具都是结果，不是原因。** POC、价值区、VWAP 的漂移，是价格与成交**已经**走出来的记录，天然滞后。用它们**确认**方向，不要用它们**预测**方向。（见理论 `18_成交量轮廓.md` §八）

## 四、走完一遍之后

1. **只挑 1–2 个 setup 实盘。** 先用小仓位跑一段，把流程练成条件反射再上仓位（见实战 `15_日内流程_全工具整合.md`）。
2. **建立自己的统计。** **基于你自己的经验建立预期，而不是基于别人的经验。**
3. **记住三条铁律**：
    - 没有时间确认 = 不交易
    - 没有失效条件 = 不交易
    - 没有写进剧本的走势 = 不交易
4. **再看一篇个人总结。** 实战 `20_交易论点.md` 是**我自己的交易总结** ——
   **不一定正确**，也不是课程的一部分。它的用处是让你看到「同一套工具，
   一个人最后收敛成了哪几句话」；**你的结论应该跟它不一样。**
