## 阶段 0 · 拍卖理论：一切的地基

> **目标**：把「市场是拍卖场」这个前提装进脑子。
> **学完你能**：不再问「庄家想干什么」，而是问「这次拍卖成功了吗」。

### U0.1 市场不是赌场，是拍卖场

- **一句话**：价格不是被谁「定」出来的，是被一次次竞价「拍」出来的。
- **为什么需要**：这是整套体系的地基。如果你相信有人在操控价格，你会去找庄家；如果你相信这是拍卖，你会去读拍卖的结果。
- **怎么看**：把市场想成一场**持续进行的拍卖会**：
    - 卖方挂出他要的价（ask），买方报出他愿付的价（bid）
    - 成交价 = 双方**同时**点头的那个价
    - 价格动，是因为**有人愿意用更差的价格成交**了 —— 没有别的原因
- **常见错误**：把「价格下跌」理解成「有人在砸盘」。更准确的描述是：**在那个价位上，卖方比买方急**。
- **自测**：价格上涨，最直接的原因是什么？
- **答案**：有买方愿意在更高的价格接手。不是「利好消息」——消息只是让人愿意出更高价的**理由之一**。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §2

### U0.2 拍卖的三条底层定律

- **一句话**：价格是广告，时间是调节器，成交量是裁判。
- **为什么需要**：这三句话解释了「为什么价格会动、为什么会停、什么时候算成功」。它们是后面所有判读规则的总纲。
- **怎么看**：
    1. **价格是机会的广告机制** —— 价格变化本身就是在喊：「这里有机会，谁来？」
    2. **时间调节每一次机会** —— 同样的价格待得越久，机会越少，参与者越少
    3. **成交量衡量每次拍卖的成功程度** —— 成交量是投票器，它告诉你这次试探有没有被认可
- **常见错误**：只看价格、不看成交量。**没有成交量支撑的价格移动，是「没成交的广告」**，很快会被撤回。
- **自测**：价格快速冲高但成交量很小，这三条定律里哪一条在提示你？
- **答案**：第三条。成交量没跟上 = 这次拍卖**没有得到认可**。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §2

### U0.3 公平价值：大多数人的共识价

- **一句话**：大多数人愿意成交的那个价格，就是公平价值 —— 日内看，它就是 POC。
- **为什么需要**：有了「公平价值」，你才有「贵」和「便宜」的参照系。没有它，价格只是数字。
- **怎么看**：
    - 公平价值基于**共识**，不是基于计算
    - 它往往落在 VA（约 70% 成交）以内，更精确地说就是 **POC**
    - 大多数人**接近同一个价值**成交；少数人刻意**远离**这个价值
- **常见错误**：把公平价值当成「正确价格」。它不是正确的，它只是**大家都认的**。
- **自测**：少数人为什么要远离公平价值成交？
- **答案**：他们要的是**成交速度**，不是好价格。急着进场或急着离场的人，会接受更差的价。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §3

### U0.4 拍卖什么时候启动

- **一句话**：价格一旦偏离公平价值，一次拍卖就启动了。
- **为什么需要**：它给了你一个明确的「事件触发点」。没有这个点，你分不清「噪音波动」和「真正的拍卖」。
- **怎么看**：启动条件只有一条 —— **价格离开 POC / 价值区**。之后看两件事：
    - **成交量有反应** → 参与者在重新评估公平价值 → 可能形成新价值区
    - **成交量没反应** → 参与者不感兴趣 → 价格很快回到均值
- **常见错误**：把每一次价格离开 POC 都当成趋势起点。**绝大多数偏离会失败**，这正是旋转交易能赚钱的原因。
- **自测**：价格离开 POC 后，你第一时间该看什么？
- **答案**：成交量。它决定这次偏离是「重新定价」还是「没人理」。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §3

[[fig:aucflow]]

### U0.5 过度延伸的拍卖与均值回归

- **一句话**：冲得太快、没有成交量配合的偏离，叫「过度延伸」，通常会回来。
- **为什么需要**：这是你最常遇到、也最容易误判的形态。它是反转交易的主要来源。
- **怎么看**：
    - 价格从 POC / 价值区**突然冲出去**
    - **成交量没有同步放大**
    - 结果是参与者开始失去兴趣 —— 「太贵了 / 太便宜了，我不干了」
    - 市场把价格拉回大多数人认可的价值区
- **常见错误**：追这种突破。它看起来最像「启动」，实际最像「结束」。
- **自测**：价格冲出 POC，但成交量是萎缩的，你该偏向哪一边？
- **答案**：偏向**回归**。这是做淡出（fade）或旋转（rotation）的机会。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §3

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **拍卖（Auction）** | 价格离开价值区、去试探新价格的过程 |
| **公平价值（Fair Value）** | 大多数成交发生的价格，日内看就是 POC |
| **均值回归（Mean Reversion）** | 价格偏离太远后会回到平均值附近 |
| **过度延伸（Over-extension）** | 没有成交量支撑的快速偏离，通常会被拉回 |
| **竞价（Bid / Ask）** | 买方愿付价 / 卖方要价，成交价是两者相交处 |
| **淡出（Fade）** | 在价格冲过头时做反向 |

## 阶段 1 · 没有人在盯着你

> **目标**：拆掉「有人专门针对我」这个念头。
> **学完你能**：把注意力从「庄家想干什么」转到「流动性在哪、我该躲哪」。

### U1.1 止损猎杀是个幻觉

- **一句话**：没有人在专门等你的止损。
- **为什么需要**：这个念头会让你做出所有错误决策 —— 放大止损、不敢设止损、扛单。
- **怎么看**：真相不是「你不重要」，而是 —— **在这个尺度里，你的相关性非常小**。
    - 你的仓位对价格的直接影响约等于零
    - 价格扫到你的止损，是因为**那个位置本来就堆着大量相似的止损**
    - 你不是被瞄准的，你是**顺带被扫到的**
- **常见错误**：因为「怕被扫」而把止损放得很远。结果单次亏损远超你的风控上限。
- **自测**：如果你的止损被扫了，最可能的原因是什么？
- **答案**：你和其他很多人把止损放在了同一个位置。**你的止损位置本身就是可预测的信息**。
- **延伸阅读**：`03_市场参与者与流动性.md` §1

### U1.2 你是浮游生物

- **一句话**：你可能会「意外」成为鲸鱼的食物，但鲸鱼就算想找你也看不见你。
- **为什么需要**：它把「被针对」的恐惧，换成了「闪避」的操作目标。
- **怎么看**：把市场想成海洋：
    - **鲸鱼**不吃浮游生物，它只是**游过去**
    - 挡在它路线上的东西会被一起带走
    - 你要学的不是对抗，而是**别坐在它的运行轨迹上**
- **常见错误**：把「我被扫了」当成「有人要害我」。这让你从「找位置」滑向「找敌人」。
- **自测**：你无法对抗流动性，那你能做哪三件事？
- **答案**：**读它、避开它、或者顺着它。** 这三条涵盖了所有正确动作。
- **延伸阅读**：`03_市场参与者与流动性.md` §1

### U1.3 谁在交易：流动性构成

- **一句话**：绝大多数成交量来自算法机器人和散户，它们才是你真正在跟的东西。
- **为什么需要**：你默认的对手方是错的。搞错了对手，你的所有推断都会偏。
- **怎么看**：
    - **每天 >90% 的交易由算法机器人与散户完成**，其中算法可能 >70%
    - **算法机器人**：机构管理，几跳内开平，提供流动性，**它们设定每日的 IB**
    - **日内交易者**：市场参与者里的主要成分
    - **波段交易者**：持仓几天到几周
    - **鲸鱼 / 做市商**：大额订单，**罕见**，但对应罕见的高时间框架事件
- **常见错误**：以为自己是和「主力」在博弈。你日常的对手方是算法 —— 它没有情绪，也没有针对你的意图。
- **自测**：日内的 IB 主要由谁设定？
- **答案**：算法机器人。它们生成 IB，也制造我们赖以呼吸的流动性。
- **延伸阅读**：`03_市场参与者与流动性.md` §2

[[fig:liquidity]]

### U1.4 你。很。可。预。测。

- **一句话**：只要你不是天才也不是蠢货，你就会和多数人做一样的动作 —— 包括止损。
- **为什么需要**：这是把「普通人谬误」变成**可交易信息**的关键一步。
- **怎么看**：
    1. 你的猴子脑会识别模式 —— 和大家一样
    2. 你画着和大家一样的支撑线
    3. 线下方一点点就是「失效」，再下面一点就是你的止损
    4. 价格扎一下、打掉止损、然后反转
    - 这叫做「**千刀万剐式的死亡（Death by a thousand cuts）**」
- **常见错误**：以为「我知道这个陷阱了」就能免疫。知道和做到是两回事 —— 要靠**改变下单位置**，不是靠意志力。
- **自测**：怎么破这个循环？
- **答案**：**不要试图变聪明，要试图模仿大资金。** 把剩下的脑力当成镜像神经元，去模仿那些巨脑在做什么。
- **延伸阅读**：`03_市场参与者与流动性.md` §3、§6

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **止损猎杀（Stop Hunt）** | 大众想象中「专门打你止损」的行为；实际是止损扎堆被顺带扫掉 |
| **流动性（Liquidity）** | 挂单的深度。价格移动需要它，薄的地方走得快 |
| **算法机器人（Algo / Bot）** | 机构管理的高频程序，提供流动性并设定 IB |
| **鲸鱼（Whale）** | 高时间框架的大额订单，罕见但影响大 |
| **普通人谬误** | 多数人止损位置高度相似，因此可被预测 |
| **千刀万剐式死亡** | 反复被扫小止损、缓慢亏光的过程 |

## 阶段 2 · TPO 是怎么形成的

> **目标**：搞清 TPO 图到底在画什么，以及它是怎么被「堆」出来的。
> **学完你能**：自己从零推出一张轮廓，而不是背形态。

### U2.1 K 线丢了哪一维

- **一句话**：K 线告诉你价格**去过**哪里，不告诉你它在哪**停留**。
- **为什么需要**：这是 TPO 存在的全部理由。不理解这一点，你会把轮廓图当 K 线看。
- **怎么看**：同一段行情，两种画法：
    - **K 线**：X 轴是时间 → 你看到的是**顺序**
    - **TPO**：X 轴是「该价位被成交的次数」→ 你看到的是**分布**
    - 停留时间 = 市场对那个价格的**认可程度**
- **常见错误**：在轮廓图上找「形态」（头肩顶、三角形）。它不是价格走势图，是**分布图**。
- **自测**：某个价位被反复交易了很多次，说明什么？
- **答案**：市场反复认可这个价格 —— 它是**共识区**，价格容易在这里停留。
- **延伸阅读**：`01_市场轮廓基础.md` §1–3

[[fig:klinevstpo]]

### U2.2 时段与字母：TPO 的最小单位

- **一句话**：每个字母代表一个时间单位（通常 30 分钟）—— 这叫一个「时段」。
- **为什么需要**：字母是 TPO 的原子。不理解字母，你就读不出「谁在什么时候参与了」。
- **怎么看**：
    - 一天被切成若干时段，按字母顺序命名：**A、B、C、D…**
    - 每个时段结束后，把它**交易过的所有价位**都打上一个该时段的字母
    - 同一个价位被两个时段访问过，那一行就有两个字母
    - **字母数量 = 访问次数**，不是成交量
- **常见错误**：以为字母数量代表成交量。它代表**时间**：几个时段来过这个价位。
- **自测**：某价位显示 "A B C"，说明什么？
- **答案**：A、B、C 三个时段都在这个价位成交过 —— 它被**三次**访问。
- **延伸阅读**：`01_市场轮廓基础.md` §2–3

### U2.3 X 轴 / Y 轴：把走势变成分布

- **一句话**：Y 轴是价格，X 轴是「该价位被交易的次数」。
- **为什么需要**：坐标轴搞反了，整张图就读反了。
- **怎么看**：
    - **Y 轴（纵）= 价格**，从上到下由高到低
    - **X 轴（横）= 次数**，从左边起往右增长
    - 每一行是一根横向的柱子，柱子越长 = 这个价位被访问得越多
    - 开盘与收盘通常标在 Y 轴上
- **常见错误**：把 X 轴当时间。轮廓图**没有时间轴** —— 时间已经被折叠进字母里了。
- **自测**：轮廓图往右越长，代表什么？
- **答案**：那个价位被越多时段访问过 —— 是**成交密集区**。
- **延伸阅读**：`01_市场轮廓基础.md` §3

[[fig:tpo]]

### U2.4 从一个时段长成一张轮廓

- **一句话**：轮廓不是画出来的，是一个时段一个时段**堆**出来的。
- **为什么需要**：理解了生成过程，你就能反推：任何一个胖的地方，都是**多个时段反复回来**的结果。
- **怎么看**：
    - 时段 A 结束 → 只有 A 的价位有字母，轮廓还很瘦
    - 时段 B 结束 → B 覆盖的价位加上 B，轮廓变高
    - 时段 C、D 依次叠加 → 重叠越多的地方，柱子越长
    - **最后柱子最长的那一行，就是 POC**
- **常见错误**：以为轮廓是「当天行情的样子」。它是**当天所有时段行为的叠加结果**。
- **自测**：一个价位上出现了 4 个字母，最少需要几个时段？
- **答案**：4 个（如果每个时段只访问一次）。字母数不可能超过时段数。
- **延伸阅读**：`01_市场轮廓基础.md` §2–3

[[fig:tpobuild]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **TPO（Time Price Opportunity）** | 时间-价格机会：某时段在某价位成交过，记一个字母 |
| **时段（Period / TPO Period）** | 时间单位，通常 30 分钟，用 A、B、C… 命名 |
| **轮廓（Profile）** | 一天里所有时段叠加出来的横向分布图 |
| **X 轴 / Y 轴** | Y = 价格，X = 该价位被访问的次数 |
| **价值区（VA）** | 成交最密集的那一段，约占 70% |
| **POC** | 柱子最长的那一行，成交最密集的价位 |

## 阶段 3 · 读懂一张轮廓

> **目标**：能指着任意一张轮廓图，把每条线的名字和作用说出来。
> **学完你能**：一眼看出「贵区」「便宜区」「磁铁」在哪。

### U3.1 价值区间 VA / VAH / VAL

- **一句话**：70% 的成交发生的那一段价格，就是价值区间。
- **为什么需要**：它定义了「贵」和「便宜」的基准线。没有它，你只能看单点价格，判断不了位置。
- **怎么看**：VA 的上边界叫 **VAH**，下边界叫 **VAL**，上下各留 15%。它的统计学含义是「均值 ±1 个标准差」。
- **常见错误**：把 VAH / VAL 当铁板支撑阻力。它们只是**大多数人成交区的边界**，被穿过去是常态。
- **自测**：价格从 VAL 下方回到 VA 内部，你该想到哪条规则？
- **答案**：80% 规则 —— 开盘在昨日 VA 外、又被接受回 VA 内，有 80% 概率走到 VA 的另一端。（见 U8.4）
- **延伸阅读**：`01_市场轮廓基础.md` §4

### U3.2 控制点 POC

- **一句话**：成交最密集的那一个价位。
- **为什么需要**：它是市场用真金白银投出来的「最公平价格」，像磁铁一样把价格吸回来。
- **怎么看**：图上通常是一根红线或红色带。价格偏离它越远、且没有成交量支撑，回归的概率越大。
- **常见错误**：以为 POC 一定是支撑。它是**磁铁**，不是墙 —— 价格可以穿过它，只是倾向于回来。
- **自测**：价格从 POC 上方快速冲高，但成交量没跟上，大概率会怎样？
- **答案**：回到 POC 附近。这叫「过度延伸的拍卖」—— 参与者觉得太贵了，不干了。
- **延伸阅读**：`01_市场轮廓基础.md` §5

### U3.3 初始平衡 IB

- **一句话**：开盘后第一个小时（前两个 30 分钟时段）的价格区间。
- **为什么需要**：它给全天定调，是后面所有「拍卖」判断的基准。IB 宽窄直接预示当天的波动性。
- **怎么看**：A + B 两个时段的最高价和最低价。突破 IBH（上沿）或 IBL（下沿），说明有长周期参与者开始行动。
- **常见错误**：IB 还没成形就急着下单。**至少等 2–3 个时段**，看清市场在做什么。
- **自测**：IB 很窄意味着什么？
- **答案**：当天可能盘整，但也可能是「挤压」—— 参与者仓位很挤，随时可能来一段快速拉升或跳水。
- **延伸阅读**：`01_市场轮廓基础.md` §6

[[fig:ib]]

### U3.4 分布：单 / 双 / 三重

- **一句话**：一天里形成几个「肚子」，就是几重分布。
- **为什么需要**：双重或三重分布意味着市场**换了价值区**，不能整体当一个 VA 处理。
- **怎么看**：轮廓上出现两个或三个分离的成交量密集区。
- **常见错误**：三重分布日还把整个轮廓当一个 VA 用，导致目标位算错。
- **自测**：三重分布日，80% 规则的目标该怎么定？
- **答案**：把**每个分布当作独立的「一天」**，用相邻那个分布的 VA 来定目标，而不是整个轮廓的 VAH / VAL。
- **延伸阅读**：`05_策略组二_Tetris与80%规则.md` §2

### U3.5 正态分布：轮廓的理想形状

- **一句话**：理想状态下，轮廓长得像一条钟形曲线 —— 中间胖、两头细。
- **为什么需要**：它是判断「健康 / 不健康」的标尺。偏离钟形越远，市场越不平衡。
- **怎么看**：
    - 中间厚 = 大多数成交集中在公平价值附近
    - 两头薄 = 极端价格只有少数人接受
    - 两头突然伸出去一小截 = **尾巴**，代表拒绝（见 U4.2）
- **常见错误**：以为真实轮廓就该是漂亮的钟形。**真实市场很少这么清晰** —— 偏斜、双峰、缺口都是常态。
- **自测**：一个明显偏斜的轮廓在提示什么？
- **答案**：一方在主导。偏斜说明某个方向的参与者更激进，属于**不平衡**状态。
- **延伸阅读**：`01_市场轮廓基础.md` §1、§9

[[fig:bell]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **VA / VAH / VAL** | 价值区 / 其上沿 / 其下沿，各留 15% |
| **POC** | 成交最密集的价位，磁铁 |
| **IB / IBH / IBL** | 初始平衡（开盘后前 2 个时段）及其上下沿 |
| **单分布 / 双分布 / 三重分布** | 一天里形成 1 / 2 / 3 个价值区 |
| **偏斜（Skew）** | 轮廓不对称，说明一方主导 |
| **钟形曲线** | 理想轮廓形状，衡量健康度的标尺 |

## 阶段 4 · 读出市场的形状

> **目标**：看到一张轮廓，能说出它「哪里有效率、哪里没有」。
> **学完你能**：一眼判断哪些位置值得关注、哪些是噪音。

### U4.1 单印

- **一句话**：某个价位只出现过一次交易（只有一个字母）。
- **为什么需要**：它标记了「市场快速穿过、没有停留」的地方 —— 低效率区。价格以后回来时容易产生反应。
- **怎么看**：图上某个价位只有孤零零一个字母。连续多个价位都是这样，就是一条单印带。
- **常见错误**：把 **1 个**单印当确认信号。**一个单印不算确认。** 要等时间证据。
- **自测**：单印区出现在一段快速上涨中，价格回落时它更可能起什么作用？
- **答案**：支撑。那是买方曾经激进介入、没有遇到对手的位置。
- **延伸阅读**：`01_市场轮廓基础.md` §7

### U4.2 买入尾 / 卖出尾

- **一句话**：轮廓底部（买入尾）或顶部（卖出尾）的单印延伸，代表市场在极端位置「拒绝」。
- **为什么需要**：尾巴是大资金表态的痕迹 —— 有人在那个价格**激进地接货或砸盘**。
- **怎么看**：**至少 2 个单印**才算尾巴。买入尾 = 低位有激进买盘把价格顶回去；卖出尾 = 高位被卖方压下来。
- **常见错误**：把 1 个单印叫尾巴。数量不够，说明力度不够。
- **自测**：伦敦时段出现一根卖出尾，下一个时段你应该偏向哪个方向？
- **答案**：偏空。典型链条是：卖出尾 → 随后形成弱低点（进一步确认）→ 下一时段回测卖出尾的价位。
- **延伸阅读**：`01_市场轮廓基础.md` §10、`03_市场参与者与流动性.md` §4

### U4.3 弱高 / 弱低

- **一句话**：轮廓顶部或底部**收敛结束**，既没有尾巴、也没有厚实的成交堆积。
- **为什么需要**：说明那一侧「决心不足」。它们是**低效率**，价格倾向回去看一眼。
- **怎么看**：顶部或底部平坦，字母数量没有明显衰减。多个弱高点叠在一起时，像磁铁一样吸引价格。
- **常见错误**：以为弱高点是强阻力。恰恰相反 —— **弱**是它的名字，它容易被扫掉。
- **自测**：出现 3 个未被触碰的弱高点，价格大概率会怎样？
- **答案**：被吸引过去「扫一下」。但注意 —— **被扫 ≠ 被接受**，扫完经常就反向。
- **延伸阅读**：`01_市场轮廓基础.md` §8、`04_策略组一_拍卖_单印_扫掠_旋转.md` §5

### U4.4 HVN / LVN

- **一句话**：成交量密集的价格带（HVN）和稀疏的价格带（LVN）。
- **为什么需要**：价格在 HVN 容易**停留**，在 LVN 容易**加速穿过**。这直接决定你的止损该放哪。
- **怎么看**：HVN = 轮廓「胖」的地方；LVN = 轮廓「瘦」的地方，通常对应单印带。
- **常见错误**：在 LVN 里等回调。那里根本没有成交，价格不会回头。
- **自测**：价格冲进一段 LVN，你该期待快速穿过还是慢慢磨？
- **答案**：快速穿过。LVN 是「加速带」。
- **延伸阅读**：`01_市场轮廓基础.md` §14、`03_市场参与者与流动性.md` §5

### U4.5 形状总览：一眼分类

- **一句话**：把所有形状放在一起看，你会发现它们只有几类。
- **为什么需要**：分类是判断的第一步。不知道「这是什么形状」，就没法决定「该做什么」。
- **怎么看**：记住四个基本类型：
    - **正常分布** → 钟形，区间日，做旋转
    - **P 形** → 上方堆积，先跌后涨或逼空回补，**必须结合语境**（见 U6.1）
    - **b 形** → 下方堆积，先涨后跌或挤压
    - **双 / 三重分布** → 换过价值区，分段处理
- **常见错误**：看到 P 形就做空。**同一个形状在不同语境下结论完全相反** —— 这是下一阶段要解决的问题。
- **自测**：为什么 P 形和 b 形不能单独使用？
- **答案**：因为它们只描述「堆积在哪一侧」，不描述**市场处于什么背景**。同一形状在趋势里和区间里含义相反。
- **延伸阅读**：`01_市场轮廓基础.md` §14、`06_语境_市场结构_关键水平_节奏.md` §2

[[fig:shapes]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **单印（Single Print）** | 只有一个字母的价位，低效率区 |
| **买入尾 / 卖出尾（Buying / Selling Tail）** | 底部 / 顶部的单印延伸，至少 2 个单印 |
| **弱高 / 弱低（Poor High / Poor Low）** | 收敛结束、没有尾巴的顶部 / 底部，容易被扫 |
| **HVN / LVN** | 高成交量节点（停留）/ 低成交量节点（加速） |
| **P 形 / b 形** | 上方堆积 / 下方堆积的轮廓形状 |
| **拒绝（Rejection）** | 极端价位被市场明确否定，留下尾巴 |

## 阶段 5 · 今天是哪种日子

> **目标**：开盘两小时内，说出今天是趋势日还是区间日。
> **学完你能**：不再用同一种打法对付所有行情。

### U5.1 四种开盘形态

- **一句话**：开盘后两小时的价格行为，决定今天是趋势日还是区间日。
- **为什么需要**：选错「今天的性格」，后面所有操作都会拧着来。
- **怎么看**：按信念强度排序 ——
    - **Open-Drive**（直接走）→ 趋势日，**禁止逆势淡出**
    - **Open-Test-Drive**（先试一下再走）→ 趋势日，顺势为主
    - **Open-Rejection-Reverse**（先被拒绝再反向）→ 仍是趋势日，但形成更慢
    - **Open-Auction**（开盘就在区间里磨）→ 区间日，只适合旋转 / 剥头皮
- **常见错误**：在 Open-Drive 里逆势淡出。这是最容易亏大钱的动作。
- **自测**：开盘先向下试了一下，然后迅速调头贯穿 IB 跑到另一侧，这是哪种？
- **答案**：Open-Test-Drive。趋势仍然清晰，**不要逆势**。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §5

[[fig:openings]]

### U5.2 拍卖成功 vs 拍卖失败

- **一句话**：突破 IB 之后能不能在 IB **外面站住**，决定拍卖是成功还是失败。
- **为什么需要**：这是最核心的分支判断 —— 决定你做**延续**还是做**回归**。
- **怎么看**：两个指标 ——
    - **短期**：价格在 IB 外站住 **≥30 分钟**（1 个完整时段）→ 确认；少于 30 分钟回到 IB 内 → 失败
    - **长期**：当日**收盘**是否在 IB 外
- **常见错误**：突破就算成功。必须**站住**，一瞬间扎出去不算。
- **自测**：C 时段突破 IB 向上，但 C 时段内就开始回落，D 时段回到 IB 内。成功还是失败？
- **答案**：失败。这时 D 时段就是做空的机会。
- **延伸阅读**：`04_策略组一_拍卖_单印_扫掠_旋转.md` §1

[[fig:auction]]

### U5.3 趋势日 vs 区间日

- **一句话**：薄轮廓 + 单边踏步 = 趋势；矮胖均匀 = 区间。
- **为什么需要**：它决定你今天该顺势还是该做旋转 —— 用错打法比不做还糟。
- **怎么看**：看三点 —— 轮廓厚度、是否 one-timeframing（见 U7.2）、IB 的相对宽窄。
- **常见错误**：在区间日追趋势，在趋势日做淡出。这是最常见的两类亏损。
- **自测**：IB 很窄 + 轮廓很薄 + 每个时段都创新高。这是什么日？
- **答案**：趋势日。而且是很强的那种。
- **延伸阅读**：`07_动量与形态识别.md` §3②

### U5.4 练习：给开盘两小时定性

- **一句话**：把「猜今天是什么日」练成条件反射，靠的是重复，不是天赋。
- **为什么需要**：这个判断每天都要做一次。做不熟，你每天都在临场编。
- **怎么看**：一套可重复的练习法 ——
    1. 回看前几天，识别开盘形态，推测当天会是哪种 IB 形态
    2. 把闹钟设在开盘 **2 小时后**（30 分钟一个时段：A、B、C、D 共 4 个时段）
    3. 尽量在这 2 小时内**写下你的判断**
    4. **先不实盘**，只训练眼睛和大脑
    5. 统计一周能做对多少次
- **常见错误**：跳过练习直接实盘。你会用真钱交学费，而且不知道自己错在哪。
- **自测**：为什么截止时间设在开盘后 2 小时？
- **答案**：那时 A、B、C、D 四个时段已经走完，IB 和开盘形态都已经成形 —— 再晚就错过可操作的窗口了。
- **延伸阅读**：`02_拍卖机制与四种开盘.md` §7

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **Open-Drive** | 开盘直接单边走，最强趋势日 |
| **Open-Test-Drive** | 先试探再反向贯穿 IB，趋势日 |
| **Open-Rejection-Reverse** | 先被拒绝再反转，趋势形成更慢 |
| **Open-Auction** | 开盘即在区间内磨，区间日 |
| **拍卖确认（≥30 分钟）** | 在 IB 外站住一个完整时段 |
| **趋势日 / 区间日** | 薄轮廓单边 / 矮胖均匀 |

## 阶段 6 · 建立语境

> **目标**：养成「先看背景、再看形态」的习惯。
> **学完你能**：不再孤立地解读任何一个形态。

### U6.1 为什么语境优先

- **一句话**：同一个形态，在不同背景下结论完全相反。
- **为什么需要**：这是整套体系里最重要的一条 —— **没有语境，所有形态都会把你带进陷阱。**
- **怎么看**：固定顺序 —— 先定大方向 → 再定关键水平 → 最后才看形态。
- **常见错误**：看到 P 形就做空。P 形在下跌趋势里可能是「挤压的 D 形」，代表**要涨**，不是逼空回补。
- **自测**：下跌趋势里出现 P 形，什么条件下它才代表「逼空回补」？
- **答案**：肚子**最后**形成的时候。如果先形成肚子、后形成 P 的腿，那是挤压形态，含义相反。
- **延伸阅读**：`06_语境_市场结构_关键水平_节奏.md` §0、§2

### U6.2 市场结构

- **一句话**：先看周线 / 日线，确定现在是上涨、下跌还是震荡。
- **为什么需要**：顺趋势的交易胜率高得多。逆势很酷，但风险极高。
- **怎么看**：周线方向 + 关键高低点 + 是否在两个水平之间「框架化（bracketing）」。
- **常见错误**：在下跌趋势里抄底。**2019 年以来趋势反转的概率只有 0.36%**（2513 天里只有 9 天）。
- **自测**：你不确定方向时，正确动作是什么？
- **答案**：**不交易。** 「如果你不确定，或者市场非常震荡，那就别做这一单，坐着看就好。」
- **延伸阅读**：`06_语境_市场结构_关键水平_节奏.md` §A

### U6.3 关键水平

- **一句话**：年开盘、年高 / 低、区间线、SMA200、锚定 VWAP —— 价格会在这里产生反应。
- **为什么需要**：这些是心理障碍位。价格靠近时会**减速、纠缠**，有时会反转。
- **怎么看**：价格靠近关键水平时，找「延续」或「反转」的证据。多数情况是磨一阵再穿过去。
- **常见错误**：以为每个关键水平都会反转。更常见的是**磨蹭后刺穿**。
- **自测**：价格「像长矛一样」直接穿过关键水平，说明什么？
- **答案**：某个大参与者（鲸鱼）决定在这些水平上砸盘或扫货。**这很少见**，是强信号。
- **延伸阅读**：`06_语境_市场结构_关键水平_节奏.md` §B

### U6.4 节奏（Tempo）

- **一句话**：价格变化的速度，本质是市场的「信念强度」。
- **为什么需要**：节奏加速 = 确认；节奏衰竭 = 止盈信号。这是出场判断的核心工具。
- **怎么看**：价格**接近已知水平时降速**，**穿越未知区域时加速**。跟人走夜路一样 —— 到了熟悉的地方就慢下来。
- **常见错误**：把节奏当成波动率。它们是两回事 —— 节奏讲的是**决心**，不是振幅。
- **自测**：价格接近年开盘时明显放慢，你该更激进还是更谨慎？
- **答案**：更谨慎。降速说明参与者在犹豫，突破失败的概率上升。
- **延伸阅读**：`06_语境_市场结构_关键水平_节奏.md` §2

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **语境（Context）** | 形态所处的市场背景；脱离语境的形态没有意义 |
| **市场结构（Market Structure）** | 周线 / 日线的方向与关键高低点 |
| **框架化（Bracketing）** | 价格在两个水平之间来回，形成区间 |
| **关键水平（Key Level）** | 年开盘、年高低、SMA200、锚定 VWAP 等心理障碍位 |
| **节奏（Tempo）** | 价格变化速度，等价于信念强度 |
| **期望值（Expectancy）** | 长期每笔交易的平均结果，必须建立在自己的统计上 |

## 阶段 7 · 识别动量

> **目标**：能区分「真正有驱动力的动作」和「机械发生的噪音」。
> **学完你能**：知道哪些形态值得跟，哪些必须无视。

### U7.1 信念标记 vs 机械标记

- **一句话**：有些形态是「被驱动的」（信念），有些只是「机械发生」（噪音）。
- **为什么需要**：机械标记脱离语境会把你坑死 —— 它们一直在发生，但不代表任何事。
- **怎么看**：
    - **信念标记** = 不平衡、区间延伸、one-timeframing、更大级别买方 / 卖方控制
    - **机械标记** = 过度（excess）、弱高 / 弱低、失败的区间延伸、回补
- **常见错误**：看到弱高点就做空。先问一句：**「这么多弱高点，但一个都没被扫掉。为什么？」** —— 答案在语境里。
- **自测**：一堆弱高点一个都没被扫掉，说明什么？
- **答案**：市场没有动力去回访它们，可能处于强趋势中（趋势日不会回头扫这些小结构）。
- **延伸阅读**：`07_动量与形态识别.md` §2

### U7.2 One-timeframing（单边踏步）

- **一句话**：每个时段都只朝一个方向推进，不回头测试前一时段。
- **为什么需要**：这是**最强的动量信号**。它的终止往往是反转的第一警告。
- **怎么看**：逐时段看 —— 如果某个时段**没有**向前一时段的第一根 TPO 反向交易，就是 one-timeframing。
- **常见错误**：在 one-timeframing 里做逆势。方向性信念极强，别挡路。
- **自测**：one-timeframing 突然终止（出现反向 TPO），意味着什么？
- **答案**：动量减弱或结束的**第一警告**。注意是「第一」警告，不是反转确认。
- **延伸阅读**：`07_动量与形态识别.md` §3①

[[fig:otf]]

### U7.3 Range Extension（区间延伸）

- **一句话**：价格先在窄区间里磨，然后**带着信念**突破 IB 向外延伸。
- **为什么需要**：这是「拍卖启动」的明确信号 —— 动量来了。
- **怎么看**：先有一个窄区间（常与 VA 重叠），然后价格突破 IB 并继续走。
- **常见错误**：把区间内的假突破当延伸。关键是突破**之后**有没有延续。
- **自测**：突破 IB 但成交量没跟上，算不算 range extension？
- **答案**：要警惕。关键是「带着信念突破」—— 没有成交量配合的突破更容易失败。
- **延伸阅读**：`07_动量与形态识别.md` §3③

### U7.4 Spike 与 POC 迁移

- **一句话**：Spike 是极端位置的动量冲击（属于「过度」）；POC 迁移是价值中心在移动。
- **为什么需要**：Spike 常**标志该方向动量结束**；POC 迁移确认趋势正在构建。
- **怎么看**：
    - **Spike**：出现在时段的极端位置（开盘或收盘附近），是一种 excess
    - **POC 迁移**：连续多个交易日朝一个方向移动 → 中期动量确认
- **常见错误**：追 spike。市场**讨厌过度**，因为它们是低效率 —— 所以 spike 常是反向信号。
- **自测**：POC 连续 3 天向上迁移，说明什么？
- **答案**：中期动量在构建，更大级别的一方在控制。但盘中（当日）的 POC 迁移**不要过度依赖** —— 后续时段可能很快反向。
- **延伸阅读**：`07_动量与形态识别.md` §3④⑤

[[fig:momforms]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **信念标记（Conviction Marker）** | 由真实驱动力产生的形态，值得跟 |
| **机械标记（Mechanical Marker）** | 机械发生的形态，脱离语境没有意义 |
| **One-timeframing** | 每个时段都单向推进，最强动量信号 |
| **区间延伸（Range Extension）** | 窄区间后带信念突破 IB |
| **尖刺（Spike）** | 极端位置的动量冲击，属「过度」 |
| **POC 迁移** | 价值中心连续向一个方向移动 |
| **过度（Excess）** | 价格冲过头的部分，通常会被回补 |

## 阶段 8 · 可交易的策略

> **目标**：把前面学的判断，变成可以下单的具体打法。
> **学完你能**：手上有一套明确的 setup，而不是「感觉要涨」。

### U8.1 拍卖交易

- **一句话**：拍卖成功就顺势做延续，拍卖失败就淡出新尝试、做反向。
- **为什么需要**：这是把「判断」变成「操作」的第一条路径，也是最主线的一条。
- **怎么看**：确认拍卖点 → 看时段收盘相对拍卖点的位置 → 收盘在上方就预期继续上拍，反之亦然。
- **常见错误**：拍卖失败后还追同方向。失败意味着长周期参与者**没成功**，下次他们会在同一水平做反向。
- **自测**：拍卖失败后，第一目标通常放在哪？
- **答案**：POC 下方。因为均值回归的第一站就是 POC。
- **延伸阅读**：`04_策略组一_拍卖_单印_扫掠_旋转.md` §5-II

### U8.2 弱高 / 弱低扫掠

- **一句话**：多个未被触碰的弱高 / 弱低像磁铁，吸引价格去「扫一下」。
- **为什么需要**：这是相对高胜率的短打机会，逻辑清晰、目标明确。
- **怎么看**：找**重复出现的、仍未被触碰的**弱高 / 弱低 → 等价格过去扫。
- **常见错误**：扫到之后不走。原则是：**除非这个动作有拍卖支持，否则扫掉之后就该走。**
- **自测**：扫掉弱低点之后，什么情况下可以继续持有？
- **答案**：出现了**拍卖成功或被接受**的证据（价格在下方站住、成交量配合）。否则扫完就反向。
- **延伸阅读**：`04_策略组一_拍卖_单印_扫掠_旋转.md` §5-I

### U8.3 旋转交易（Rotation）

- **一句话**：在 VA 边缘或日内极端位置淡出，目标回到 POC。
- **为什么需要**：这是均值回归的标准打法，区间日的主力策略。
- **怎么看**：前提是**没有强动量标记** —— 没有 one-timeframing、没有 range extension、POC 没有多日迁移。
- **常见错误**：在趋势日做旋转。趋势日里价格不会回到 POC，它会一路走。
- **自测**：什么情况下**绝对不能**做旋转？
- **答案**：出现 one-timeframing、range extension 或 POC 多日同向迁移时 —— 这些说明动量在，价格不会回归。
- **延伸阅读**：`04_策略组一_拍卖_单印_扫掠_旋转.md` §5-III

### U8.4 80% 规则

- **一句话**：开盘在昨日 VA 外，被接受回 VA 内后，有 80% 概率走到 VA 的另一端。
- **为什么需要**：这是最机械化、最容易验证的一条规则，适合作为第一个实战 setup。
- **怎么看**：等「**被接受**」的确认 —— 多根时间单位站稳，不是一个瞬间扎针。
- **常见错误**：不等确认就进场。「现实从不如理论顺滑，价格很少走直线」—— 不等确认，止损再宽也会被扫。
- **自测**：三重分布日怎么用这个规则？
- **答案**：把每个分布当作独立的「一天」，用相邻分布的 VA 来定目标。
- **延伸阅读**：`05_策略组二_Tetris与80%规则.md` §2

[[fig:rule80]]

### U8.5 Tetris（俄罗斯方块）

- **一句话**：把多个 profile 合并，找出未填补的缺口，价格会被吸引过去。
- **为什么需要**：它告诉你「**哪里**会被吸引」，是方向线索。
- **怎么看**：右键选中 profile →「Merge with previous profile section」→ 重复操作 → 看合并后哪里还有粗糙地形。
- **常见错误**：以为缺口一定会补。**它不告诉你「什么时候」** —— 时机必须来自语境 + 节奏确认。
- **自测**：Tetris 找到缺口后，还需要什么才能进场？
- **答案**：语境（大方向）+ 动量 / 节奏确认。**不能只靠「缺口一定会补」入场。**
- **延伸阅读**：`05_策略组二_Tetris与80%规则.md` §1

[[fig:tetris]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **拍卖点（Auction Point）** | 第一个走出 IB 的那个点 |
| **拍卖确认 / 失败** | 在 IB 外站住 ≥1 个时段 / 未站住就回落 |
| **扫掠（Sweep）** | 价格去触碰未被打掉的弱高 / 弱低 |
| **旋转（Rotation）** | 在区间边缘淡出、目标回 POC |
| **80% 规则** | 从 VA 外被接受回 VA 内 → 走到另一端 |
| **Tetris（合并轮廓）** | 多日 profile 合并找未填补缺口 |
| **Round-trip（来回打脸）** | 浮盈回吐成亏损，必须避免 |

## 阶段 9 · 用订单流确认

> **目标**：把「位置对了」升级成「位置对了 + 有人在动手」。
> **学完你能**：过滤掉大量假突破。

### U9.1 订单簿（DOM）

- **一句话**：所有挂单的清单，告诉你流动性有多深。
- **为什么需要**：价格移动需要流动性。看懂簿子，才知道价格能走多快、哪里会减速。
- **怎么看**：中间是成交价；上方是卖单（ask），下方是买单（bid）。**价格每移动一次，对应一侧会生成新的挂单** —— 价格上涨时下方生成新 bid，下跌时上方生成新 ask。
- **常见错误**：把「墙」当真实。**大多数买墙卖墙在价格靠近时都会消失**（诱骗挂单 / spoofing）。
- **自测**：簿子很薄的时候，价格移动会更快还是更慢？
- **答案**：更快。薄簿子意味着更小的市价单就能推动更大的价格位移。
- **延伸阅读**：`10_订单流三件套.md` §1、`12_衍生品数据_上_OT_CVD_Funding_Depth.md` §5

[[fig:dom]]

### U9.2 足迹图（Footprint）

- **一句话**：把每根 K 线的成交量拆成 bid / ask 两侧显示。
- **为什么需要**：让你看到一根 K 线**内部**发生了什么，而不只是开高低收四个数。
- **怎么看**：**对角线读，它不是镜像。** 空隙下方左侧 = 成交的 bid；空隙上方右侧 = 成交的 ask。简化记法：**右胖 = 价格上冲；左胖 = 不上冲；两边都胖 = 平衡**。
- **常见错误**：当成镜像读，把 bid 和 ask 看反。
- **自测**：足迹图右侧明显更胖，说明什么？
- **答案**：主动性买盘占优，价格倾向向上。
- **延伸阅读**：`10_订单流三件套.md` §2

[[fig:footprint]]

### U9.3 Delta 与 CVD

- **一句话**：Delta 是单根 K 线的主动买卖差，CVD 是它的累计。
- **为什么需要**：它告诉你「谁在更主动」—— 这是判断真假突破的关键。
- **怎么看**：Delta 逐根重置（微观视角），CVD 跨 K 线累加（宏观视角）。**用 HTF CVD（1H / 4H / 日）定方向，用 LTF CVD（1m / 5m / 15m）定执行。**
- **常见错误**：单独用低周期 CVD。**低周期 CVD 本身噪音很大，绝对不要单独使用。**
- **自测**：突破之前 CVD 是「先逐步堆起来」，还是「突破那一下才突然尖刺」—— 哪个是真需求？
- **答案**：「先堆起来」是真需求（build before the break）；「突破时尖刺」往往是假突破。
- **延伸阅读**：`11_CVD完全指南.md` §1、`13_衍生品数据_下_清算_Delta_多空比_Taker.md` §3

### U9.4 吸收 vs 衰竭

- **一句话**：CVD 和价格背离时，要么是有大单在**承接**（吸收），要么是主动方**没力气了**（衰竭）。
- **为什么需要**：这是订单流里最强的反转信号，也是区分「真推不动」和「假推不动」的关键。
- **怎么看**：
    - **吸收** = 有隐藏限价单在被动接（对手方强大）→ 结合热力图能看到墙
    - **衰竭** = 主动方自己没劲了（没有对手方）→ 成交量在萎缩
- **常见错误**：把衰竭点当绝对顶底。**衰竭点往往不是绝对顶 / 底，而且经常会被再次回踩。**
- **自测**：CVD 上升但价格下跌，这是哪种？
- **答案**：买入吸收（Buying Absorption）—— 主动买单被隐藏的限价卖单吃掉了。
- **延伸阅读**：`11_CVD完全指南.md` §4

[[fig:cvddiv]]

### U9.5 现货 CVD vs 永续 CVD

- **一句话**：现货 CVD 是真实需求，永续 CVD 是杠杆情绪。
- **为什么需要**：判断这波行情是**可持续**还是**脆弱**。
- **怎么看**：
    - 现货 CVD ↑ 而永续 CVD ↓ → 真实需求进入，杠杆还没参与 → **更可持续**
    - 现货 CVD ↓ 而永续 CVD ↑ → 杠杆硬推，现货买家不支持 → **假突破 / 清算瀑布 / 陷阱**
- **常见错误**：把杠杆推起来的行情当成趋势。
- **自测**：哪一种组合更可能形成可持续的上行趋势？
- **答案**：现货 CVD 上升 + 永续 CVD 下降（或走平）。现货买家不会因资金费率或清算被强制踢出。
- **延伸阅读**：`11_CVD完全指南.md` §6.1、`12_衍生品数据_上_OT_CVD_Funding_Depth.md` §3.1

[[fig:spotperp]]

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **DOM（订单簿）** | 所有挂单清单，反映流动性深度 |
| **诱骗挂单（Spoofing）** | 挂出大单制造假深度，价格靠近就撤 |
| **足迹图（Footprint）** | 把 K 线成交量拆成 bid / ask 两侧 |
| **Delta** | 单根 K 线的主动买 − 主动卖 |
| **CVD** | Delta 的累计值，跨 K 线累加 |
| **吸收（Absorption）** | 主动单被隐藏限价单吃掉，反转信号 |
| **衰竭（Exhaustion）** | 主动方自己没力气了，成交量萎缩 |
| **堆叠不平衡（Stacked Imbalances）** | 连续多档出现单边不平衡，强信号 |

## 阶段 10 · 用衍生品判断脆弱性

> **目标**：知道当前持仓结构有多脆弱、哪里可能爆。
> **学完你能**：避开「看起来很好但随时会崩」的位置。

### U10.1 未平仓量（OI）

- **一句话**：市场上还没平掉的合约总量，代表有多少杠杆在场。
- **为什么需要**：OI 告诉你行情背后有多少「潜在能量」—— 敞口越大，波动潜力越大。
- **怎么看**：**必须和价格一起看** ——
    - 价格 ↑ + OI ↑ = 新多头进入，趋势更强
    - 价格 ↑ + OI ↓ = 空头回补，**看起来强但更脆弱**
    - 价格 ↓ + OI ↑ = 新空头进入，下跌更强
    - 价格 ↓ + OI ↓ = 多头平仓 / 被清算，恐慌出逃
- **常见错误**：以为 OI 能告诉你多空方向。**每个多头必然对应一个空头**，OI 只反映总敞口。
- **自测**：价格上涨但 OI 下降，这个上涨健康吗？
- **答案**：不健康。这是空头回补推动的，一旦回补结束，上涨就失去动力。
- **延伸阅读**：`12_衍生品数据_上_OT_CVD_Funding_Depth.md` §2

### U10.2 资金费率（Funding）

- **一句话**：永续多空之间的周期性支付，用来把合约价格锚回现货。
- **为什么需要**：它衡量「持仓压力」—— 谁在付钱、付多少、能付多久。
- **怎么看**：正费率 = 多头拥挤（多头付给空头）；负费率 = 空头拥挤。**关键是「极端 + 持续 + OI 上升」三者同时出现**才危险。
- **常见错误**：以为极端费率会自动导致反转。**高 / 低费率本身不会导致反转** —— 要看极端持续多久、OI 在升还是降。
- **自测**：现货持续买入，同时资金费率为负，哪一边会被套？
- **答案**：空头。「现货趋势很强，而永续一侧出现极端资金费率的反向信号，永续那一侧通常会输。」
- **延伸阅读**：`12_衍生品数据_上_OT_CVD_Funding_Depth.md` §4

### U10.3 清算（Liquidations）

- **一句话**：保证金不足时的强制平仓，产生「非自愿」的市价单。
- **为什么需要**：清算驱动的行情**又快又容易过冲** —— 知道它，才不会在瀑布里被卷走。
- **怎么看**：找**清算簇**（交易者倾向用相似杠杆、把止损放相似位置，所以会扎堆）。用 **z-score** 判断这次清算相对近期有多「猛」。
- **常见错误**：追清算瀑布的第一根。正确做法是**降低仓位，或只做确认后的回踩 / 反转**。
- **自测**：清算瀑布需要哪五个条件同时具备？
- **答案**：深度低 + 点差扩大 + 高杠杆 + OI 上升 + 参与度低。
- **延伸阅读**：`13_衍生品数据_下_清算_Delta_多空比_Taker.md` §2

[[fig:liq]]

### U10.4 多空比与 Taker Flow

- **一句话**：多空比是散户情绪（弱信号），Taker Flow 是实际成交流（强信号）。
- **为什么需要**：区分「谁在说话」和「谁在动手」—— 前者噪音大，后者才是钱。
- **怎么看**：
    - **多空比**只统计**账户数量**，不是仓位规模。单独用很弱，必须配合 OI
    - **Taker Buy / Sell** 是真实的主动买卖量，不绑定 K 线，是「最干净」的短窗主动性指标
- **常见错误**：单独用多空比做方向判断。它只是「温和的反向指标」。
- **自测**：多空比极高，但 OI 走平。这个信号强吗？
- **答案**：弱。说明只是很多小散户在做多，**规模不大**。需要 OI 快速上升配合，才说明真有杠杆扎堆。
- **延伸阅读**：`13_衍生品数据_下_清算_Delta_多空比_Taker.md` §5–6、§四（净头寸）

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **OI（未平仓量）** | 未平掉的合约总量，反映总杠杆敞口 |
| **OI Delta** | OI 的变化量，配合价格判断新增 / 平仓 |
| **资金费率（Funding）** | 永续多空的周期性支付，衡量持仓压力 |
| **清算簇（Liquidation Cluster）** | 相似杠杆 / 止损位置扎堆形成的爆仓带 |
| **z-score** | 衡量本次清算相对近期有多极端的标准分 |
| **多空比（Long/Short Ratio）** | 按账户数统计的多空比，弱信号 |
| **Taker Flow** | 主动买 / 卖量，不绑 K 线，最干净的短窗指标 |

## 阶段 11 · VWAP

> **目标**：多一个稳定的价值锚点，用来判断「贵还是便宜」。
> **学完你能**：把 VWAP 和订单流组合成一套确认流程。

### U11.1 VWAP 与偏离带

- **一句话**：按成交量加权的平均价，比普通均线更「黏」价格。
- **为什么需要**：它给出一个稳定的价值锚点，判断价格处于溢价区还是折价区。
- **怎么看**：价格在 VWAP **上方** = 溢价区（可能多头强势）；**下方** = 折价区。第 1 / 2 / 3 个标准差带用来衡量「过度延伸」的程度。**±2 / ±3σ 是统计上的反转高发区**，但只是「该看的地方」，不是「该进的地方」。
- **时间维度**：**高时间维度的 VWAP 效力强于低时间维度**。月 / 周锚定的 VWAP 是全体参与者的成本中枢，日内 VWAP 只是当天的成本线。定方向看高周期，找点位看低周期。
- **常见错误**：以为市场一定会回到 VWAP。**市场没有义务尊重 VWAP，也没有义务回到 VWAP。**
- **自测**：价格进入 3σ 偏离带，你该做什么？
- **答案**：进入**警戒状态**（不是入场状态），然后打开**当时的足迹图**：若主动单很猛但价格不再往外走 = **吸收** → 反转可信；若连续堆叠不平衡、价格跟着走 = **被击穿** → 趋势延续，别逆势。
- **延伸阅读**：`14_VWAP实用指南.md` §3–4

[[fig:vwap]]

### U11.2 VWAP × 订单流

- **一句话**：VWAP 定**位置**，订单流定**时机**。
- **为什么需要**：单用 VWAP 只知道「贵或便宜」，不知道「会不会继续」。
- **怎么看**：回踩 VWAP 时看 **CVD 是否维持强势**；观察 VWAP 附近有没有**堆叠不平衡（stacked imbalances）**作为入场信号。
- **极值处反过来看**：在 **±2 / ±3σ** 位置，同样一张足迹图要问的是「**吸收还是被击穿**」——回踩找延续，极值找反转，用的是同一张图。
- **常见错误**：VWAP 附近看到买入就进，不看 CVD 配合；或者到了 ±2 / ±3 直接逆势抄底摸顶。
- **自测**：价格上破 VWAP 时主动买很多，但价格就是不涨，说明什么？
- **答案**：买方需要付出**明显更大的努力**才能推动价格，说明卖方在吸收。这最终会导致下跌延续。
- **延伸阅读**：`14_VWAP实用指南.md` §5

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **VWAP** | 成交量加权平均价，比普通均线更黏价格 |
| **锚定 VWAP（Anchored VWAP）** | 从指定起点（月 / 季 / 事件）重算的 VWAP |
| **偏离带（1 / 2 / 3σ）** | 衡量价格偏离 VWAP 多远 |
| **反转高发区（±2 / ±3σ）** | 统计上的极端偏离位，常出现反转，但必须用足迹图确认 |
| **时间维度（Timeframe）** | VWAP 的锚定起点周期；越高（周 / 月）效力越强 |
| **溢价区 / 折价区** | VWAP 上方 / 下方 |
| **堆叠不平衡** | 连续多档单边不平衡，VWAP 附近的入场信号 |

## 阶段 12 · 组装起来

> **目标**：把前面所有零件拼成一套每天能重复执行的流程。
> **学完你能**：开盘前 10 分钟做完准备，盘中不用临场编。

### U12.1 三重确认

- **一句话**：**位置 × 时间 × 流**，三个都满足才允许开仓。
- **为什么需要**：这是避免瞎猜的最低门槛。缺任何一条，你就是在赌。
- **怎么看**：
    - **位置**：必须发生在结构 / 价值参考点附近（VAH / VAL / POC、单印边缘、tails、VWAP / 偏离带、清算簇、深度墙）
    - **时间**：必须有 Profile 的时间确认（接受 / 拒绝 / 失败拍卖），≥1 个完整时段
    - **流**：至少 1–2 个流动指标同向，或给出清晰的背离信号
- **常见错误**：只看位置就进。这是最常见的错误 —— 「位置对了」不等于「现在就该进」。
- **自测**：缺了「时间」这一条会怎样？
- **答案**：你会被单根尖刺 K 线诱骗进去。时间确认的作用就是过滤掉这些瞬间假动作。
- **延伸阅读**：`15_日内流程_全工具整合.md` §5

[[fig:triple]]

### U12.2 情景剧本

- **一句话**：开盘前写好 2–3 个「如果……那么……」，并明确写下**不交易的条件**。
- **为什么需要**：没有计划 = FOMO = 送钱。**你没有计划，你就不交易。**
- **怎么看**：每个剧本包含六项 —— **触发 / 确认 / 失效 / 止损 / 目标 / 管理**。
- **常见错误**：盘中临时改剧本。**不追单、不临时改剧本。**
- **自测**：市场走出了你没写进剧本的走势，正确动作是什么？
- **答案**：**不交易。** 你只是 FOMO 追进未知区域，根本不知道会发生什么。
- **延伸阅读**：`08_策略蓝图.md`、`15_日内流程_全工具整合.md` §3

### U12.3 每日执行清单

- **一句话**：把上面所有东西压成一张可重复执行的清单。
- **为什么需要**：流程化的目的是**减少临场决策** —— 决策越少，犯错越少。
- **怎么看**：三段 —— 开盘前 ≤10 分钟（定方向、标水平、写剧本）→ 盘中前 2 小时（等 IB、分类、三重确认后进场）→ 盘后 ≤15 分钟（记录、复盘、只改一个点）。
- **常见错误**：清单写了不做。建议先用**极小仓位**跑 2–4 周，把流程练成条件反射再上仓位。
- **自测**：盘后复盘最少要记录哪几项？
- **答案**：日型（趋势 / 区间）、开盘型（四种之一）、动量标记、你的执行评分，以及**下次只改的一个点**。
- **延伸阅读**：`16_每日执行清单.md`

### 本阶段需要关注的术语

| 术语 | 一句话 |
|---|---|
| **三重确认** | 位置 × 时间 × 流，三者齐备才开仓 |
| **情景剧本（Scenario）** | 开盘前写好的「如果……那么……」计划 |
| **失效条件（Invalidation）** | 什么情况证明你的判断错了，必须离场 |
| **执行评分** | 盘后给自己的纪律打分，而不是给盈亏打分 |
| **FOMO** | 怕错过而追进未知区域，最常见的送钱方式 |
