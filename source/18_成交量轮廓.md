# 成交量轮廓：同一张图的另一种量法

**目标**：分清 TPO、VPVR、VPSV 三样东西，知道每一把尺子量的是什么、什么时候用哪把。

**学完你能**：看到别人说「POC 在 64800」，先问一句「哪把尺子量出来的、框的是哪一段」。

---

## 一、先分清三样东西

**它们都在价格旁边画水平分布，所以经常被当成一回事。但它们量的是不同的东西。**

| | 横轴量什么 | 纵轴的范围由谁定 | 会不会随你滚动而变化 |
|---|---|---|---|
| **TPO 轮廓** | **时间**（每个时段在某价位待了多久） | 一个交易时段 | 不会，锚在时段上 |
| **VPSV**（成交量轮廓 · 时段版） | **成交量** | 一个交易时段 | 不会，锚在日历上 |
| **VPVR**（成交量轮廓 · 可见范围版） | **成交量** | **你屏幕上当前能看到的那一段** | **会** —— 滚动、缩放都会重算 |

**这张表是全篇的地基。** 记住两件事：

1. **TPO 量时间，成交量轮廓量成交量。** 同一个价位，「待得久」和「换手多」是两回事。
2. **VPSV 和 VPVR 的区别不在量什么，而在「量哪一段」。** 一个锚在日历上，一个锚在你的屏幕上。

---

## 二、成交量轮廓是怎么算出来的

**把价格区间切成若干等高的「档」（rows），每一笔成交归进它成交价所在的那一档，然后把每档的成交量画成横向柱状图。**

- **柱长的档 = 那个价位成交得多。**
- **柱短的档 = 市场匆匆路过，没做成多少生意。**

### 档高（row size）不是随便设的

| 档高 | 效果 |
|---|---|
| **档少**（每档覆盖的价格多） | 形状平滑、好读，但细节被抹掉 |
| **档多**（每档覆盖的价格少） | 能分辨具体价位，但长区间上会显得毛糙 |

**设多少取决于你在看多长的一段市场。** 看一个月的行情用细档，整张图会变成一团噪音。

### 每一档还能拆成买 / 卖

因为主动买单和主动卖单可以分开统计，**多数成交量轮廓会把每一档拆成「打到卖价」和「打到买价」两部分**。
这样你看到的不只是那一档成交了多少，还有**它是被谁吃掉的**。

**这一步很关键** —— 它把成交量轮廓从「哪里热闹」升级成「哪一边在出力」。

## 三、POC 与价值区：两个价位的含义

### POC（控制点）= 最长的那一档

**它就是这个期间成交最密集的价位**，也就是这个期间**买卖双方达成共识最多的地方**。

- 一般把它读作**该期间的公平价格**。
- 市场经常回来测试之前的 POC。
- **在震荡行情里，它表现为一个磁铁** —— 价格绕着它转。

### 价值区（VA）从 POC 往外长出来

不是画一个固定宽度，而是**一步步长出来的**：

1. 从 POC 开始，比较它上面一档和下面一档；
2. **把成交量大的那一档并进来**；
3. 重复这个动作，每次都取「剩下的邻档里更大的那个」；
4. 直到收进来的档位累计占到该期间总成交量的 **70%**（默认值）。

**收进来之后，最高的那一档 = VAH（价值区上沿），最低的那一档 = VAL（价值区下沿）。**

### 为什么 VAH / VAL 值得看

**它们不是离 POC 的固定距离，而且通常不对称。**

VAH 和 VAL 落在**成交量用尽的地方**。所以：

> **价值区往上伸得比往下远 = 这个期间大部分的生意是在上涨过程中做的。**

**这个不对称本身就是信息**，不要把它当成误差。

**用法**：价格被接回价值区内 → 市场重新认可这个估值；价格在 VAH / VAL 被拒绝 → 市场不认。

## 四、VPSV：一场一个轮廓

**VPSV 每个交易时段画一个独立的轮廓，时段结束就封口，下一场重新开始。**

所以一周的日线会话会得到**七个并排的轮廓**，而不是一个混在一起的大分布。

### 为什么要分开

**因为这样才可比。**

每个轮廓都是对**一段固定长度、固定钟点**的独立描述：那一天的价值在哪、POC 在哪、价值区多宽。
而且因为它锚在日历上、不锚在你的视口上，**你滚动它也不会变**。

**逐场比较的三种读法**：

| 现象 | 含义 |
|---|---|
| **价值整体抬升** | 买方接受了昨天市场不接受的价格 —— **这就是趋势在轮廓图上的样子** |
| **价值重叠** | 两场基本认同同一个区间，谁也没能把公认区间推走 —— 旋转行情 |
| **POC 连续迁移** | 共识在往一个方向漂 —— 有时比价格图本身更清楚 |

### 开发中 POC（Developing POC）

**收完盘的轮廓只告诉你 POC 最后落在哪。开发中 POC 告诉你它一路是怎么走的。**

它揭示方向：**稳定爬升 = 价值在实时被越推越高；纹丝不动 = 一整天都在围着同一个价格转。**
价值区边缘同样可以画出「开发中」的形态。

### 裸露价位（Naked Levels）

**一个价位自它诞生的那一场之后，价格再没回来过，就叫裸露（naked，也叫 virgin）。**

三场之前的裸露 POC，意味着那是市场曾经重度认同、之后再没回访的价格。
**未被测试的价位倾向于吸引价格**，所以常把它们从产生它的那一场向前延伸出去，当作目标位盯着，
直到价格回来把它「填掉」，延伸才停止。**VAH / VAL 同理。**

### 它的局限

**如果你关心的那段结构不按场次切，VPSV 会把它劈成两个分布，结果两个都描述不好。**

## 五、VPVR：看多少算多少

**VPVR 只统计你屏幕上当前可见的那一段，滚动或缩放就重新计算。**

所以它是用来问这个问题的：**「在*这一段*行情里，成交量落在哪？」** —— 而「这一段」由你自己框。

**它最合适的场合**：

- **震荡行情** —— 轮廓会鼓出一个清晰的包，POC 和 VA 边缘成为市场反复测试的水平。
- **用眼睛框出一段结构** —— 放大到你关心的那个 swing、那段盘整、那一条趋势腿，
  轮廓就只描述那段结构，别的什么都不掺。这是任何固定周期的工具都做不到的。

### 它最大的弱点

**轮廓完全取决于你屏幕上显示了什么。**

> **两个交易者看同一个市场，缩放不同，会得到不同的 POC。**

**所以一条 VPVR 价位，只有连同「产生它的那个区间」一起说才有意义。**
「POC 在 64800」是没用的；「**从 63100 到 66200 这一段**的 POC 在 64800」才有用。

**这条规则对你自己也成立**：记笔记、跟人交流的时候，把框选范围一起写下来。

## 六、跟 TPO 到底差在哪

**这是最容易搞混的一节。**

### 差别只有一个：尺子量什么

| | TPO 轮廓 | 成交量轮廓 |
|---|---|---|
| **每一档记什么** | 市场在该价位**待了多少时间**（每 30 分钟一个字母） | 该价位**成交了多少量** |
| **回答的问题** | **哪里被接受了** | **哪里真正换手了** |
| **一眼看什么** | 形状、单印、尾巴、弱高低 | 包在哪里、POC 在哪、价值区多宽 |

**一句话**：**看结构用 TPO，看成本用成交量轮廓。**

### 但它们共用同一套骨架

**这点很重要，别被「两种东西」的说法带偏**：

**POC、价值区、VAH / VAL、单印、裸露延伸 —— 这些概念两边都成立。**

TPO 的 POC 是「时间最长的价位」，成交量轮廓的 POC 是「成交最多的价位」；
两者的价值区都用同一套「从 POC 向外生长到 70%」的算法。

**所以你不需要学两套语言。学一套骨架，换两种尺子。**

### 两者不一致时，故事就在分歧里

**它们经常一致。而当它们不一致时，那个分歧本身就在讲故事：**

| 现象 | 含义 |
|---|---|
| **成交量很大，但时间很少** | **大量生意在很短时间里做完** —— 一次激进成交，一次清算 |
| **时间很多，但成交量很小** | **市场乐意坐在那里，没有多少东西换手** |

### ⚠️ 最容易犯的错：拿两个 POC 对不上就说数据有问题

**TPO 的 POC 和成交量轮廓的 POC 经常不在同一个价位。**

**这不是矛盾，是正常结果** —— 一个问「待得最久」，一个问「换手最多」。
**如果它们总是一致，那才说明其中一把尺子是多余的。**

看到 POC 不一致时，正确的动作是**问「为什么在这里分歧」**，而不是去修数据。

## 七、本篇可执行动作

1. **先给自己的图定两把尺子**：一个 TPO 轮廓 + 一个 VPSV（日线）。两者都开 POC 与价值区。
2. **每天开盘前做一次逐场比较**：昨天到今天，价值是抬升、重叠还是迁移？POC 往哪漂？
3. **把裸露价位标出来**：前一日的 naked POC / naked VAH / naked VAL 延伸出去，当作参考位。
4. **要用 VPVR 时，先把框选范围写下来** —— 包括写给你自己看。没有范围的 VPVR 价位没有意义。
5. **遇到两个 POC 对不上，先当信息读，别当错误修。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **成交量轮廓（Volume Profile）** | 把成交量摊在价格轴上，看每个价位换手了多少 |
| **VPSV** | 成交量轮廓的**时段版** —— 每个交易时段一个独立轮廓，锚在日历上 |
| **VPVR** | 成交量轮廓的**可见范围版** —— 只统计屏幕上当前可见的一段，滚动就重算 |
| **档（Row）** | 价格被切成的等高区间，每笔成交归进它所在的那一档 |
| **POC（控制点）** | 最长的那一档 —— 该期间成交最密集、共识最强的价位 |
| **价值区（VA）** | 从 POC 向外生长、累计占总成交量 70% 的价格区间 |
| **VAH / VAL** | 价值区上沿 / 下沿，落在成交量用尽处，**通常不对称** |
| **开发中 POC（Developing POC）** | POC 在时段内一路迁移的轨迹，用来实时判断价值在往哪推 |
| **裸露价位（Naked / Virgin Level）** | 自诞生后再未被回访的 POC 或 VA 边缘，倾向吸引价格 |
| **档高（Row Size）** | 每档覆盖多少价格。档少平滑、档多精细但易噪 |

## 自测

> 覆盖「成交量轮廓」阶段。
> **答案默认折叠** —— 先自己想，再点开对答案。

**U5.1 三样东西的量法**

- ⚠️ **常见错误**：把 VPVR 和 VPSV 当成两个不同的指标去理解，其实它们量的是同一样东西。
- **自测**：VPSV 和 VPVR 都在统计成交量，它们的区别在哪？
- **答案**：**在「量哪一段」**。VPSV 锚在日历上（一场一个轮廓，滚动不变），
  VPVR 锚在你的视口上（滚动、缩放就重算）。

**U5.2 POC 与价值区**

- ⚠️ **常见错误**：以为 VAH / VAL 是 POC 上下对称的固定距离。
- **自测**：价值区往上伸得比往下远，说明什么？
- **答案**：**这个期间大部分生意是在上涨过程中做的。** 价值区是从 POC 向外按成交量生长出来的，
  落在成交量用尽处，所以不对称是常态，而且本身就是信息。

**U5.3 VPSV 的逐场比较**

- ⚠️ **常见错误**：只看当天轮廓，不跟前一天比 —— 那样就浪费了 VPSV 唯一的优势。
- **自测**：今天整个轮廓比昨天整体抬高了一截，这是趋势还是震荡？
- **答案**：**趋势。** 买方接受了昨天市场不接受的价格。反之若两场价值重叠，就是旋转行情。

**U5.4 VPVR 的框选范围**

- ⚠️ **常见错误**：直接说「VPVR 的 POC 在 64800」—— 这个数字脱离框选范围就没有意义。
- **自测**：别人给你一条 VPVR 价位，你该先问什么？
- **答案**：**「你框的是哪一段？」** 两个交易者缩放不同会得到不同的 POC，
  所以 VPVR 的价位必须和产生它的区间一起说。

**U5.5 TPO 与成交量轮廓的分歧**

- ⚠️ **常见错误**：发现两个 POC 对不上，就认为其中一个是错的。
- **自测**：某个价位成交量很大但停留时间很短，说明什么？
- **答案**：**大量生意在很短时间里做完了** —— 一次激进成交或一次清算。
  两个 POC 不一致是正常结果，不是数据错误；一致反而说明其中一把尺子多余。
