# 图鉴 08 · 实时清算流（Live Liquidation Feed）

> **这一篇讲什么**：实时清算流和清算柱的区别在哪、它多显示了什么、四条读法、五个局限。
> **配图**：无（原页概念区没有配图）。
> **来源**：译自 mmt.gg/learn/live-liquidations，已删除全部平台操作说明。

**一句话**：清算柱告诉你**发生了多少**，清算流告诉你**它是怎么发生的** —— 而且**在它还在发生的时候**。

---

## 一、实时清算流是怎么工作的

**当一笔杠杆仓位耗光保证金，交易所会平掉它。**

**那次平仓不是一次普通成交** —— 它是一张**必须成交的市价单**，在**任何能拿到的价位**，朝**仓位做错的那个方向**：

- **被强平的多头 → 被强制卖出**
- **被强平的空头 → 被强制买入**

（机制细节见 `26_图鉴_清算.md`。）

### 流是什么

**交易所会在清算发生时把它们公布出来。**

**清算流订阅这条事件流，每来一条就单独打一行** ——
**所以你盯着看的，是正在实时进入市场的强制流。**

### 和清算柱的唯一区别：时间

| | 清算柱（图表指标） | 实时清算流 |
|---|---|---|
| **呈现** | 把清算聚合成一根根柱子 | 每条清算**单独一行**，按到达顺序 |
| **你能看到的** | 这根柱子**总共**是多少 | 每一次清算**分别**是什么 |
| **时间性** | 柱子走完你才知道 | **它还在跑的时候你就看到了** |

**这个区别就是全部意义所在。**
**瀑布在几秒内就结束了 —— 而这几秒，是这条信息唯一还「可操作」的窗口。**

---

## 二、清算流多显示了什么

清算柱能给你总数，但**四个东西是总数里看不到的**：

### 1. 单个事件

**一根柱子写着 400 万，只告诉了你总额。**

**流会告诉你那到底是 1 笔仓位，还是 400 笔仓位** ——
**这是两种不同的处境，后果也完全不同。**

### 2. 顺序

**是大额平仓先来、把小额拖着走？还是小额先跑、大额在最后才投降？**

**这写在行的到达顺序里，而它在任何总额里都是看不见的。**

### 3. 节奏

**每几秒来一条清算** = 市场在慢慢磨掉弱仓位。
**同一秒里来五十条** = 瀑布。

**这两种情况可以落进同一根柱子里。**

### 4. 它先发生

**瀑布在几秒内就结束了。**
**流在它还在跑的时候就把它显示出来 —— 而那是这条信息唯一还有用的时刻。**

---

## 三、怎么读清算流

### 看爆发，不看单行

**在任何杠杆市场里，零星的清算都是恒定的背景噪音。**

**真正有意义的是速率突然改变的那一刻。**

### 注意是哪一边在被清

| 现象 | 含义 |
|---|---|
| **连续的多头清算** | **强制卖出**，把价格往下推 |
| **连续的空头清算** | **强制买入**，把价格往上推 |
| **一次行情中途流从一边翻到另一边** | 通常标记这波行情**已经耗尽了自己** |

### 给参与者估个量级

- **由许多小额平仓组成的爆发** = **散户杠杆被冲掉**
- **爆发里夹着几笔极大的** = **有分量的参与者被抬出去了** ——
  **这类通常标记的是行情的极值，而不是行情的中间**

### 盯住尾部

**当拥挤的仓位被清完，瀑布就结束了** —— **而流会直接把这件事显示出来：速率崩回背景水平。**

**那一刻往往就是反转点，因为强制性的供给已经用光了。**

### 和价位对照

**一批平仓出现在你本来就在盯着的价位上，说明那个价位确实做了什么。**

**和清算热力图对照，你能看出那个价位上「预计的燃料」到底烧掉了没有。**

## 四、清算流的局限

| 局限 | 说明 |
|---|---|
| **上报不统一** | 各交易所公布清算的方式不同，有些会**节流或批量**上报。**所以流是「有代表性的画面」，不是「完整的普查」** |
| **它要求你全神贯注** | 和任何实时数据流一样，**你只有在看着它的时候它才在告诉你东西**。瀑布那几秒你走开了，最关键的部分就错过了 |
| **它没有形状** | **一列文字不携带任何你能扫一眼的历史**。要看清算随时间落在价格的哪些位置，需要清算柱指标 |
| **大小 ≠ 重要性** | **在薄市场里的一笔大平仓，比在深市场里大得多的平仓推价推得更远**。**单看数字本身说明不了冲击有多大** |
| **它按定义就是向后看的** | **每一行都是「已经被强制」的东西**。要看**还有哪些平仓在等着发生**，请用清算热力图 |

> **一句话记法**：**清算柱 = 统计；清算流 = 直播。**
> **统计用来复盘和定位置，直播用来抓那几秒。**

### 本篇需要关注的术语

| 术语 | 一句话 |
|---|---|
| **实时清算流（Live Liquidation Feed）** | 把每条清算单独、按到达顺序实时打印出来的数据流 |
| **爆发（Burst）** | 清算速率在短时间内突然跳升 |
| **背景噪音（Background Noise）** | 杠杆市场里恒定的零星清算，无信息量 |
| **尾部（Tail）** | 瀑布末尾速率崩回背景水平的那一刻，常对应反转 |
| **节流 / 批量上报（Throttling / Batching）** | 交易所不逐条公布，而是合并或延迟发布 |
