# 交易论点

> **性质**：这是**我自己的交易总结** —— 个人经验，**不一定正确**。
> 它不是教材、不是定论，也不构成任何建议。
> 目标只是**逻辑自洽**：每条能说清来源，内部不互相打架。

**两条边界先划清楚**：

1. **不含执行层。** 止损放哪、仓位多大、什么时点进场 —— **每个人做法不一样**，
   写进来只会误导。这一章只讲**判断**，不讲**参数**。
2. **拍卖的判断部分不严谨。** 下面讲到的足迹图**只是其中一个判据**；
   真正的判断要**综合其他衍生品数据**。这一章**不做赘述** —— 情况太多，穷举不了。

## 一、定义

### 1.1 定义 0 · 价格向【尚未被消耗的】流动性高地运动

**方向 = 流动性的梯度，不是绝对存量。**

价格不是「被某个大池子吸过去」，而是**沿着流动性从低到高的梯度走**。
所以「哪里流动性多」不够，还要看**哪边还没被消耗**。

↳ 推论：**一个池子被吃掉之后，它对价格的引力就消失了** ——
价格会去找**下一个**还没被消耗的池子。

### 1.2 定义 1 · 共识密度 = Volume Profile

**所有位置都是买出来的，不是算出来的。**

成交量是**已经成交的事实** —— 不是挂单、不是指标算出来的数。所以它比盘口深度**硬**
（挂单可以撤、可以假挂，成交不会）。

**Volume Profile 的用途：只是让你知道哪里是 LVN。**

| | 共识 | 价格的行为 | 是不是「重要位置」 |
|---|---|---|---|
| **HVN**（高成交量节点） | **高共识** | 被接受 → **停留**（= 箱体） | ❌ **不是** —— 它是**参照系** |
| **LVN**（低成交量节点） | **低共识** | 被拒绝 → **快速穿过** | ✅ **是** |

⚠️ 这里最容易搞反：**HVN 是价格停留的地方（箱体），不是你要操作的地方。你要找的是 LVN。**

**箱体 = IB = HVN：同一个东西，只是位置不一样。**

**箱体、IB、HVN 都是一回事** —— 都是「价格被接受、稳定下来的那段区间」。
差别只在**位置**（哪一段、什么尺度）。

| 箱体来源 | 尺度 / 性质 |
|---|---|
| **IB** | 开盘一小时 |
| **TPO / 结构** | 日内相对稳定的区间 |
| **HVN** | Volume Profile 上的高成交区 |
| **VWAP ±1** | **随价格移动的箱体** |

→ **所以「脱离」永远有参照物** —— 找不到 IB 也能用 VWAP ±1，反之亦然。

**⚠️ 不要把它和足迹图混在一起。**
**Volume Profile 和足迹图没有关系。** Volume Profile 只是让你知道**哪里是 LVN**。

- 问「**哪里有低共识区**」→ **Volume Profile**
- 问「**消耗成不成功**」→ **足迹图**

### 1.3 定义 2 · 脱离

**横盘是怎么来的**：上下方都存在流动性池 → 价格被两边拉扯 → **混沌（横盘）**。

横盘不是「没行情」，是**两边都有引力、互相抵消**。
↳ 用 Volume Profile 说：**横盘 = 价格停在 HVN 区**（= 箱体 = 稳定结构）。

**拍卖发生的定义：向上或向下脱离箱体 = 拍卖发生。**

脱离意味着**某一方的池子被吃掉了** → 价格会走向**下一个**流动性池。
↳ 脱离 = **离开 HVN、进入 LVN**。

**⚠️ 最关键的一句：不能用几根 K 线量化。**

- 走 2 根脱离，是脱离；走 10 根才脱离，也是脱离。
- 一旦引入「几根」，就变成**量**的判断；脱离是**质**的判断。
- **也不必先算清箱体多大** —— 重要的是**有没有离开它**。

### 1.4 口径 · 只看范围，位置是【带】不是【线】

- **所有的位置都是一个带，不是一个价位。** VWAP 的 ±1 / ±2 / ±3 也是带。
- 不需要知道挂单的确切位置 —— 它对价格的影响本来就是一个范围。
- 带与带之间可以重叠、可以有长尾 —— 不影响判断，因为判断看的是**脱离**。

## 二、核心论点

### 2.1 拍卖的广义定义 —— 位置是定义的一部分

| 尺度 | 说法 |
|---|---|
| 大范围（IB 级） | 拍卖 = 突破 IB 后的反应 |
| **广义（通用）** | **只要对流动性池进行消化，就算拍卖启动** |

因为 **IB 也只是箱体的一种**，「大范围口径」是**广义定义在 IB 尺度上的特例**，
不是另一套定义。

**操作后果**：不再问「这是哪一档拍卖」，改问
「**这里有没有池子正在被消化？消化到什么程度？**」

### 2.2 脱离箱体 = 拍卖发生；成功延续，失败反转

**前提：先有「稳定结构被打破」这个过程。** 没有这个前提，就还没有拍卖。

| 努力 | 有没有结果 | 拍卖 | 动作 |
|---|---|---|---|
| 一次大失衡 / 一次发起 | **有结果**（脱离了） | 成功 | **顺着做**（趋势延续） |
| 一次大失衡 / 一次发起 | **没结果**（回到箱内） | 失败 | **反向做**（反转） |

**三条边界**：

1. **不局限在 IB 里面。** 脱离是**通用判据** —— 因为箱体不止 IB 一种。
2. **不能用几根 K 线量化。**
3. **判据是「努力有没有结果」**，不是「努力与结果是否匹配」——
   后者会引入阈值，前者不会。

**这条同时就是进场逻辑**：努力没结果 → 反向做。

### 2.3 位置决定这单能赚 / 亏多少钱

**拍卖发生的位置，决定了这单能赚/亏多少钱。**

- **位置 → 到目标的距离 → 盈亏的幅度。**
- 同一套逻辑（拍卖失败 → 反向），在**不同位置**做，盈亏的**数量级完全不同**。
- **逻辑失败也发生在某个位置** —— 你要能说出「价格到了哪里，我的假设就不成立了」。

↳ **进场位置的选择，比「拍卖有没有发生」更重要。**

### 2.4 什么算「重要位置」，以及【共振】

**重要位置有三类**：

| 重要位置 | 为什么 |
|---|---|
| **LVN**（低成交量节点） | 低共识 → 价格在这里**快速穿过**（趋势发生的地方） |
| **VWAP ±2 / ±3** | 那里已经是**市场对价值偏移程度容忍度最高**的位置 → 再往外愿意接的人就没了 |
| **箱体边界**（IB / TPO / HVN / VWAP ±1 被脱离的那条边） | **稳定结构被打破**的地方 |

**⚠️ VWAP ±1 不算 —— 因为 VWAP ±1 就是一个稳定的箱体。**

```
VWAP ────────  价值中枢
 ±1  ────────  箱体边界 ← 稳定结构；里面是停留区，不是重要位置
 ±2  ────────  重要位置
 ±3  ────────  重要位置（容忍度极限）
```

**于是「箱体」和「重要位置」的关系被钉死了**：

- **箱体（= IB = HVN = VWAP ±1）= 参照系**，用来判「有没有脱离」。
- **重要位置在箱体之外** —— **箱体里面没有重要位置。**

#### 共振：判断「证据够不够强」的唯一方法

**不要问「多个箱体冲突时听谁的」—— 要看它们有没有【共振】。**

**例子**：脱离了 IB，**但没到 VWAP +1**。
问：**这个位置是不是和 LVN 重叠？**

- **重叠 → 共振 → 证据强 → 可以做**
- **不重叠 → 没有共振 → 不要做**（进场证据不够强）

#### ★ 共振为什么有意义：它在指认「真正的流动性池」

> **多个指标给出的位置重叠在同一处 —— 说明那里存在一个真正的流动性池。**
> **原因：这个位置代表了资金的共识。**

**一个指标指向某处，可能只是那个指标的口径造成的；**
**多个来源不同的指标同时指向同一处，那就不可能是巧合** ——
**是几股不同的钱，在同一个价位做了同一件事。**

**⚠️ 于是「怎么数」就有一条硬规则：**

> **共振数的是【机制】，不是【位置】。**
> **同一个机制推导出来的多个位置，只算一次。**

**例**：IB 上沿、VWAP ±1、当日 HVN 边界 ——
如果它们**本质上是同一个箱体的三个说法**，那么
**那是「一个位置」出现在三个地方，不是「三个位置共振」。**

**只有来源不同的机制落在同一处才算共振** ——
例如「VWAP ±2σ 的偏离带」+「一个 LVN」+「一个周线级别的旧价值区边缘」：
**三者来源不同、重叠在同一处，那才是一个真正的流动性池。**

**共振的五条规则**：

| # | 内容 |
|---|---|
| **1** | **多个重要位置落在同一价位区 = 共振 = 证据强** |
| **2** | **只有一个重要位置 = 证据不够强 = 不做** |
| **3** | **层级越高，强度越高** —— 高时间框架的 LVN / VWAP **强于**低时间框架的（**高时间框架 = 周 / 月**） |
| **4** | **不同层级之间也会打架**（和箱体一样）→ 冲突时**同样看共振** |
| **5** | ⚠️ **共振数的是【机制】，不是【位置】** —— **同一机制推导出的多个位置只计一次**（见上） |

→ 所以「听谁的」这个问题本身就是错的：**不是选一个，是数有几个来源不同的东西指向同一处。**

### 2.5 消耗状态 = 足迹图状态

**「消耗」不是从 Volume Profile 读的，是从足迹图读的。**

**消耗正常**（拍卖成功，价格被推走）：

| 方向 | 足迹图特征 | 含义 |
|---|---|---|
| 上涨 | **交易量失衡气泡在 K 线顶部** | 主动资金更愿意在**高位**成交 = **要把价格推上去** |
| 下跌 | 失衡气泡在 K 线**底部** | 主动卖在低位成交 = 要推下去（同理） |

**消耗失败**：

| 方向 | 表现 |
|---|---|
| 上涨 | **长上影线**（推上去，被卖回来） |
| 下跌 | 长下影线（同理） |

**⚠️ 但真正反转需要确认信号 —— 通常是 delta 反转。**

↳ 所以「长影线」只是**消耗失败的表现**，不是反转的判据。
  **反转要等 delta 反转确认。**

### 2.6 证据由足迹图说了算

**真正的证据是足迹图，不是 K 线。**

| ❌ 不是证据 | ✅ 是证据 |
|---|---|
| 走了几根 K 线 | **逐价位的主动买卖** |
| K 线形态（吞没 / 放量） | **失衡气泡的位置**（顶部 / 底部） |
| 收盘价突破 | **delta 方向**（有没有反转） |

↳ **「脱离」的确认必须回到足迹上** —— 是不是真的有一方把另一方的单子吃掉了。

**⚠️ 不严谨声明**：**足迹图只是其中一个判据，不是全部。**
真正的判断要**综合其他衍生品数据**（未平仓合约、资金费率、清算、订单簿深度、
多空比、吃单量等，见理论 `12_衍生品数据_上_OT_CVD_Funding_Depth.md` 与
`13_衍生品数据_下_清算_Delta_多空比_Taker.md`）。

**这一章不做赘述** —— 情况太多，穷举不了。
**别把「足迹图看懂了」当成「会判断了」，这两件事差得很远。**

### 2.7 IB 只是一个箱体范围

**IB 大部分时间包含的信息是有限的** —— 它给你**一个箱体范围**，不给方向、不给触发。
**某些情况下**它会有明显的趋势指向，但那是少数。

**反证**：IB 成形时刻**晚于**开盘后第一段的交易窗口 →
**把 IB 当信号，那段行情做不出来。**

#### 「宽 IB = 波动」—— 理论没错，错在「宽」没有定义

**书里的理论没问题：宽 IB = 今天有大范围。但「宽 IB」怎么定义？**

**我的答案：看这个 IB 跟其他关键位是否重叠 / 共振，才能有结论。**

| | |
|---|---|
| **与其他关键位重叠 / 共振** | 这个范围**有意义** → 可以由此下结论 |
| **不重叠** | 只是**一个范围** —— **不构成结论** |

→ **「宽」不是一个自己能量出来的刻度，是一个关系判断。**
  （和共振同一条规则：**不是量出来的，是数出来的。**）

### 2.8 止盈跟止损一样需要证伪

**止损本身就是一次证伪**（价格到了 → 假设错了）。
说「止盈也要」，等于**不承认「到目标价就平」是默认动作** ——
**平仓也必须由一次证伪触发。**

↳ **出场侧的证伪条件必须与进场侧同等对待、当场写。**

## 三、导出论点

### 3.1 流动性池是【有弹性的区间】

同一个池子，反应点有三种可能：**在上沿 / 在下沿 / 不反弹直接过去**。

**为什么最厚处反而可能是反应点**：最厚的地方是**公共信息** →
别人也在看 → 别人抢先买入 → **最厚处反而更可能成为反弹点**。

↳ 与「技术分析为什么有用」的**反身层**同源：形态自我实现，依赖「看的人足够多」。

⚠️ **取证要求**：验证这个机制必须**在进场当时**截池子图。
事后快照无法区分「最厚处吸引了买入」和「买入的成交堆成了最厚处」——**因果方向不可辨**。

### 3.2 结构位的【消耗状态】决定它能不能当止损位

| 状态 | 含义 | 用法 |
|---|---|---|
| **未消耗** | 该位的努力还没换来结果 | **是反应点** → 不要把止损贴在上面 |
| **已消耗** | 该位的努力已经换来结果（价格照失衡方向走了） | **返回概率低** → 可以放止损 |

**判据**：**看足迹图** —— 该价位出现失衡后，**价格是否照失衡方向走了**（走了 = 已消耗）。

↳ 与定义 0 一致：已消耗 = 引力已消失。

### 3.3 进出场同构

| 侧 | 押注 | 证伪条件 | 当时写了吗 |
|---|---|---|---|
| 进场 | 拍卖失败 → 价格朝某方向 | 在该位**重新发起拍卖** | ✅ |
| 出场 | 会击穿该池子 → 到目标 | 在池内反应、没击穿 | ❌（假设本身明确，就没写） |

→ **道理是对称的，执行上不对称。**
→ **补法**：出场侧也当场写证伪条件。
→ 判断不了的部分由**机械规则兜底**：**能当场判断的用判断，判断不了的用机械规则。**
  （具体参数属执行层 —— **各人做法不同，这一章不列**。）

### 3.4 失效条件是【逻辑的】，不是价格的

| 锚法 | 形态 |
|---|---|
| **区间相对** | 价格**迅速脱离**该区间（且不收回） |
| **结构位相对** | 在该结构位**重新发起拍卖** |

→ 逻辑失效条件与「机械止损」是**两个独立的东西**，**两个都要用**。

**被损 ≠ 逻辑错。** 止损被打掉只说明**价格到了那里**，**不等于假设被证伪**。
证伪是逻辑的事，止损是风控的事 —— **两者独立**。

### 3.5 拍卖的流程

**拍卖发起 → 判失败 → 在回抽处进场。**
（进场晚于判失败，中间有一段回抽。）

### 3.6 止盈依据 =【具名结构】

止盈落在**具体的结构对象**上：
**裸 POC**（未被测试过的磁铁）/ **挂单密集区** / **流动性池** / **价值区边界**。

↳ 那些都是**高共识位**，也就是**价格的目标**。

### 3.7 末端特例：吃穿 = 反转

**趋势末端的脉冲要真的吃穿流动性池，反转才成立。**

**这不是与「有结果 = 延续」矛盾，而是它在「末端位置」上的特例** ——
因为「有结果」的定义**依赖位置**：

| 位置 | 吃穿池子意味着 | 动作 |
|---|---|---|
| **普通位置** | 池子被消化，**后面还有下一个池子** | **延续** |
| **末端位置** | **最后的池子被消化，后面没有了** | **反转** |

↳ 由定义 0 解释：价格找的是「**尚未被消耗的**」池子。末端吃穿后**没有下一个池子**，引力反向。

**怎么知道是末端**：**切换到高时间框架就可以知道**（**周 / 月**）。
末端不是从当前周期看出来的，是从高时间框架看出来的。

**所以「吃穿」本身不是信号，要问「后面还有没有池子」。**

### 3.8 吸收 ≠ 反转

出现吸收只说明**有人在那个价位接**，**不等于价格会反转**。
吸收是「有对手盘」，不是「方向要变」。

↳ 与 2.5 一致：**真正反转需要确认信号（delta 反转）** —— 吸收只是对手盘出现了。

## 四、边界：这一章不写什么

| 不写 | 为什么 |
|---|---|
| **执行层**（止损参数 / 仓位 / 进场时点 / 记录格式） | **每个人做法不一样**，写进来只会误导 |
| **足迹图 / 衍生品数据的具体读法** | 情况太多，穷举不了。**实战是最好的老师** |
| **「怎么把位置和判据合成一次下单」** | 这一章只管**位置在哪**；**怎么判**要用足迹图 + 其他衍生品数据 |

> **关于最后一条**：这一章的职责是**把位置说清楚**。
> 具体怎么判断，要靠**足迹图数据 + 其他衍生品数据** ——
> 这也是为什么**衍生品数据**会出现在这套体系里：它**不是偏题**，
> 它是**拍卖成败判断的组成部分**。

| 2 | 池子快照必须在进场当时截 | 硬性要求 |
| 3 | 已消耗位 vs 未消耗位的被打率差 | 待累积（需要对照组） |
| 4 | 押「击穿池子」的胜率 | 待累积 |

**没有「待确认」的结构问题了，剩下的都是「待累积」。**

## 六、一页速查

```
定义 0  价格向【尚未被消耗的】流动性高地运动（方向 = 梯度）
  │
  ├─ 定义 1  共识密度 = Volume Profile（钱买出来的）
  │            └─ 用途：只是让你知道【哪里是 LVN】
  │               HVN = 价格停留 = 箱体（参照系，不是重要位置）
  │               箱体 = IB = HVN = VWAP ±1（同一个东西，只是位置不一样）
  │
  ├─ 定义 2  脱离：横盘 = 停在 HVN → 混沌
  │            【脱离箱体】= 拍卖发生 = 离开 HVN、进入 LVN
  │            ❌ 不用几根 K 线量化；❌ 不必先算箱体多大
  │
  └─ 口径    只看范围；【位置是带不是线】
     │
核心 1（2.1–2.6）  拍卖 = 对流动性池的消化；【位置是定义的一部分】
  │      脱离 → 成功延续 / 失败反转（前提：稳定结构先被打破）
  │      位置 → 决定这单能赚/亏多少 + 逻辑失败在什么位置
  │      【重要位置 = LVN、VWAP ±2 / ±3、箱体边界】
  │      ★★【共振】= 判断「证据够不够强」的唯一方法
  │         多个重要位置落同一处 = 证据强 → 做
  │         只有一个 = 证据不够强 → 不做
  │         高时间框架强度 > 低时间框架（HTF = 周 / 月）
  │      【分工】这一章只管「位置在哪」；
  │         具体怎么判 = 足迹图 + 衍生品数据（⚠️ 不严谨，情况太多）
  │
  ├─ 导出 1  池子有弹性（最厚处也可能是反应点）
  ├─ 导出 2  消耗状态 → 决定能不能当止损位
  ├─ 导出 3  进出场同构 → 出场侧也要证伪
  ├─ 导出 4  失效条件是逻辑的（被损 ≠ 逻辑错）
  ├─ 导出 5  流程：发起 → 判失败 → 回抽进场
  ├─ 导出 6  止盈 = 具名结构
  ├─ 导出 7  末端特例：吃穿 = 反转（末端 = 切 HTF 判，HTF = 周 / 月）
  └─ 导出 8  吸收 ≠ 反转
  │
核心 2（2.7）  IB = 一个箱体范围（与核心 1 本质相同，不是独立的一条）
  │      「宽 IB = 波动」理论对 → 但「宽」靠【是否与其他关键位重叠 / 共振】定义
核心 3（2.8）  止盈跟止损一样【需要证伪】
  │
执行层  ★ 不写进本章（各人做法不同）
```

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **流动性梯度** | 价格朝「尚未被消耗的」流动性高地运动，看的是方向不是存量 |
| **共识密度** | 用成交量衡量的「多少人认可这个价位」；Volume Profile 就是它 |
| **HVN（高成交量节点）** | 高共识 → 价格停留 → 就是箱体。**参照系，不是重要位置** |
| **LVN（低成交量节点）** | 低共识 → 价格快速穿过 → **这才是重要位置** |
| **箱体** | 价格被接受、稳定下来的区间。**IB / HVN / VWAP ±1 都是它** |
| **IB（初始平衡）** | 开盘一小时形成的箱体。只是一个初始作战地图，大部分时间信息有限 |
| **脱离** | 离开箱体 = 拍卖发生。**是质变，不能用几根 K 线量化** |
| **拍卖成功 / 失败** | 努力有没有结果：脱离了 = 成功（延续）；回到箱内 = 失败（反转） |
| **重要位置** | LVN、VWAP ±2 / ±3、箱体边界。**VWAP ±1 不算**（它本身就是箱体） |
| **共振** | 多个重要位置落在同一价位区 = 证据强。**只有一个就不做** |
| **消耗状态** | 该位的努力有没有换来结果。**看足迹图判**，不看 Volume Profile |
| **失衡气泡** | 足迹图里单边成交占绝对优势的价位；出现在 K 线顶部/底部 = 消耗正常 |
| **吸收（Absorption）** | 主动单很猛但价格不动。**只是有对手盘，不等于反转** |
| **delta 反转** | 主动买卖方向翻转。**真正反转需要的确认信号** |
| **裸 POC** | 未被测试过的控制点，像磁铁一样吸引价格 |
| **高时间框架（HTF）** | 这一章指**周 / 月**。判断末端、比较强度都用它 |
