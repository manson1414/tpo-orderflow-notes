# 01 · 市场轮廓基础

**目标**：读完能看懂一张 TPO 图上的每一个元素。

---

## 1. 底层逻辑：正态分布

正态分布是一条钟形曲线，描述数据点如何分布：大多数数值聚集在均值附近（峰顶），向两侧对称衰减形成"尾部"。

**在 Market Profile 里的含义**：
- **平衡区** = 多数成交发生的地方（钟形曲线的肚子）
- **不平衡区** = 极端位置（尾部）
- 标准差衡量数据偏离均值的程度：约 **68%** 的数据落在均值 ±1 个标准差内 → 这个概念直接对应"价值区间（VA）"

> **核心心智模型**：市场渴望钟形曲线。偏离钟形曲线的形态（缺口、单印、粗糙地形）= 低效率 = 迟早被回访修正。

---

## 2. TPO（时间-价格机会）

- 每一个 TPO（字母 A、B、C…）代表**一个时间单位**（通常 30 分钟）
- 表示在那个时间段里，市场曾在某个价格档位发生交易
- 价格在不同时间再次回到同一价位 → 该价位**新增一个字母**

**关键**：把它称为"足迹（footprint）"是理解它的关键。你要做的是沿着价格走过的路径去**追踪足迹**。

**举例**：A 时段（开盘后前 30 分钟）价格从 110,900 走到 110,700；B 时段价格从 110,600 走到 110,500；然后又回到开盘价 110,900……以此类推。

> 把 TPO 图旋转一下，会发现它和钟形曲线非常像。

---

## 3. X 轴 / Y 轴 与 Profile

先回忆 K 线图怎么工作，**然后暂时把它忘掉**。

| | K 线图 | TPO 图 |
|---|---|---|
| X 轴 | 时间 | **某价格被交易的频次** |
| Y 轴 | 价格 | 价格 **+ 时间信息** |

- 每一个 TPO Profile 对应一个"交易时段（session）"：可以是一整天、某个市场时段，或一小时
- 开盘与收盘标记也显示在 Y 轴上
- **X 轴上足迹越多 = 该价位成交活动越多**
- 区间中央的价格档位会有更多足迹（价格更频繁地在该处穿梭）

> 简化处理：这里暂时不考虑最小跳动单位（tick size）。

---

## 4. 价值区间（VA）

**VA 本质上就是均值 ±1 个标准差的范围。**

| 元素 | 占比 |
|---|---|
| **VA**（Value Area，价值区间） | 70% |
| **VAH**（Value Area High，上沿） | 15% |
| **VAL**（Value Area Low，下沿） | 15% |

---

## 5. 控制点（POC）

- **POC = 成交活动最密集的价位**。用钟形曲线比喻，它就是"均值"所在的位置
- 在价格轴上以一条水平线标出，Profile 里对应一条带状区域
- **POC 经常像磁铁一样吸引价格**，可能在后续时段充当潜在支撑或阻力
- 因为这是市场基于成交量找到的"最公平价格"，交易者重点关注它——用来做**旋转（rotation）**或**突破（breakout）**的参考

---

## 6. 初始平衡（IB）

- **IB = 前 2 个时段的价格区间**（一般 2×30 分钟，共 1 小时），即 A + B 两个时段
- 在 Profile 左侧以一条竖向带标出
- **作用**：为当日定调，显示买方或卖方早期的"信念/决心"
- **IB 很宽** → 后续波动可能更大；**IB 很窄** → 可能盘整
- 是判断日内方向的**关键参考**（后续所有"拍卖"策略都基于 IB）

---

## 7. 单印（Single Prints）

- Profile 里某些价位**只出现一个 TPO**（只有一个字母）
- 说明市场快速穿过该区域，几乎没有回头反复交易
- **提示"不平衡区域"**：例如快速的买压或卖压
- 价格以后回到这些区域时，**可能成为未来的支撑/阻力**


---

## 8. 弱高点 / 弱低点（Poor Highs / Poor Lows）

- Profile **顶部或底部结构收敛结束**，但**没有形成"尾巴（tail）"，也没有形成厚实的成交堆积**
- 含义：买方（在高点）或卖方（在低点）的**决心不够强**
- **经常暗示潜在的反转或失败的突破**——因为市场并没有"接受"这些极端价位

> 纽约时段的一个弱低点。注意后续时段把这个弱低点扫掉了。
> **→ 弱低点会被扫掉，这是常态，不是例外。**（策略部分「弱高/弱低扫掠」即基于此）

---

## 9. 峰度（Kurtosis）与"尾巴"

峰度衡量分布**尾巴的厚度**。

| 峰度 | 特征 | 对应行情 |
|---|---|---|
| **高峰度** | 尾巴更肥、极端价格波动更多、峰值更尖锐 | 更波动 / 更趋势化的时段 |
| **低峰度** | 尾巴更薄、轮廓更扁平 | 更平衡 / 区间震荡的时段 |

Profile 里的"尾巴"代表价格曾经延伸过去、但**没能停留**的离群区域，往往揭示市场的**拒绝点（rejection points）**。

---

## 10. 买入尾 / 卖出尾（Buying / Selling Tails）

- 是 Profile **底部（买入尾）**或**顶部（卖出尾）**的**单印延伸**
- **买入尾**：低位有激进买盘介入、拒绝更低的价格 → 常暗示潜在**向上反转**
- **卖出尾**：高位卖方压倒买方把价格压下去 → 可能暗示**下跌延续**

> **实操阈值**：为了让尾巴"更有意义"，**至少要有 2 个单印**。
>
> 伦敦时段的卖出尾 → 卖压非常强形成不平衡 → 随后形成弱低点（进一步确认）→ 下一个时段回测了卖出尾所在的价位。

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **TPO（Time Price Opportunity）** | 时间-价格机会：某时段在某价位成交过，就记一个字母 |
| **时段（Period）** | 时间单位，通常 30 分钟，按 A、B、C… 命名 |
| **Profile（轮廓）** | 一天里所有时段叠加出来的横向分布图 |
| **VA / VAH / VAL** | 价值区及其上沿 / 下沿，标准切分为 70% / 15% / 15% |
| **POC** | 柱子最长的那一行，成交最密集的价位 |
| **IB / IBH / IBL** | 初始平衡（开盘后前两个时段）及其上下沿 |
| **单印（Single Print）** | 只有一个字母的价位，属于低效率区 |
| **买入尾 / 卖出尾** | 底部 / 顶部的单印延伸，至少要有 2 个单印 |
| **弱高 / 弱低（Poor High / Low）** | 收敛结束、没有尾巴的顶部 / 底部，容易被扫掉 |
| **HVN / LVN** | 高成交量节点（价格停留）/ 低成交量节点（价格加速） |
| **分布（Distribution）** | 单 / 双 / 三重，代表当天换了几个价值区 |
