# 市场轮廓基础

**目标**：读完能看懂一张 TPO 图上的每一个元素。

---

## 1. 底层逻辑：正态分布

正态分布是一条钟形曲线，描述数据点如何分布：大多数数值聚集在均值附近（峰顶），向两侧对称衰减形成"尾部"。

**在 Market Profile 里的含义**：

- **平衡区** = 多数成交发生的地方（钟形曲线的肚子）
- **不平衡区** = 极端位置（尾部）
- 标准差衡量数据偏离均值的程度：约 **68%** 的数据落在均值 ±1 个标准差内 → 这个概念直接对应"价值区间（VA）"

> **核心心智模型**：市场渴望钟形曲线。偏离钟形曲线的形态（缺口、单印、粗糙地形）= 低效率 = 迟早被回访修正。

### 真实轮廓长什么样

[[img:tpo-hero]]

**它和 K 线图最关键的区别**：**K 线记录价格「去过哪里」，但不记录它「在那里待了多久」。**
轮廓把时间显性化，于是「接受」与「拒绝」才第一次变得可见：

- **在一个价位逗留的市场，接受了它**
- **立刻离开的市场，拒绝了它**

> 这套方法由 J. Peter Steidlmayer 在 1980 年代的芝加哥期货交易所（CBOT）发展出来。
> 它产生的结构 —— 控制点、价值区间、初始平衡 —— 至今仍是拍卖市场理论的标准词汇。

## 2. TPO（时间-价格机会）

- 每一个 TPO（字母 A、B、C…）代表**一个时间单位**（通常 30 分钟）
- 表示在那个时间段里，市场曾在某个价格档位发生交易
- 价格在不同时间再次回到同一价位 → 该价位**新增一个字母**

**关键**：把它称为"足迹（footprint）"是理解它的关键。你要做的是沿着价格走过的路径去**追踪足迹**。

**举例**：A 时段（开盘后前 30 分钟）价格从 110,900 走到 110,700；B 时段价格从 110,600 走到 110,500；然后又回到开盘价 110,900……以此类推。

> 把 TPO 图旋转一下，会发现它和钟形曲线非常像。

### 时段字母是怎么分配到价格档上的

**每个时段用一个字母标识**，这就是为什么印在纸上的轮廓**看起来像一页堆起来的字母**。

**字母不是装饰：它们告诉你某个价位是在时段中的「什么时候」被成交的** ——
**而这是让你能把轮廓读成一个故事、而不是一个静态形状的东西。**

## 3. X 轴 / Y 轴 与 Profile

先回忆 K 线图怎么工作，**然后暂时把它忘掉**。

| | K 线图 | TPO 图 |
|---|---|---|
| X 轴 | 时间 | **某价格被交易的频次** |
| Y 轴 | 价格 | 价格 **+ 时间信息** |

- 每一个 TPO Profile 对应一个"交易时段（session）"：可以是一整天、某个市场时段，或一小时
- 开盘与收盘标记也显示在 Y 轴上
- **X 轴上足迹越多 = 该价位成交活动越多**
- 区间中央的价格档位会有更多足迹（价格更频繁地在该处穿梭）

> 简化处理：这里暂时不考虑最小跳动单位（tick size）。

### 轮廓是怎么逐时段长出来的

**时段被切成等长的时间块。在每个块里，市场成交过的每一个价位都被记录并分配一个块** ——
**所以单个时段会产生一条覆盖该时段范围的竖直长条：市场动得越多，这条越长。**

**然后每个新时段的块被向左推挤，在每个价位上填入第一个空列：**
**被很多时段成交过的价位累积成长行；只被一个时段成交过的价位，就只有一个块那么宽。**

[[img:tpo-formation]]

**形状本身就是工具的意义：**

| 形状 | 含义 |
|---|---|
| **肥厚、对称** | 市场整段在围绕一个共识价格旋转 —— **平衡（balance）** |
| **瘦长、鼓包偏一端** | 市场整段都在往某个方向走 —— **失衡（imbalance）** |

## 4. 价值区间（VA）

**VA 本质上就是均值 ±1 个标准差的范围。**

| 元素 | 占比 |
|---|---|
| **VA**（Value Area，价值区间） | 70% |
| **VAH**（Value Area High，上沿） | 15% |
| **VAL**（Value Area Low，下沿） | 15% |

### 它具体是怎么算出来的

**从 POC 向外扩张**：比较紧邻的**上一行**和**下一行**，**把较大的那一行加进来**，重复这个过程，直到累计达到目标百分比（70%）。

**这个算法值得记住，因为它解释了 VA 的形状为什么总是不对称** ——
**它扩张的方向由每一行的实际长度决定，不由几何对称决定。**

### 边缘比中间重要

**VA 是市场做掉大部分生意的地方，但真正有用的是它的边缘。**

| 现象 | 含义 |
|---|---|
| **价格被接回前一个 VA 之内** | 市场**重新认同了那个估值** |
| **价格在 VAH 或 VAL 被拒绝** | 市场**不认同** |

## 5. 控制点（POC）

- **POC = 成交活动最密集的价位**。用钟形曲线比喻，它就是"均值"所在的位置
- 在价格轴上以一条水平线标出，Profile 里对应一条带状区域
- **POC 经常像磁铁一样吸引价格**，可能在后续时段充当潜在支撑或阻力
- 因为这是市场基于成交量找到的"最公平价格"，交易者重点关注它——用来做**旋转（rotation）**或**突破（breakout）**的参考

### 并列最长时怎么取

**并列最长时用位置裁决：取最靠近该时段高低点中点的那一行。**

**这个规则的存在本身就说明一件事：POC 的定义是「时间最长的价位」，当时间并列时，才退而用位置来裁决。**

### 回到前一个时段的 POC 意味着什么

**当价格回到前一个时段的 POC，它是在回到一个被大量接受的水平** ——
**而市场常常在那里停顿或做出反应。**

[[img:tpo-poc]]

## 6. 初始平衡（IB）

- **IB = 前 2 个时段的价格区间**（一般 2×30 分钟，共 1 小时），即 A + B 两个时段
- 在 Profile 左侧以一条竖向带标出
- **作用**：为当日定调，显示买方或卖方早期的"信念/决心"
- **IB 很宽** → 后续波动可能更大；**IB 很窄** → 可能盘整
- 是判断日内方向的**关键参考**（后续所有"拍卖"策略都基于 IB）

[[img:tpo-ib]]

### 重要的是 IB 之后发生了什么

| 情形 | 含义 |
|---|---|
| **整个时段都在 IB 内部度过** | **平衡、旋转** |
| **突破并延伸（区间扩展，Range Extension）** | **后来的参与者强烈不同意开盘的估值，足以把市场推动** |

**所以 IB 本身不是信号，「IB 被突破还是被守住」才是。**

## 7. 单印（Single Prints）

- Profile 里某些价位**只出现一个 TPO**（只有一个字母）
- 说明市场快速穿过该区域，几乎没有回头反复交易
- **提示"不平衡区域"**：例如快速的买压或卖压
- 价格以后回到这些区域时，**可能成为未来的支撑/阻力**

### 它们是「未完成的生意」

**单印 = 拍卖走得太快、没来得及在那档做成生意而留下的缺口**，
**所以它是「低效率区迟早被回访」这条规律最直接的一种体现。**

### ⚠️ 一个必须加的限定

**判据是「孤立」：真单印的上下都得有块。**

**只贴在轮廓最顶端或最底端的那一个单块，是当日极值，不是单印** ——
**不加这条限定，每个正常的日高日低都会被误判成单印。**

[[img:tpo-single]]

## 8. 弱高点 / 弱低点（Poor Highs / Poor Lows）

- Profile **顶部或底部结构收敛结束**，但**没有形成"尾巴（tail）"，也没有形成厚实的成交堆积**
- 含义：买方（在高点）或卖方（在低点）的**决心不够强**
- **经常暗示潜在的反转或失败的突破**——因为市场并没有"接受"这些极端价位

> 纽约时段的一个弱低点。注意后续时段把这个弱低点扫掉了。
> **→ 弱低点会被扫掉，这是常态，不是例外。**（策略部分「弱高/弱低扫掠」即基于此）

### 更准确的判据：看极值上平躺了几个块

**判据是「平躺」：极值那一档上堆了两个或更多块，而不是收成一个尖。**

**和它对照的是「好高 / 好低」：**

| | 形成方式 | 含义 |
|---|---|---|
| **好高（Good High）** | 向上够一下、**找不到买方就被立刻拒绝**，收成一个尖 | **拍卖完成了** |
| **弱高（Poor High）** | **停在极值上继续成交**，既没被拒绝，也没突破过去 | **拍卖卡住了** |

**移动从未被解决，所以弱极值通常会被回访修补** —— 这就是「弱高/弱低扫掠」策略的根据。

[[img:tpo-poorhl]]

## 9. 峰度（Kurtosis）与"尾巴"

峰度衡量分布**尾巴的厚度**。

| 峰度 | 特征 | 对应行情 |
|---|---|---|
| **高峰度** | 尾巴更肥、极端价格波动更多、峰值更尖锐 | 更波动 / 更趋势化的时段 |
| **低峰度** | 尾巴更薄、轮廓更扁平 | 更平衡 / 区间震荡的时段 |

Profile 里的"尾巴"代表价格曾经延伸过去、但**没能停留**的离群区域，往往揭示市场的**拒绝点（rejection points）**。

## 10. 买入尾 / 卖出尾（Buying / Selling Tails）

- 是 Profile **底部（买入尾）**或**顶部（卖出尾）**的**单印延伸**
- **买入尾**：低位有激进买盘介入、拒绝更低的价格 → 常暗示潜在**向上反转**
- **卖出尾**：高位卖方压倒买方把价格压下去 → 可能暗示**下跌延续**

> **实操阈值**：为了让尾巴"更有意义"，**至少要有 2 个单印**。
>
> 伦敦时段的卖出尾 → 卖压非常强形成不平衡 → 随后形成弱低点（进一步确认）→ 下一个时段回测了卖出尾所在的价位。

[[img:tpo-tails]]

## 11. 裸露延伸（Naked Extensions）

**「裸露 / 处子（naked / virgin）」= 某价位被创造出来后，价格再没回来过。**

**把这种价位向前画出来，就叫裸露延伸；一直画到价格回来测试，延伸就停止。**

**一条心法：** **市场大量认同过、然后又走开的价位，是未完成的生意** ——
**未测试的价位倾向于吸引价格，所以延伸把静态的历史轮廓变成了活的参照物。**

### 哪些结构可以延伸

**不止 POC。轮廓产出的每一种结构都能单独向前带：**

| 可延伸的结构 | 未回访时的名字 |
|---|---|
| **POC** | 裸露 POC（Naked POC）—— 最常用 |
| **VAH / VAL** | 裸露价值区边缘 |
| **弱高 / 弱低** | 待修补的极值 |
| **单印** | 未完成的拍卖 |
| **尾巴** | 被拒绝后未再测试的价位 |

**全部打开的图会无法阅读。实务上只跑裸露 POC 和 VA 边缘，其余按需开启。**

## 12. 轮廓 vs 成交量轮廓：时间还是量

**两者都在价格旁边画水平分布，所以经常被搞混** —— **但它们衡量的东西不一样。**

| | 行长的原因 |
|---|---|
| **成交量轮廓（Volume Profile）** | 在那个价位**成交了很多「合约」** |
| **TPO 轮廓** | 市场在那个价位**花了很多「时间」** |

### 两者不一致时，故事就在这里

**它们经常一致，而当它们不一致时，那个分歧本身就在讲故事：**

| 现象 | 含义 |
|---|---|
| **成交量很大，但时间很少** | **大量生意在很短时间里做完** —— 一次激进成交，一次清算 |
| **时间很多，但成交量很小** | **市场乐意坐在那里，没有多少东西换手** |

**两者合读，比在两者之间二选一更有用。**

> **实务建议**：TPO 轮廓适合回答「哪里被接受了」，成交量轮廓适合回答「哪里真正换手了」。
> **看结构用 TPO，看成本用成交量轮廓。**

## 13. 什么时候该用市场轮廓

**市场轮廓回答的是关于「接受」的问题，而不是关于「方向」的问题。**

### 最有用的三个场景

1. **判断市场是平衡还是趋势**
2. **识别市场已经认同、并且很可能回访的那些价位**
3. **把一个时段放在前一个时段的框架里读** —— **今天是接受了昨天的价值，还是拒绝了它？**

### 最没用的场景：择时

**轮廓描述的是「已经被拍卖掉的东西」；它不给出入场信号。**

**交易者一般用它来「建地图」** —— **价值在哪里、生意在哪里没做完** ——
**然后用更快的工具（订单簿热力图、足迹图）在地图里择时。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **TPO（Time Price Opportunity）** | 时间-价格机会：某时段在某价位成交过，就记一个字母 |
| **时段（Period）** | 时间单位，通常 30 分钟，按 A、B、C… 命名 |
| **Profile（轮廓）** | 一天里所有时段叠加出来的横向分布图 |
| **VA / VAH / VAL** | 价值区及其上沿 / 下沿，标准切分为 70% / 15% / 15% |
| **POC** | 柱子最长的那一行，成交最密集的价位 |
| **IB / IBH / IBL** | 初始平衡（开盘后前两个时段）及其上下沿 |
| **单印（Single Print）** | 只有一个字母、且上下都有字母的孤立价位，属于低效率区 |
| **买入尾 / 卖出尾** | 底部 / 顶部的单印延伸，至少要有 2 个单印 |
| **好高 / 好低（Good High / Low）** | 极值处立即被拒绝、留下收窄单块 —— 拍卖完成了 |
| **弱高 / 弱低（Poor High / Low）** | 极值处平躺两个以上块 —— 拍卖卡住了，容易被扫掉 |
| **裸露 / 处子（Naked / Virgin）** | 产生后价格再未回访的价位，可向前延伸直到被测试 |
| **接受 / 拒绝（Acceptance / Rejection）** | 在某价位逗留 = 接受；立刻离开 = 拒绝 |
| **区间扩展（Range Extension）** | 价格突破 IB 并继续延伸 |
| **HVN / LVN** | 高成交量节点（价格停留）/ 低成交量节点（价格加速） |
| **分布（Distribution）** | 单 / 双 / 三重，代表当天换了几个价值区 |
| **接受 / 拒绝（Acceptance / Rejection）** | 市场在某价位逗留 = 接受；立刻离开 = 拒绝 |
