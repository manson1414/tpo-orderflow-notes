# Gamma 与 GEX：期权做市商的对冲如何推动现货

**目标**：搞懂 Gamma 是什么、为什么它能让期权做市商变成现货的「刹车」或「油门」，以及怎么读一张 GEX 价位图。

**学完你能**：看到「GEX 翻转点」「Call Wall」「Put Wall」这三个词，知道它们各自是什么、在什么条件下会失效。

---

## 一、先补一个希腊字母：Gamma

**Delta 和 Gamma 是期权里最容易被搞混的一对。**

| 希腊字母 | 回答的问题 |
|---|---|
| **Delta（Δ）** | 标的每动 1 元，**期权价格**动多少 |
| **Gamma（Γ）** | 标的每动 1 元，**Delta 变多少** |

**所以 Gamma 不是「价格的变化率」，而是「变化率的变化率」。** 它衡量的是 **Delta 有多不稳定**。

**Gamma 有两个特征必须记住**：

- **平值（ATM）附近最大，深度实值 / 深度虚值趋近 0。**
  平值期权的 Delta 在 0.5 附近，最容易被价格推动；深度实值的 Delta 已经贴着 1（或 0），再推也不怎么变。
- **离到期越近，平值附近的 Gamma 越陡。**
  时间价值快耗完时，期权要么变实值要么作废，Delta 的翻转会非常剧烈。

**一句话**：**Gamma 衡量的是「对冲的急迫程度」。** Gamma 大的价位，做市商被迫频繁调整对冲；Gamma 趋近 0 的价位，做市商可以不管。

---

## 二、为什么做市商的 Gamma 会推动现货价格

**这是本篇的核心机制。**

做市商卖出期权给买方，拿到权利金，但**不想承担方向风险** ——
所以他必须用**现货或期货**去对冲，把 Delta 拉回中性。**Gamma 决定了这股对冲流的方向。**

| 做市商的状态 | 价格涨的时候 | 价格跌的时候 | 净效果 |
|---|---|---|---|
| **净多 Gamma**（Long Gamma） | Delta 变大 → **卖出**标的 | Delta 变小 → **买入**标的 | **逆势对冲** → 压住波动 |
| **净空 Gamma**（Short Gamma） | 要补 Delta → **买入**标的 | 要减 Delta → **卖出**标的 | **顺势对冲** → 放大波动 |

**这张表要这么读**：

- **净多 Gamma 时，做市商「涨了卖、跌了买」** —— 这正好是追涨杀跌的反面，也是做市业务的本意：高抛低吸，赚时间价值。
- **净空 Gamma 时，做市商被迫「涨了买、跌了卖」** —— 追涨杀跌。
  **这不是他们想这么干，是维持中性必须这么干。**

**所以这不是「庄家故意」，而是结构性的、机械的对冲流。** 这一点很重要 ——
它意味着你可以**预期**这股流的方向，而不需要去猜谁在操纵。

## 三、GEX：把 Gamma 画成一张分布图

**GEX（Gamma Exposure，Gamma 敞口）就是把每个行权价上的 Gamma 敞口按规模加总，摊在价格轴上。**

**你会得到一张「山峰与山谷」的图**：横轴是价格，纵轴是那个价位上堆积了多少 Gamma。

**净 GEX 的符号 = 做市商的整体状态**：

- **净 GEX 为正** → 系统整体处于 **Long Gamma** → 波动倾向被抑制
- **净 GEX 为负** → 系统整体处于 **Short Gamma** → 波动倾向被放大

**⚠️ 这里有一条必须划清的边界**：

> **GEX 描述的是「市场结构」和「波动敏感度」，不是「方向」。**
> 它能回答「这个价位附近，市场对价格变化有多敏感」；
> 它**不能**回答「接下来是涨还是跌」。

**负 GEX 只告诉你「一旦动起来会更猛」，不告诉你往哪边动。**

## 四、三个关键价位

### GEX 翻转点（Gamma Flip / Zero Gamma）

**累计 GEX 穿过零的那个价位。**

- **现价在它之上** → Long Gamma → 均值回归主导，日内区间容易压缩
- **现价在它之下** → Short Gamma → 动量主导，突破更难被淡出

**它是「波动率制度的开关」，不是「方向信号」。** 这一句是本篇最值钱的一句 ——
它切换的是**市场对价格变化的反应方式**，不是价格的走向。

**不同数据源算出来的翻转点经常不一样**，因为它取决于持仓符号的假设、包含哪些到期日、
波动率输入、数据快照时间。这是正常的，不是谁算错了。

### Call Wall（看涨墙）

**Call Gamma 集中度最高的行权价** —— 通常是现价上方 Gamma 最厚的那个。

做市商在那里是净多 call（Long Gamma），价格往那里涨时他们**卖出**对冲 → **形成阻力**。
**越接近，推回来的力量越强** —— 像一根橡皮筋。

### Put Wall（看跌墙）

**Put 侧 Gamma 集中度最高的行权价** —— 通常落在现价下方。

价格往那里跌时，相关的对冲流倾向于**买入**标的 → 在正 Gamma 环境下**形成支撑**。

### 三者的位置关系

```
Call Wall        ← 阻力：做市商卖出
   现价
Gamma Flip       ← 制度分界：之上压波动，之下放波动
Put Wall         ← 支撑：做市商买入
```

**⚠️ 这两堵墙不是自动生效的天花板和地板。** 它们只在**正 Gamma 环境下**才硬；
一旦价格落到翻转点之下，同一堵墙可能连减速带都算不上。

## 五、墙被击穿时会发生什么

**这是最反直觉的一节：墙被击穿，往往不是「失效」，而是「换挡」。**

**原因**：Gamma 在平值附近最大，**深度实值 / 深度虚值的 Gamma 趋近 0**。
所以价格一旦穿过某个行权价走远，那个行权价上的 Gamma 就衰减掉了 ——
**原来在那里对冲的那股力量，消失了。**

| 事件 | 机制 | 结果 |
|---|---|---|
| **Call Wall 被突破** | 该行权价 Gamma 衰减 → 卖压消失 | **上方的刹车被松开**，容易加速；更高的那个 Call Wall 成为新目标 |
| **Put Wall 被跌破** | 该行权价 Gamma 衰减 → 买盘支撑消失 | **下方的地板被抽走**，容易级联下跌 |

**⚠️ 这两件事不对称**：

> **Put Wall 破位通常比 Call Wall 突破更剧烈。**
> 因为跌破 Put Wall 时，价格往往同时进入**负 Gamma 区** ——
> 对冲方向从「买入支撑」翻转成「卖出放大」，两股力量叠在一起。

**所以看到价格在负 Gamma 环境里逼近 Put Wall，要格外小心。** 那不是「支撑位做多」的位置。

### 顶部三个数（先看这个）

### 右侧的四条线

最上方那条虚线的价位标签是 **2613.06** —— 它是「重置」那一刻的参考价，

### 底部强度表

| 点位 | 行权价 | 较现价 | GEX 强度 |
|---|---|---|---|
| Call Wall 1 | $5,000 | +102.8% | 强 |
| Call Wall 2 | $2,400 | −2.6% | 强 |
| GEX Flip | $2,425 | −1.6% | n/a |
| Put Wall 1 | $2,000 | −18.9% | 极弱 |
| Put Wall 2 | $2,375 | −3.7% | 极弱 |
| Put Wall 3 | $2,350 | −4.7% | 极弱 |

**「GEX 强度」那一列才是重点** —— 它告诉你这堵墙有多厚。
这张图里 Put Wall 的强度条几乎是空的，说明**下方没有多少 Gamma 在撑着**。

### 自洽性核对（每次拿到一张图都该做一遍）

**第一步：现价和翻转点比大小。**
现价 2467.73，翻转点 2425.13 → 现价在翻转点之上 → 状态应该显示 LONG GAMMA。
**图上显示的就是 LONG GAMMA** ✅ 对得上。

**第二步：复算「较现价」那一列。**
按图上的现价 2467.73 去算：$2,400 是 −2.74%、$2,375 是 −3.76%、$2,350 是 −4.77%、
$2,000 是 −18.95%、$5,000 是 +102.62%。
图上给的是 −2.6% / −3.7% / −4.7% / −18.9% / +102.8% —— **每一行都差 0.05～0.18 个百分点。**

**反推一下**：要得出图上那些百分比，用的现价应该在 **2464.1 ～ 2466.3** 之间，
而图上最后一根 K 线的价格标签是 2467.73。

> **这个 0.1% 的错位不是错误，是快照时间差。**
> 这类工具每隔一段时间刷新一次，价格标签和百分比列不是同一瞬间算的。
> **但它提醒你一件事**：这些字段之间会有小幅不同步，别拿它们当精确到小数点的开关。

**⚠️ 另一个容易被误读的地方**：这张图的 **Call Wall 2 在 $2,400，比现价还低**。
「墙」的定义是「Gamma 集中度最高的行权价」，**不是「一定在现价上方」** ——
行情涨过去之后，原来那堵墙就落到脚下了。
**别把「Call Wall」当成「上方阻力」的同义词。**

## 七、⚠️ GEX 的三个硬伤

**这一节比前面所有内容都重要。** 不知道这三点，前面学的会让你亏钱。

### 硬伤一：它是模型输出，不是交易所公布的统计

**两家工具给出不同的翻转点是正常的** —— 持仓符号怎么假设、包含哪些到期日、
波动率取哪个时点，各家都不一样。**没有哪个是「官方值」。**

### 硬伤二：公开数据看不到「谁是多头谁是空头」

未平仓量只告诉你**有多少张合约还开着**，不告诉你**这些合约在谁手里、有没有在别处对冲过**。
所以做市商持仓是**估算**出来的，不是观测到的。

### 硬伤三：它不预测方向

**GEX 是制度指标，不是交易信号。** 负 Gamma 可以安静很久，直到别的东西把价格推动起来。

### 还有三条操作上的提醒

- **价位是「区间」，不是「线」。** 别拿 $2,425 当精确开关，给它留一段宽度。
- **离到期越近越有效。** Gamma 在到期前会陡增，所以同一堵墙，
  由三天后到期的合约撑起来的，比 45 天后到期的强得多。**做日内时先确认今天是哪个到期日。**
- **别忽略更厚的宏观事件。** 大额现货流、宏观数据、政策事件，都能盖过做市商对冲。

**最后一条**：不同工具的字段名不完全一样 —— 有的还会给你按到期日拆开的 Gamma 矩阵、
squeeze 价位、pin risk 之类的字段。**认字段的含义，不要认字段的名字。**

## 八、跟本站其它工具怎么配合

**GEX 回答「位置与波动制度」，订单流回答「谁在出力」。两者互补，不能互相替代。**

**加密市场有一个特别的落点**：做市商对冲期权敞口，主要打在两处 —— **永续合约**和**现货**。
所以到期日附近的 **OI / Funding / CVD** 异常，可以和 GEX 互相印证。

**一篇 2026 年发表在 _Finance Research Letters_ 的论文**
（Weiss 等，《Bitcoin option expiration, gamma exposure, and intraday price reversals》）
用 Deribit 比特币期权与永续合约的数据做了验证，结论值得记下来：

- **比特币在期权到期前后出现日内收益反转**；
- **效应集中在平值未平仓量偏高的日子**；
- **在累计 Gamma 敞口为负时最强** —— 与做市商对冲净空敞口造成的正反馈交易压力一致；
- **到期日前后，Deribit 永续与现货的成交活动同时上升**；
- 这些日内效应隐含每年约 **5000 万美元**的财富转移。

**它正好把前面几章的机制串成了一条链**：
**Gamma 是原因 → 对冲流是动作 → 永续和现货的成交与持仓是痕迹。**

**配合方式**：

| 场景 | GEX 说什么 | 再去哪里找证据 |
|---|---|---|
| 现价在翻转点之上、贴着 Call Wall | 波动被压，追突破性价比低 | 足迹图：是**吸收**还是**堆叠失衡击穿** |
| 现价跌破翻转点 | 制度切到放大，破位更难被淡出 | OI 与 Funding：是加杠杆推进还是出清 |
| 负 Gamma 下逼近 Put Wall | 支撑最脆的位置 | 清算柱与 CVD，等**衰竭**再谈反弹 |

## 九、本篇可执行动作

1. **先找翻转点，再看别的。** 打开一张 GEX 图，第一步永远是把现价和翻转点比一下 —— 制度没定，价位不用看。
2. **只记三个数**：翻转点、净 GEX 的符号、最厚的那堵墙在哪个行权价。其余都是噪音。
3. **核一遍字段自洽性**：现价 vs 翻转点 vs 状态，三个字段能不能对上。
4. **每个到期日单独看一次。** 别把不同到期日的 Gamma 混成一张图。
5. **把「墙被击穿」当成事件，而不是失效。** 破位时先问「原来在那里对冲的力量去哪了」。
6. **GEX 只做语境，不做信号。** 它永远不单独构成一次开仓理由。

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **Gamma（Γ）** | 标的每动 1 元，Delta 变多少 —— 衡量 Delta 有多不稳定 |
| **Delta（Δ）** | 标的每动 1 元，期权价格动多少 |
| **Delta 中性（Delta Neutral）** | 把方向风险对冲掉的状态，必须随价格不断调整 |
| **GEX（Gamma Exposure）** | 把每个行权价的 Gamma 敞口按规模加总，摊在价格轴上 |
| **净 GEX** | 所有行权价加总后的符号：正 = 整体 Long Gamma，负 = Short Gamma |
| **Long Gamma** | 做市商净多 Gamma → 涨卖跌买 → 逆势对冲 → 压波动 |
| **Short Gamma** | 做市商净空 Gamma → 涨买跌卖 → 顺势对冲 → 放大波动 |
| **GEX 翻转点（Gamma Flip / Zero Gamma）** | 累计 GEX 穿零的价位，波动制度的开关 |
| **Call Wall** | Call Gamma 最集中的行权价，正 Gamma 环境下构成阻力 |
| **Put Wall** | Put Gamma 最集中的行权价，正 Gamma 环境下构成支撑 |
| **Gamma Unclenching** | 价格穿过某个行权价后那里的 Gamma 衰减、对冲压力消失 → 加速 |
| **钉住（Pinning）** | 正 Gamma 环境下价格被压在 Gamma 最厚的行权价附近 |
| **0DTE** | 当日到期的期权。Gamma 在到期前最陡，这类合约的对冲流最急 |

## 自测

> 覆盖「Gamma 与 GEX」阶段。
> **答案默认折叠** —— 先自己想，再点开对答案。

**U12.1 Gamma 到底是什么**

- ⚠️ **常见错误**：把 Gamma 当成「另一个均线」或者「波动率指标」。
- **自测**：Gamma 和 Delta 的关系是什么？
- **答案**：Gamma 是 **Delta 的变化率** —— 标的每动 1 元，Delta 变多少。
  它在平值附近最大、深度实值与深度虚值趋近 0，离到期越近越陡。

**U12.2 两种 Gamma 状态下的对冲方向**

- ⚠️ **常见错误**：以为做市商总是在「高抛低吸」。
- **自测**：做市商净空 Gamma 时，价格上涨他必须做什么？为什么？
- **答案**：**买入。** 为了维持 Delta 中性，价格上涨使他的空头敞口变大，必须补回标的 ——
  这就是**顺势对冲**，追涨杀跌，放大波动。净多 Gamma 时反过来：涨了卖、跌了买。

**U12.3 GEX 翻转点**

- ⚠️ **常见错误**：把翻转点当成方向信号 —— 跌破就做空。
- **自测**：价格从翻转点上方跌到下方，市场发生了什么变化？
- **答案**：**切换的是波动制度，不是方向。** 做市商从逆势对冲变成顺势对冲，
  波动从被压制变成被放大。往哪边走，GEX 不告诉你。

**U12.4 Call Wall 与 Put Wall**

- ⚠️ **常见错误**：把墙当成精确的天花板与地板。
- **自测**：价格跌破 Put Wall，说明「支撑有效」还是「支撑消失」？
- **答案**：**支撑消失。** 那个行权价的 Gamma 在价格走远后衰减，
  原来买入对冲的力量撤了；若同时进入负 Gamma 区，对冲方向翻转成卖出，跌势会加速。
  所以 Put Wall 破位通常比 Call Wall 突破更剧烈。

**U12.5 GEX 的边界**

- ⚠️ **常见错误**：拿两家工具的翻转点对不上，就说其中一个算错了。
- **自测**：为什么两个平台给出的 GEX 翻转点会不一样？
- **答案**：**因为 GEX 是模型输出，不是交易所公布的统计。**
  持仓符号怎么假设、包含哪些到期日、波动率取哪个时点，各家都不同。
  而且公开持仓看不到谁是多头谁是空头 —— 做市商持仓本身是估算的。

**U12.6 GEX 怎么和订单流配合**

- ⚠️ **常见错误**：拿 GEX 单独做开仓依据。
- **自测**：GEX 告诉你「这里波动会被放大」，下一步该去哪里找证据？
- **答案**：**订单流。** GEX 给位置与制度，订单流给「谁在出力」。
  加密里做市商对冲主要落在**永续和现货**上，所以到期日附近的 OI / Funding / CVD 异常
  可以和 GEX 互相印证。
