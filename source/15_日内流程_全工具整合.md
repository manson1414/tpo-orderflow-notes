# 日内交易流程（全工具整合版）

**性质**：在 `09_日内流程_Profile版.md` 基础上，加入 VWAP、订单流、衍生品数据三层。

> ⚠️ 仅用于学习交流，不构成任何投资建议；日内交易风险极高，请以严格风控为前提。

---

## 一、图表与数据面板（开盘前固定好）

**你不需要把所有工具一次性用满，但建议把"语境层 → 价值层 → 执行层 → 风控层"分开摆放**：

| 层级 | 内容 |
|---|---|
| **语境层（Higher TF）** | 周线 / 日线 / 4H 结构线、关键高低点、重要开盘价（周开 / 日开 / UTC 开盘等） |
| **Profile 价值层** | TPO / Market Profile（当日与前一日/前几日），至少包括：VA、VAH、VAL、POC、IB、single prints、tails、poor high/low、value/POC migration |
| **VWAP 价值层** | 当日会话 VWAP（建议 UTC 或你交易的主要会话开盘），以及 VWAP 的 1/2/3 标准差带；必要时使用 Anchored VWAP 锚定到关键结构点或开盘点 |
| **执行层（Order Flow）** | Footprint（足迹图：Bid/Ask、Delta、Imbalances、Stacked imbalances），以及 CVD（最好能区分 Spot CVD 与 Perp CVD） |
| **衍生品与流动性面板** | OI 与 OI Delta、Funding、Orderbook Depth/DOM、Heatmap、Liquidations（含 clusters / z-score）、Taker Buy/Sell Ratio、Long-Short Ratio（**仅作情绪背景**） |

> ⚠️ **提醒**：反复强调——**任何单一指标都不是"信号"**。你要用它们做**语境与确认**，而不是机械开仓。

---

## 二、开盘前 15–30 分钟：建立"语境"

### 步骤 1：先定大级别结构（周/日/4H）

- 你现在处于**趋势（trend）**还是**箱体/括号（bracketing）**？
- 关键结构水平：最近的 **swing high/low**、关键突破位/回踩位、前高前低、明显的供需拐点

### 步骤 2：读"前一日/前几日"的 Market Profile（价值与拍卖）

- 昨日是**趋势日、震荡日还是中性日**？
- **Value 是否上移/下移**（value migration）？**POC 是否迁移**（POC migration）？
- 昨日极值是否"**干净**"：有无 **tails**？有没有 **single prints**？高点/低点是否**贫穷**（poor high/low）？
- 把今天最可能被测试的参考点**提前标出来**：pdVAH / pdVAL / pdPOC、single print 边缘、tails 的起点/终点、缺口与不平衡区（如果你做多日"拼图/tetris"）

### 步骤 3：读 VWAP（价值锚）

- 价格当前在 **VWAP 上方还是下方**？距离 VWAP 有多远（是否进入 **2σ/3σ 偏离带**）？
- **若价格远离 VWAP**：要更警惕"**过度延伸**"与均值回归（mean reversion）
- **若价格围绕 VWAP 盘整**：要警惕从价值区向外扩张引发的**趋势延伸**
- 需要更精细时，**锚定 VWAP 到关键点**（Anchored VWAP）：UTC 开盘、主要会话开盘、结构拐点、关键高低点等

### 步骤 4：读衍生品持仓与流动性（告诉你行情"脆不脆"）

- **OI**：现在是**高 OI 还是低 OI**？OI 在**上升（加杠杆）还是下降（去杠杆）**？
- **Funding**：是否**极端**？极端是否"**持续**"且伴随 **OI 上升**（更危险、更容易出挤压/清算）？
- **Liquidations**：清算簇在哪里？如果价格走进去，可能出现**瀑布（cascade）**还是**清掉后回弹（snap-back）**？
- **Depth / Heatmap**：簿子**厚还是薄**？是否出现明显**墙/流动性簇**？**注意 spoofing——不要在价格没靠近前就假设墙是真的**
- **Long-Short Ratio**：只当作"**散户情绪背景**"，只有当它与 **OI、Funding 同时极端共振**时才更有参考价值

### 步骤 5：读 CVD（谁在更主动）

- 用 **HTF CVD（1H/4H/D）给方向偏向**，用 **LTF CVD（1m/5m/15m）找执行精度**
- 重点观察**两类背离**：
    - **吸收**（CVD 强但价格不走）
    - **衰竭**（价格想走但 CVD 跟不上）
- 如果能看 **Spot vs Perp CVD**：用它判断"**真实需求**"是否支持杠杆流

## 三、写出当天 2–3 个"情景剧本"（Scenario Planning）

> 把所有信息压缩成可执行的"**如果……那么……**"剧本。
> **每个剧本至少写清：触发条件、入场确认、无效条件、目标位、止损逻辑。**

### 剧本 A：趋势延续（Trend Continuation）

| 字段 | 内容 |
|---|---|
| **典型语境** | Value/POC 持续向一个方向迁移；价格稳定在 VWAP 同侧；OI 上升且 CVD 与价格同向；簿子不至于极薄（或即便薄也有明确主动流穿透） |
| **触发** | 回踩到 **VWAP / VAH / VAL / 关键结构位**并出现**接受（acceptance）** |
| **确认** | Footprint 出现**连续主动性**（delta / stacked imbalances）、**Taker Buy/Sell 同向占优**、**CVD 重新转强**；OI 不出现快速掉头出清 |
| **目标** | 下一处 profile 参考点（POC / VAH / VAL / 单印边缘）或 **VWAP 偏离带**；也可参考**清算簇 / 深度墙**作为"磁铁" |
| **无效** | 跌回 VWAP 与价值区并形成**反向接受**，或出现明显**吸收背离**（CVD 很强但价格不再推进） |

### 剧本 B：均值回归（Mean Reversion / 价值回归）

| 字段 | 内容 |
|---|---|
| **典型语境** | 开盘在**前一日价值区外**，但缺乏后续接受；价格在 **2σ/3σ 偏离带**出现**衰竭**；CVD 与价格出现**背离**；**taker 流与价格方向不一致（吸收）** |
| **触发** | 关键水平被"**失败拍卖（failed auction）**"或出现 **tails / 单印拒绝**；或价格在偏离带上出现**反转结构** |
| **确认** | **CVD / Delta 出现衰竭或吸收信号**；Footprint 显示**堆叠不平衡撞墙（delta trap）**；**OI 开始下降**（强制流动被清掉） |
| **目标** | 先看 **VWAP**；进一步看 **pdPOC / 当日 POC** 与**价值区另一侧边界** |
| **无效** | 价格重新在偏离带外形成**持续接受**（多根时间单位站稳）且 **OI / CVD 同向增强** |

### 剧本 C：流动性事件（Stop Hunt / 清算瀑布 / 假突破）

| 字段 | 内容 |
|---|---|
| **典型语境** | **高 OI + 薄簿子**；清算簇贴近区间边缘；Funding 极端；容易出现"**强制性流动**"尖刺 |
| **两种分支** | **1) 真突破**：突破前 CVD **先逐步堆起来**（build before break），突破时 taker 流**持续跟进**，价格位移与 CVD 匹配<br>**2) 假突破/扫止损**：突破点出现 **CVD 尖刺但价格推进不足（吸收）**，随后**快速反向**（常见 V 形） |
| **处理** | 这种情景要么**降低仓位**，要么**只做"确认后的回踩/反转"**，**不要追第一根尖刺 K 线** |

## 四、开盘到前 2 小时：执行框架（Profile 先分类，Order Flow 再确认）

### 步骤 1：用前一日价值区定义"开盘位置"（Open Location）

| 开盘位置 | 偏向 | 动作 |
|---|---|---|
| **在价值区内** | 更偏**双向** | 优先等**边界测试与失败/接受** |
| **在价值区上方** | — | 观察是否**接受**（强势趋势日可能直接扩张）；否则容易回到价值区 |
| **在价值区下方** | — | 同理，观察是否**接受**；否则容易**回归** |

### 步骤 2：等 IB（Initial Balance，A+B 时段）形成

- **不要在 IB 没形成就把自己当先知。先看市场给出的"初始框架"。**
- 观察是否出现 **range extension、one-timeframing、spike**，以及 **POC / value 是否开始迁移**

### 步骤 3：在关键参考点上区分"接受 vs 拒绝"

- **接受（acceptance）**：需要**时间确认**——多根时间单位/多段 TPO 站稳，**不是一个瞬间扎针**
- **拒绝（rejection）**：看 **tails、single prints、失败拍卖**；结合 **VWAP 位置与偏离带**判断是否属于"**过度延伸**"

### 步骤 4：用 Order Flow 只做两件事：确认与定风险

- **Footprint**：看**不平衡（imbalances）**、**堆叠不平衡（stacked imbalances）**、成交量是否在关键位**放大但位移不跟（吸收）**
- **CVD**：看**价格与 CVD 是否匹配**；看**吸收/衰竭背离**；必要时对比 **Spot vs Perp**，判断是**真需求**还是**杠杆在硬推**
- **Taker Buy/Sell**：把它当作更"**干净的短窗主动性**"，尤其适合在 **VWAP、区间边缘、突破点**做快速判断
- **OI / Funding**：用来判断这波动是"**加杠杆推进**"还是"**出清推进**"。**出清推进容易 V 形；加杠杆推进更可能延续，但也更容易在拥挤时被挤压**

## 五、入场规则：三重确认（位置 × 时间 × 流）

**把入场门槛写死：缺一不可。**

| 维度 | 要求 |
|---|---|
| **位置（Location）** | 必须发生在"**结构/价值**"参考点附近（VAH / VAL / POC、single prints 边缘、tails、VWAP / 偏离带、清算簇、深度墙等） |
| **时间（Time）** | 必须出现 **Profile 的时间确认**（接受 / 拒绝 / 失败拍卖），避免被单根尖刺 K 线诱骗 |
| **流（Flow）** | 至少 **1–2 个流动指标**与你的方向一致，或给出清晰的**背离信号**（吸收 / 衰竭）支持你的反向交易 |

**常见的"加分项"**（不是必需项，但能提高质量）：

- **OI 与 CVD 同向增强**
- **taker 流在突破后持续跟进**
- **spot CVD 支持趋势方向**

---

## 六、风控与仓位：先把"你最多亏多少"写出来

- **单笔风险**：固定为账户权益的一个**小比例**（例如 **0.25%–1%**，具体看你策略回撤与胜率）
- **日内最大亏损**：达到即**停止交易**（例如 2–3 笔连续亏损或当日 −X%）
- **止损放在哪里**：放在"**结构无效点**"，而不是随便一个固定点数
    - **趋势延续**：止损通常放在 **VWAP / 价值边界的另一侧**，或关键 **tail / single print 的外侧**
    - **均值回归**：止损放在**偏离带外的"再次接受"位置**，或**扫止损尖刺的外侧**
- **高风险环境降杠杆**：**高 OI + 薄簿子 + 极端 Funding + 清算簇临近** → 要么减仓，要么不做
- ⚠️ **不要因为"看起来很确定"就放大仓位**：多次强调——**市场机制会让你在最自信的时候被挤压**

---

## 七、出场与管理：让结构替你做决定

- **目标位优先用 Profile / VWAP**：当日 POC、前一日 POC、VAH / VAL、VWAP、VWAP 偏离带、单印边缘、清算簇 / 深度墙
- **分批止盈**：在 **POC / 价值边界 / VWAP** 处减仓，让你在不确定性里把期望值做大
- **趋势持仓的"健康度"检查**：
    - 价格推进是否仍与 **CVD** 匹配？
    - **OI** 是否继续增加（而不是快速掉头出清）？
    - **Footprint** 是否仍能在回踩处出现**主动性簇**？
- **如果出现明显吸收背离**（CVD 很强但价格不再推进）或 **taker 流转向** → 考虑**收缩仓位或退出**
- **均值回归交易**：第一目标通常是 **VWAP**；若回到 VWAP 后出现**接受/拒绝**，再决定是否继续持有到**价值区另一侧**

---

## 八、复盘：把"工具"变成"系统"

> **最重要的一句话之一：这些数据提供的是语境，不是信号。把语境变成优势，需要系统与回测/统计。**

**每天至少做 10–15 分钟复盘**：

- **截图**：当日 Profile（含开盘类型 / IB / 日型）、VWAP（含偏离带）、Footprint、CVD、OI / Funding / Depth / Liquidations 面板
- **记录**：你做的是哪个剧本（A/B/C）？入场满足了"**位置 × 时间 × 流**"吗？止损是否放在**结构无效点**？
- **给执行打分**：计划内执行 / 计划外冲动各占多少？
- **只改 1 个点**：下一交易日只优化一个环节（例如：更严格的时间确认、更少追单、更明确的止损位置）

> ⚠️ **最后提醒**：如果你还没有一个经过统计验证的策略（哪怕是极简的 1–2 个 setup），**先用极小仓位跑 2–4 周**，把流程练成条件反射，再考虑提高频率和仓位。

## 九、与 Profile 版流程的差异速览

| | Profile 版（`09`） | 全工具版（本篇） |
|---|---|---|
| 语境层 | 周/日线 + 关键水平 | 周/日/4H + 关键水平 + **VWAP 偏离带** + **衍生品面板** |
| 价值层 | VA / VAH / VAL / POC / IB | 同上 + **VWAP（含锚定）** |
| 执行层 | TPO 时间确认 + 节奏/动量 | 同上 + **Footprint / CVD / Taker Flow** |
| 情景数 | 6 个分支（A–F） | 3 个剧本（A–C），每个更细化 |
| 入场门槛 | 4 条硬条件 | **三重确认（位置 × 时间 × 流）** |
| 风控 | 结构无效点 + 仓位 | 同上 + **单笔 0.25%–1%** + **日内最大亏损** + **高风险环境降杠杆** |
| 出场 | Profile 参考点 + 节奏 | 同上 + **CVD 健康度检查** + **taker 流转向** |

> **建议**：先跑 Profile 版（`09`）2–4 周，练熟"确认 / 节奏 / 动量 / 参考点"四件事，再加入本篇的订单流与衍生品层。**一次加一层，不要一次全上。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **三重确认** | 位置 × 时间 × 流 —— 三者齐备才开仓的最低门槛 |
| **位置（Location）** | 必须发生在结构 / 价值参考点附近 |
| **时间（Time）** | 必须有 Profile 的时间确认，≥1 个完整时段 |
| **流（Flow）** | 至少 1–2 个流动指标同向或给出清晰背离 |
| **情景剧本（Scenario）** | 开盘前写好的 2–3 条「如果……那么……」 |
| **失效条件（Invalidation）** | 什么情况证明判断错了，必须离场 |
