# 图鉴 10 · 资金费率（Funding Rate）

> **这一篇讲什么**：为什么永续合约需要资金费率、它怎么暴露拥挤方向、和价格一起读的四种组合、五个局限。
> **配图**：1 张真实行情截图。
> **来源**：译自 mmt.gg/learn/funding-rate，已删除全部平台操作说明。

**一句话**：**资金费率是「谁在付钱持有仓位」的直接读数** —— **付钱的那一边，就是拥挤的那一边。**

---

## 一、资金费率是怎么工作的

### 先看普通期货

**普通期货合约有到期日。**
**不管中间价格怎么走，到期时它都要对着现货结算** ——
**而这个「必然收敛」就是阻止两者长期偏离的锚**：
**任何人都可以套利这个价差，因为他知道它必须闭合。**

### 永续合约的问题

**永续合约没有到期日，所以它没有这个锚。**

**放任不管，它可以无限期地相对现货升水或贴水交易。**

**资金费率就是为「替代那个缺失的收敛」而被发明出来的机制。**

### 机制：让拥挤的一边付钱

**如果永续高于现货 → 费率为正 → 每个资金周期，多头付钱给空头。**

**持有多头现在开始花钱，持有空头开始赚钱** ——
**这会把参与者拉向空头一边，把升水拉回零。**

**如果永续低于现货，机制反向运转：空头付钱给多头。**

[[img:funding-hero]]

### 三个必须记住的细节

| 细节 | 说明 |
|---|---|
| **钱在多空之间走** | **不是交给交易所** |
| **按固定周期结算** | 最常见是**每 8 小时**一次，但各平台不同 |
| **报价是仓位价值的百分比** | **所以它是一种「持有成本」：每个周期很小，长期持有就很实在** |

## 二、资金费率告诉你什么关于持仓的信息

**这是资金费率从「一笔费用」变成「一条信息」的地方。**

### 它是拥挤方向的直接读数

**费率直接读出哪一边在拥挤。**

- **费率为正** = 永续在升水 = **多头在花钱买「继续做多」的特权**
- **费率为负** = 反过来

**没有人需要去猜情绪 —— 拥挤的那一边，就是那个在开支票的一边。**

### 持续极端值才是有效读数

**费率连续多日强烈为正**，描述的是一个**杠杆多头已经挤进来、并且正在花钱待着**的市场。

**那就是燃料**：
**这些仓位持有成本高 → 持有者会变得没耐心 → 而没耐心的杠杆仓位，正是价格一转就溃散最快的那批。**

**费率持续为负、轧空，逻辑完全对称。**

### 穿过零轴也值得注意

**费率从正翻负，意味着升水消失了**：
**之前花钱做多的市场，现在开始花钱做空。**

**这种「谁在拥挤」的转换，往往伴随一次真正的控制权易手，而不只是一次停顿。**

## 三、怎么把资金费率和价格放在一起读

**单独看资金费率，远不如和价格放在一起看。**

| 价格 | 资金费率 | 解读 |
|---|---|---|
| **涨** | **正，且在攀升** | 上涨由**杠杆多头驱动，而且他们付的钱越来越多**。可以继续，但**昂贵且拥挤** —— **费率拉伸得越远，解开的动作越剧烈** |
| **涨** | **负** | **空头在为这波上涨付钱。** 站在行情对立面的人**在为自己的错误被收费** —— **这是更健康、也更持久的上涨形态** |
| **跌** | **仍为正** | **多头还没投降。** 他们在下跌中花钱持有 —— **意味着「能提供进一步下跌燃料」的那批仓位还在场上** |
| **跌** | **负，且在加深** | **空头已经接管，并且在为此付钱。** 在弱势中拥挤的空头，**正是轧空赖以构成的原料** |

### 贯穿四者的同一个模式

**一个由「正在付钱持有它」的那一边支撑的行情，比由「正在收钱」的那一边支撑的行情更脆弱。**

**这个模式在未平仓量、净头寸里同样成立。**

## 四、资金费率的局限

| 局限 | 说明 |
|---|---|
| **它是「利率」，不是「扳机」** | **极端费率可以持续数周。** 它描述一种状态，**完全不告诉你这个状态什么时候会解开** |
| **它是分交易所的** | **每家交易所在自己的合约上设自己的费率**，有自己的周期、公式和上下限。**跨交易所的费率不能直接比较**，一个交易所上的拥挤订单簿**不等于整个市场** |
| **周期不同** | **「每 8 小时报一次」和「每小时报一次」不是同一个数字。** 同类比同类，**并且在判断成本前先年化** |
| **它只描述永续** | **现货没有资金费率**；**有到期日的期货靠交割而不是靠付款来收敛** |

### 本篇需要关注的术语

| 术语 | 一句话 |
|---|---|
| **资金费率（Funding Rate）** | 永续合约多空之间按周期互相支付的费率，用来锚定现货 |
| **永续合约（Perpetual）** | 无到期日的合约，靠资金费率替代到期收敛 |
| **升水 / 贴水（Premium / Discount）** | 永续高于 / 低于现货 |
| **持有成本（Cost of Carry）** | 持有一个仓位每周期需付出的费率成本 |
| **穿过零轴（Zero Flip）** | 费率由正转负（或反之），拥挤方向易手 |
| **年化（Annualize）** | 把单周期费率折算成年化，用于跨周期比较成本 |
