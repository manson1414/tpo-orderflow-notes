# 图鉴 09 · 未平仓量（Open Interest, OI）

> **这一篇讲什么**：OI 数的是什么、涨跌的四种组合、OI 与成交量的根本区别、四个局限、什么时候该用它。
> **配图**：1 张真实行情截图。
> **来源**：译自 mmt.gg/learn/open-interest，已删除全部平台操作说明。

**一句话**：**成交量告诉你「交易了多少」，未平仓量告诉你「其中有多少留下了新仓位」。**

---

## 一、未平仓量是怎么工作的

**每一份衍生品合约都有两边。**
**一个仓位要存在，必须有人做多它、另一个人做空它** ——
**而未平仓量把这份合约只数一次，不数两边。**

[[img:oi-hero]]

### 三种成交，三种结果

关键不在「成交了多少」，而在**成交双方各自在做什么**：

| 买方在做 | 卖方在做 | OI 变化 | 原因 |
|---|---|---|---|
| **开仓** | **开仓** | **+1** | 一份**原本不存在**的合约诞生了 |
| **平仓** | **平仓** | **−1** | 合约被**消灭**了 |
| **开仓** | **平仓** | **0** | 合约**只是换了手**，没有任何变化 |

### 第三种情况才是重点

**因为它就是 OI 与成交量的分界线。**

**这三种成交在成交量上完全一样，都 +1。**
**但只有第一种创造了新的风险敞口。**

> **成交量 = 发生了多少交易。**
> **未平仓量 = 其中有多少留下了新仓位。**

### 所以 OI 只存在于有合约的地方

**因为它数的是「承诺」，不是「活动」。**

- **期货、永续** → **有 OI**
- **现货** → **没有**（直接买币不会创造一份「以后必须平掉」的合约）

---

## 二、OI 上升与下降分别意味着什么

**OI 单独看，数的是合约份数，而每一份合约都是「某人的多头 + 另一人的空头」** ——
**所以这个数字本身无法告诉你市场站哪一边。**

**它只有在和价格一起读的时候才有用。** 四种组合，各描述一种不同的行情：

| 价格 | OI | 含义 | 性质 |
|---|---|---|---|
| **涨** | **涨** | **新多头在强势中开仓**，新钱从买方进场 | **最健康的上涨，最可能延续** |
| **涨** | **跌** | **仓位在被平，不是被开**。空头在买回平仓 | **这是轧空的形状，不是趋势** —— 空头买完，买盘就停了 |
| **跌** | **涨** | **新空头在弱势中开仓**，新钱承诺更低价 | **有真实信念支撑的下跌趋势** |
| **跌** | **急跌** | **多头在平仓，而且往往不是自愿的** | **杠杆仓位被清算的签名** —— 没东西可强平时会突然结束 |

### 四条背后的同一个模式

**OI 上升 = 新的承诺 → 倾向于延续一波行情。**
**OI 下降 = 仓位在被解开 → 倾向于终结一波行情。**

## 三、OI 和成交量到底差在哪

**它们衡量的东西不同，而这个区别经常把人绊倒。**

| | 成交量（Volume） | 未平仓量（OI） |
|---|---|---|
| **性质** | **流量（flow）** | **存量（stock）** |
| **数什么** | 一个周期内**成交**了多少 | 某一时刻**存续**着多少合约 |
| **时间行为** | 下一周期开始时**归零重算** | 从上一周期**带过来，累积** |
| **什么时候变** | 一直在变 | **只在仓位被创造或消灭时才变** |

### 两种极端市场

- **成交量巨大 + OI 完全持平** → 交易者**整天把同一批合约互相倒手**，**没有增加任何敞口**
- **成交量平平 + OI 稳步攀升** → **远少的交易，在悄悄堆积远多的风险**

**这两种是完全不同的市场。**

---

## 四、未平仓量的局限

| 局限 | 说明 |
|---|---|
| **它没有方向** | **OI 数的是合约，不是方向。** 上升只告诉你「仓位被开了」，不告诉你是多头还是空头开的。**方向是靠和价格对照推出来的 —— 而那是推论，不是事实** |
| **它是分交易所的** | 每家交易所只报自己的合约。**一个交易所的 OI 在跌，另一个可能在涨**（仓位在两地之间搬家）。**跨交易所聚合才能得到总敞口的可靠画面** |
| **各单位不同** | 有的交易所以**合约**计，有的以**标的币**计，有的以 **USD** 计。**以币计的数字会因为价格波动而变，哪怕一个仓位都没动**。**只能同类比同类** |
| **它不区分意图** | **一个对冲现货风险的套保者，和一个做方向性投机的交易者，在 OI 上的贡献完全一样** |

## 五、什么时候该用未平仓量

**OI 是一个「信念检验器」。它很少单独产生一笔交易，但它会改变一波行情该被赋予多少权重。**

### 最好的用法：给突破定性

| 情形 | 解读 |
|---|---|
| **价格突破一个价位 + OI 上升** | 买的人是**在承担新风险** |
| **价格突破同一个价位 + OI 下降** | 买的人是**在退出旧风险** |

**这两种处境，后续的演化方式完全不同。**

### 看杠杆堆积与冲刷

**一段长时间 OI 持续上升、价格却卡在区间里 = 敞口在积累** ——
**而这就是「区间最终破掉时会产生瀑布」的那个前置条件。**

**盯这个堆积过程，往往比盯价格行为更能告诉你接下来会发生什么。**

### 它的短板

**它很慢，而且它是一个「水平」，不是一个「信号」。**
**OI 不会替你择时，而孤立地读它的一根柱子，几乎毫无意义。**

### 本篇需要关注的术语

| 术语 | 一句话 |
|---|---|
| **未平仓量（Open Interest, OI）** | 当前存续中的衍生品合约总数（每份只数一次） |
| **流量 vs 存量（Flow vs Stock）** | 成交量是流量（周期内归零）；OI 是存量（累积带过来） |
| **轧空（Short Squeeze）** | 空头被迫买回平仓推动的上涨，空头买完即止 |
| **换手（Churn）** | 合约在交易者之间倒手，OI 不变 |
| **敞口（Exposure）** | 通过开仓创造出的、尚未了结的风险 |
