# 每日执行清单（可直接打印）

> 两个版本：**基础版**（只用 Profile，对应 `09`）与**进阶版**（加 VWAP + 订单流 + 衍生品，对应 `15`）。
> 建议：**先跑基础版 2–4 周**，再上进阶版。

---

## A. 基础版（仅 Profile）

### 开盘前（≤10 分钟）

- [ ] **1) 高周期趋势偏向**：上 / 下 / 震荡　→ **不确定 = 不交易**
- [ ] **2) 关键水平**：年开盘 / 范围线 / AVWAP / SMA200 / Fib（可选）
- [ ] **3) 昨日数据**：pdVAH / pdVAL / pdPOC、pdH / pdL、Naked POC、弱高弱低、单印区、ONH / ONL
- [ ] **4) 写 2–3 个情景**，每个必须包含：
    - [ ] Trigger（触发）
    - [ ] Invalidation（失效）
    - [ ] Stop（止损）
    - [ ] Target（目标）
- [ ] **5) 写清楚：哪些情况不交易**

### 盘中（前 2 小时重点）

- [ ] **6) 等 IB（A+B）形成**；先分类四种开盘（Drive / Test-Drive / Rejection-Reverse / Auction）
- [ ] **7) 看是否有拍卖点**（突破 IB）并观察：**确认还是失败？**
- [ ] **8) 只有在出现"时间确认 + 节奏/动量一致"时才允许入场**
- [ ] **9) 到目标点执行止盈**；不追单、不临时改剧本

### 盘后（≤15 分钟）

- [ ] **10) 截图并记录**：日型、开盘型、动量标记、你的执行评分
- [ ] **11) 下一次只改 1 个点**

---

## B. 进阶版（全工具）

### 开盘前（15–30 分钟）

**1. 语境层**

- [ ] 定 HTF 结构：**趋势 or 箱体**？关键 swing 水平？

**2. Profile 价值层**

- [ ] 读前一日 Profile：pdVAH / pdVAL / pdPOC、tails、single prints、日型
- [ ] 判断：Value 是否迁移？POC 是否迁移？
- [ ] 标出今日最可能被测试的参考点

**3. VWAP 价值层**

- [ ] 设会话 VWAP + 偏离带（1σ / 2σ / 3σ）
- [ ] 必要时 Anchored VWAP 锚到关键点
- [ ] 判断：价格在 VWAP 上方还是下方？是否进入 2σ/3σ？

**4. 衍生品语境**

- [ ] OI / OI Delta：高还是低？加杠杆还是去杠杆？
- [ ] Funding：是否极端？是否持续 + 伴随 OI 上升？
- [ ] Depth / Heatmap：簿子厚还是薄？有无明显墙？（**注意 spoofing**）
- [ ] Liquidations：清算簇在哪？可能瀑布还是回弹？
- [ ] Taker Ratio（**L/S Ratio 仅作背景**）

**5. CVD**

- [ ] HTF CVD 定偏向，LTF CVD 定执行
- [ ] Spot vs Perp 是否一致？

**6. 剧本**

- [ ] 写 2–3 个剧本：**触发 / 确认 / 无效 / 目标 / 止损**

### 盘中（前 2 小时重点）

- [ ] **7) 分类开盘位置**：在价值区内 / 外？（为 80% 规则做准备）
- [ ] **8) 等 IB 成形**，再观察 range extension、one-timeframing、POC/value 迁移
- [ ] **9) 只在关键点交易**：**位置 × 时间 × 流** 三重确认后再动手
- [ ] **10) 达到计划目标位分批止盈**；出现**吸收 / 衰竭**信号则减仓或退出

### 盘后

- [ ] **11) 截图 + 记录**：日型、开盘型、VWAP 关系、订单流确认、执行得分
- [ ] **12) 只优化一个点**，第二天继续重复

## C. 三条永不妥协的规则

> 最高优先级纪律。

1. **没有时间确认 = 不交易。**
   > "一个单印不算确认。" —— 至少要 1 个完整时段站稳，更稳健是 2 个。

2. **没有失效条件 = 不交易。**
   > 没有失效条件 = 没有交易计划 = 不交易。止损必须放在失效条件之外。

3. **没有写进剧本的走势 = 不交易。**
   > FOMO 追进未知区域 = 送钱。"你没有计划，你就不交易。"

## E. 使用说明

- **第一周**：只做开盘前 + 盘后两部分，盘中只观察不下单。目标是**把清单跑成习惯**。
- **第二至四周**：用**极小仓位**执行剧本，重点验证"**位置 × 时间 × 流**"是否真的提高质量。
- **四周后**：统计胜率、盈亏比、以及"**未计划交易**"占比。**未计划交易占比是你纪律水平的最直接指标。**
- **持续**：每周末回看一周的价值迁移与 POC 迁移，收集 5 个"教科书样本" + 5 个"最差案例"。

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **日型（Day Type）** | 趋势日 / 区间日，盘后必须记录 |
| **开盘型（Opening Type）** | 四种开盘形态之一，盘后必须记录 |
| **动量标记** | 当天出现的信念 / 机械标记 |
| **执行评分** | 给自己的纪律打分，而不是给盈亏打分 |
| **三条铁律** | 没有时间确认 / 没有失效条件 / 没写进剧本 → 都不交易 |
