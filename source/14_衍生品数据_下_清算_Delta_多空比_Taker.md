**目标**：掌握四个"不那么常用但同样有价值"的工具。

> 前置：`13_衍生品数据_上_OT_CVD_Funding_Depth.md`（OI、CVD、Funding、Orderbook Depth）

## 一、清算（Liquidations）

### 1.0 机制

**清算发生在：交易者的保证金不足以支撑其杠杆仓位时。** 一旦触发阈值，**交易所会用市价单强制平仓**。

> **这会产生"强制性流动（forced flow）"，而不是交易者自主选择的流动（discretionary flow）。**
> **因此，由清算驱动的行情往往发生得很快，并且容易过冲关键水平。**

### 1.1 清算数据能让你洞察三件事

- 市场**哪一侧更拥挤**（crowded）
- 持仓到底有**多脆弱**（fragile）
- **强制流动可能在哪里加速或让行情停滞**

> **在行情运动中，如果 OI 出现大幅下降，通常意味着：若价格在下跌，那多为多头清算；若价格在上涨，那多为空头清算。**
> **这也是为什么 OI 不能孤立地看。**

### 1.2 清算簇（Liquidation Clusters）

**清算常常会"扎堆"**，因为交易者倾向于：
- 使用**相似的杠杆**
- 把**止损放在类似的位置**（例如摆动高点/低点）

**当价格进入这些"清算簇区域"时，可能出现**：

| 现象 | 说明 |
|---|---|
| **瀑布（cascades）** | 强制卖出/买入会推动行情**沿该方向继续扩张** |
| **回弹（snap-backs）** | 强制流动被清掉后，可能出现**迅猛反转** |
| **磁铁效应（magnets）** | 价格会"**漂向**"流动性，以便让买卖双方都能成交 |

> **加密市场尤其容易出现这类事件：杠杆高、波动大、订单簿薄。**

### 1.3 为什么薄簿子会放大清算行情？

**机制**：清算是用市价单执行的。**当订单簿很薄时，附近没有足够的挂单来吸收这些市价单。**
于是，**强制订单必须沿着簿子更远地"走"（walk the book）才能成交，从而造成过大的价格位移。**

**薄簿子会放大清算事件，因为**：
- 市价单需要**走更远的流动性** → K 线更大
- **每一次清算都会触发新的清算** → 形成连锁反应
- **滑点变大** → 即使小订单也会不成比例地推动价格
- **点差扩大** → 波动加速
- **被动流动性消失** → 做市商在波动尖刺时撤单

**因此，清算瀑布几乎总发生在以下环境中**：
- **深度低**（low depth）
- **点差扩大**（widening spreads）
- **高杠杆**（high leverage）
- **OI 上升**（rising OI）
- **参与度低**（low participation）

> **一句话：强制市价单 + 薄流动性 = 夸张行情。这就是清算瀑布的核心机制。**

### 1.4 Z-Score 变换（标准分数）

**问题**：原始时间序列会跳得很厉害。不同资产本来就会有不同的清算规模（成交量更大、参与者更多、OI 更高等）。高波动环境也会进一步扭曲数据。

**标准化方法**：
```
zscore = (value - mean) / standard deviation
```
**它把指标变成"相对极端程度"的度量，而不是绝对数值。**

### 1.5 为什么要用 Z-Score 看清算？

- 它能**高亮清算量异常高（或异常低）的时刻**
- 它会**根据近期环境与波动做调整**，避免把"正常行为"误判成极端
- 它能**更早识别"压力事件（stress events）"**，甚至在价格完全反应之前
- **过滤噪音**，让尖刺更清晰、更可比

**特别有用的场景**：
- 识别**正在形成的清算瀑布**
- 区分**普通止损出局 vs 真正恐慌**
- 量化"**投降式**"出清（capitulation）
- 给系统加入**统计结构**（statistical structure）

> 本质上，它告诉你：**这次清算相对最近 N 个周期到底有多"猛"，即便原始数值看起来不大。**

### 1.6 交易者实际怎么用？

- **高 z-score 的清算尖刺**，常与"**末端衰竭**"相关（end-of-move exhaustion）
- **突破但清算 z-score 很低**，往往意味着**持仓压力不大，更可能延续**
- **极端读数 + OI 下降** → 常意味着**强制行情快结束了**
- **极端读数 + OI 上升** → 说明**新的杠杆还在进入，趋势可能被延续**

## 二、成交量 Delta（Volume Delta）

### 2.0 定义

**成交量 Delta 衡量的是：单根 K 线内"市价买"和"市价卖"的净差值。**

> **与 CVD 不同，CVD 是把差值随时间累加；而 Volume Delta 是逐 K 重置的"当根净差"。**

**它让你看到**：每根 K 线是谁赢了、主动性如何在短期内切换——**这种切换往往发生在更大级别行情推进时**。

- **Delta 为正** → 市价买多于市价卖
- **Delta 为负** → 市价卖多于市价买

### 2.1 Volume Delta 与 CVD 的区别（易混淆）

| 指标 | 累加方式 | 视角 |
|---|---|---|
| **CVD** | 把买/卖主动性**随时间累加** | **宏观视角**（macro view），展示"主动性趋势" |
| **Volume Delta** | **每根 K 线重置** | **微观视角**（micro view），展示"这一根谁更主动" |

> **两者服务不同目的。**

### 2.2 把 Volume Delta 与价格一起读

| 价格 | Delta | 含义 |
|---|---|---|
| **↑** | **正** | **健康上涨**：主动买确实在驱动行情 |
| **↑** | **负** | **弱突破**：卖方在吸收，突破可能失败 |
| **↓** | **负** | **受控下跌**：主动卖在主导 |
| **↓** | **正** | **吸收或卖方被困**：常见**反转或挤压信号** |

### 2.3 Delta 背离

| 现象 | 含义 |
|---|---|
| 价格创新高，但 Delta 的**高点更低** | 主动买在**减弱**，上行可能接近**衰竭** |
| 价格创新低，但 Delta 的**低点更高** | 主动卖在**减弱**，下跌可能**放缓或反转** |

### 2.4 Delta 簇（Delta Clustering）

> **把 Delta 当"连续片段"来看，会更有用，而不是只看单根 K 线。**

**连续多根正 Delta 或负 Delta，往往代表主动性行为（initiative behavior）。**

**例子**：
- **VWAP 上方连续正 Delta** → 买方**有意图地**进场
- **价格失败 VWAP 后连续负 Delta** → 卖方主导
- **关键水平附近的 Delta 簇** → **突破/跌破前的蓄力**

> **簇体现的是"意图（intent）"，不只是结果。**

## 三、多空比（Long-Short Ratio）

### 3.0 定义

**多空比展示的是：某交易所里，持有多仓的账户数量与持有空仓的账户数量的比例。**

> ⚠️ **它常被当作情绪指标，但限制很大，绝不应当被当作方向信号。**

- **Ratio > 1** → 更多账户是**多**
- **Ratio < 1** → 更多账户是**空**

> **仅此而已。它统计的是"账户数量"，不是仓位规模、不是信念、也不是杠杆。**

### 3.1 这个比率真正反映了什么？

**因为它统计的是账户数而非名义金额，多空比主要反映散户情绪。**

**高比率往往意味着**：
- 很多**小账户在做多**
- 群体**偏向一侧**
- 一旦价格反向，**可能形成陷阱**

**低比率则相反**：群体更偏空。

> **但再次强调：这是账户数，不是风险规模。**

### 3.2 为什么它不太可靠？

交易者把它当背景噪音，主要因为：
- **一个大户的仓位能抵得上成千上万个小账户**
- 它**忽略杠杆与仓位大小**
- 它**无法捕捉跨多个交易所的持仓**
- 它**不显示现货敞口**
- 它经常反映的是**散户过度站队**，而非真实流动

> **因此，它更多被当作"温和的反向指标"（soft contrarian），而不是预测工具。**

### 3.3 交易者实际怎么用？

即便有这些限制，它仍有一些实用用途：
- **极端读数**：提示散户明显偏向一侧
- **拥挤持仓**：常与**挤压（squeezes）**对应
- **搭配资金费率**：识别"**群体在付费去做错方向**"
- **搭配 OI**：判断这群体是否真的"**重要**"（有没有规模）

**例子**：
- **多空比极高，但 OI 走平** → 可能只是很多小散户多单，**规模不大，信号弱**
- **多空比极高 + OI 快速上升 + 资金费率为正** → 说明**散户在用杠杆扎堆做多，陷阱更容易出现**

### 3.4 多空比在什么时候才更有用？

**只有少数情景能提供真正增量信息**：
- **低成交量周末**（散户更主导）
- **小交易所/小币种**（参与者更集中）
- **拥挤叙事下**，作为反向参考
- **极端读数与其他 flow 指标形成共振时**

> **单独使用很弱；结合语境，能帮助你描述"群体偏向"。**

## 四、吃单买/卖量（Taker Buy/Sell Volume）

### 4.0 定义

**Taker Buy/Sell 衡量的是：在一段窗口内，成交量中有多少来自"买方跨价差成交"（市价买）vs "卖方跨价差成交"（市价卖）。**

> **这是观察"谁在主动进攻"的最干净方式之一。**

**与其他指标的区别**：
- **和多空比不同**：它是**实际成交流（executed flow）**，不是情绪
- **和 CVD 不同**：它**不做累加**——只是展示所选窗口内的主动买/卖拆分

- **Taker Buy Volume** = 市价买
- **Taker Sell Volume** = 市价卖

> **哪边更高，哪边就控制了当下的主动流。**

### 4.1 它揭示的是什么？

因为 takers 会推动市场，这个数据能告诉你：
- **哪一侧在主动推动价格**
- **流动是否平衡或失衡**
- 行情是**被主动性推动**，还是只是**薄流动性"滑过去"**
- **上涨是否"真实"**，还是主要**被动吸收**

> **它比多空比或资金费率更直接，因为它基于实际成交量。**

### 4.2 把 Taker Flow 与价格一起读

| 价格 | Taker | 含义 |
|---|---|---|
| **↑** | **buy 占优** | **主动买驱动，强势** |
| **↑** | **sell 占优** | **吸收**：被动卖很强，突破可能失败 |
| **↓** | **sell 占优** | **卖方控制，趋势下跌** |
| **↓** | **buy 占优** | **低位吸收**，可能反转或挤压 |

> **把它当作：比 delta 更干净、时间更短的版本，不一定需要完整 footprint 图也能用。**

### 4.3 Taker 比率（Buy/Sell Ratio）

```
Ratio = Taker Buy Volume / Taker Sell Volume
```

- **= 1** → 中性、平衡
- **> 1** → 买方主动
- **< 1** → 卖方主动

> **这个比率反应很快，因此对突破、新闻驱动的行情、开盘早段波动很有用。**

### 4.4 实战怎么用？

**Taker flow 最有效的用法，是配合结构与关键参考点**：

| 场景 | 判读 |
|---|---|
| **VWAP 附近** | VWAP **上方 taker-buy 占优** → 确认**接受（acceptance）**；VWAP **上方 taker-sell 占优** → 提示**拒绝（rejection）** |
| **区间边缘** | **强 taker flow 穿越水平** → 更像**真突破**；**弱 taker flow 穿越水平** → 更像**假突破** |
| **高 OI 环境** | taker flow 告诉你：**杠杆高的时候到底是谁在"按住油门"** |
| **清算事件** | 你能看到：强制流动是**在被吸收，还是在延伸** |

> 短线交易者很常用 taker 数据，但如果做平滑/平均，它也能扩展到更高时间框架。

### 4.5 Taker Flow vs Volume Delta vs CVD（三者区分）

| 指标 | 定义 |
|---|---|
| **CVD** | 跨多根 K 线**累计**的买卖主动性差 |
| **Volume Delta** | **单根 K 线内部**的买卖主动性差 |
| **Taker Volume** | 主动买量 vs 主动卖量的"**原始成交量**"，**不绑定 K 线** |

> **Taker flow 是最"干净"的，因为它不受 K 线开收价的影响。**

## 五、结语

> 这些工具能帮助你理解：**持仓如何建立、如何出清、在压力下如何反应。**
> **但它们仍然只是语境（context）。**
>
> **清算、Volume Delta、taker flow、多空比能让你看到行情背后的机制，但并不"预测"行情本身。**
> 和第一部分一样，**它们都不应该被孤立交易**。
>
> **真正把它们变成价值的方式，是把它们纳入一个系统，并回测，真正理解你的策略机制，知道它是否确实是正期望（+EV）。**

### 本章需要关注的术语

| 术语 | 一句话 |
|---|---|
| **清算（Liquidation）** | 保证金不足时的强制平仓，产生非自愿市价单 |
| **清算簇（Liquidation Cluster）** | 相似杠杆 / 止损位置扎堆形成的爆仓带 |
| **z-score** | 衡量本次清算相对近期有多极端的标准分 |
| **Volume Delta** | 按成交量口径计算的主动买卖差 |
| **多空比（Long/Short Ratio）** | 按账户数统计的多空比 —— 弱信号，只是温和的反向指标 |
| **Taker Buy / Sell** | 真实的主动买卖量，不绑定 K 线，最干净的短窗指标 |
