# 图鉴 07 · 清算（Liquidations）

> **这一篇讲什么**：强平为什么不是普通成交、清算柱怎么读、瀑布的机制，以及数据的三个坑。
> **配图**：2 张真实行情截图。

**一句话**：**清算是一张「必须成交」的市价单** —— 在什么价位、朝哪个方向，都由不得人。

---

## 一、清算是怎么工作的

带杠杆交易意味着**用抵押品借钱**。交易所要求维持仓位所需的最低权益，称为**维持保证金（Maintenance Margin）**。

**当仓位逆向运动到权益跌破这个门槛，交易所就会替交易者平掉仓位。**
交易者**没有发言权**，而且**一旦触发，就没有机会追加保证金**。

### 为什么这件事超出了单个账户

**因为清算不是一次普通成交。**

**它是一张必须成交的市价单** —— 在**任何能拿到的价位**、朝**仓位做错的那个方向**。

- 被强平的多头 → **被强制卖出**
- 被强平的空头 → **被强制买入**

### 反馈回路

**强制卖出把价格推得更低 → 把更多多头推破维持保证金 → 逼出更多卖出。**

**当杠杆集中在相近的价位上，一次清算就会触发下一次，市场开始瀑布。**

这类瀑布制造了杠杆市场里**最快最猛烈的行情**，而且**一旦拥挤的仓位被清完，它会戛然而止** ——
**这就是为什么沉重的清算簇往往标记的是转折点，而不是趋势的起点。**

## 二、怎么读清算指标

清算画成一张**围绕基线分开的柱状图**，柱子在哪一侧**取决于它制造的压力，而不是被平掉的那个仓位**。

| 类型 | 画法 | 原因 |
|---|---|---|
| **空头清算** | 向上（涨色） | 被强平的空头 = **被强制买入** → 推高价格 |
| **多头清算** | 向下（跌色） | 被强平的多头 = **被强制卖出** → 压低价格 |

**柱高 = 该时段被清算的价值。**

### 读簇，不要读单个事件

**任何杠杆市场里，稳定的涓涓细流都是正常的，几乎没有信息量。**

**重要的是集中度**：一根巨大的尖峰，或**连续一长串沉重的柱子**，意味着**大量仓位在很短时间内被平掉**。

### 方向告诉你谁错了

- **大幅向下的簇** = 杠杆买方被强制卖出，那份卖出**促成了你在上方价格图里看到的下跌**
- **大幅向上的簇** = 杠杆卖方被强制买入，**这是猛烈轧空向上的动力**

### 最有用的读法：簇之后发生了什么

**一个在沉重的多头清算消退后停止下跌的市场，很可能已经耗尽了强制卖压** ——
那波下跌**在相当程度上是机械性的，而不是一次深思熟虑的重新定价**。

## 三、为什么清算会造成瀑布

**杠杆倾向于扎堆。**

用相似杠杆、在相似位置进场的交易者，**维持保证金落在相似的价位上** ——
**所以一个价位上可以挂着极大量仓位的强平点。**

### 连锁过程

1. 价格到达那个价位 → **第一批清算以市价单执行**
2. 那些单**把价格朝同方向推得更远** → 触及下一簇维持保证金
3. 那些仓位也被清算 → **每一轮强制平仓都为下一轮提供了触发它的那波主动性**

[[img:liq-cascade]]

### 瀑布什么时候停

**当拥挤的仓位都没了的时候。**

**没有东西可强平了，主动流骤然停止**，价格**经常急剧反转** ——
**因为这波行情是被强制驱动的，而不是因为有人判断这个资产不值这么多钱。**

> **注**：清算只存在于杠杆市场。现货市场没有保证金要求，因此**没有强制平仓** ——
> **这就是为什么清算数据只覆盖期货和永续。**

## 四、清算数据的局限

| 局限 | 说明 |
|---|---|
| **各交易所上报方式不同** | 清算引擎没有统一标准。各交易所在**如何平仓、是否公布每一个事件还是节流的样本、多久公布一次**上都有差异。**不同交易所之间的数字不能直接比较** |
| **它是单一交易所的** | 一条清算数据流只描述上报它的那个交易所。**跨交易所聚合才能给出「到底洗掉了多少杠杆」的更好画面** |
| **它是向后看的** | 清算指标报告的是**已经执行完**的强制平仓。**要看清算接下来可能发生在哪里，需要清算热力图（Liquidation Heatmap）** —— 它估计的是**杠杆仓位会被清算的位置**，而不是**已经发生的位置** |

### 本篇需要关注的术语

| 术语 | 一句话 |
|---|---|
| **清算 / 强平（Liquidation）** | 交易所因保证金不足强制平掉仓位 |
| **维持保证金（Maintenance Margin）** | 维持仓位所需的最低权益门槛 |
| **清算瀑布（Cascade）** | 强制平仓推价 → 触发更多强平的连锁 |
| **清算簇（Liquidation Cluster）** | 大量清算集中在短时间/少数价位 |
| **清算热力图（Liquidation Heatmap）** | 估计杠杆仓位**将会**被清算的位置（前瞻性） |
