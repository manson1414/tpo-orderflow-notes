阶段 0 · 拍卖理论：一切的地基#

目标：把「市场是拍卖场」这个前提装进脑子。 学完你能：不再问「庄家想干什么」，而是问「这次拍卖成功了吗」。

U0.1 市场不是赌场，是拍卖场#

  • 一句话：价格不是被谁「定」出来的，是被一次次竞价「拍」出来的。
  • 为什么需要：这是整套体系的地基。如果你相信有人在操控价格，你会去找庄家；如果你相信这是拍卖，你会去读拍卖的结果。
  • 怎么看：把市场想成一场持续进行的拍卖会：
  • 卖方挂出他要的价（ask），买方报出他愿付的价（bid）
  • 成交价 = 双方同时点头的那个价
  • 价格动，是因为有人愿意用更差的价格成交了 —— 没有别的原因
  • 常见错误：把「价格下跌」理解成「有人在砸盘」。更准确的描述是：在那个价位上，卖方比买方急。
自测一下

问题价格上涨，最直接的原因是什么？

答案有买方愿意在更高的价格接手。不是「利好消息」——消息只是让人愿意出更高价的理由之一。

  • 延伸阅读：02 拍卖与开盘 §2

U0.2 拍卖的三条底层定律#

  • 一句话：价格是广告，时间是调节器，成交量是裁判。
  • 为什么需要：这三句话解释了「为什么价格会动、为什么会停、什么时候算成功」。它们是后面所有判读规则的总纲。
  • 怎么看： 1. 价格是机会的广告机制 —— 价格变化本身就是在喊：「这里有机会，谁来？」 2. 时间调节每一次机会 —— 同样的价格待得越久，机会越少，参与者越少 3. 成交量衡量每次拍卖的成功程度 —— 成交量是投票器，它告诉你这次试探有没有被认可
  • 常见错误：只看价格、不看成交量。没有成交量支撑的价格移动，是「没成交的广告」，很快会被撤回。
自测一下

问题价格快速冲高但成交量很小，这三条定律里哪一条在提示你？

答案第三条。成交量没跟上 = 这次拍卖没有得到认可。

  • 延伸阅读：02 拍卖与开盘 §2

U0.3 公平价值：大多数人的共识价#

  • 一句话：大多数人愿意成交的那个价格，就是公平价值 —— 日内看，它就是 POC。
  • 为什么需要：有了「公平价值」，你才有「贵」和「便宜」的参照系。没有它，价格只是数字。
  • 怎么看：
  • 公平价值基于共识，不是基于计算
  • 它往往落在 VA（约 70% 成交）以内，更精确地说就是 POC
  • 大多数人接近同一个价值成交；少数人刻意远离这个价值
  • 常见错误：把公平价值当成「正确价格」。它不是正确的，它只是大家都认的。
自测一下

问题少数人为什么要远离公平价值成交？

答案他们要的是成交速度，不是好价格。急着进场或急着离场的人，会接受更差的价。

  • 延伸阅读：02 拍卖与开盘 §3

U0.4 拍卖什么时候启动#

  • 一句话：价格一旦偏离公平价值，一次拍卖就启动了。
  • 为什么需要：它给了你一个明确的「事件触发点」。没有这个点，你分不清「噪音波动」和「真正的拍卖」。
  • 怎么看：启动条件只有一条 —— 价格离开 POC / 价值区。之后看两件事：
  • 成交量有反应 → 参与者在重新评估公平价值 → 可能形成新价值区
  • 成交量没反应 → 参与者不感兴趣 → 价格很快回到均值
  • 常见错误：把每一次价格离开 POC 都当成趋势起点。绝大多数偏离会失败，这正是旋转交易能赚钱的原因。
自测一下

问题价格离开 POC 后，你第一时间该看什么？

答案成交量。它决定这次偏离是「重新定价」还是「没人理」。

  • 延伸阅读：02 拍卖与开盘 §3

U0.5 过度延伸的拍卖与均值回归#

  • 一句话：冲得太快、没有成交量配合的偏离，叫「过度延伸」，通常会回来。
  • 为什么需要：这是你最常遇到、也最容易误判的形态。它是反转交易的主要来源。
  • 怎么看：
  • 价格从 POC / 价值区突然冲出去
  • 成交量没有同步放大
  • 结果是参与者开始失去兴趣 —— 「太贵了 / 太便宜了，我不干了」
  • 市场把价格拉回大多数人认可的价值区
  • 常见错误：追这种突破。它看起来最像「启动」，实际最像「结束」。
自测一下

问题价格冲出 POC，但成交量是萎缩的，你该偏向哪一边？

答案偏向回归。这是做淡出（fade）或旋转（rotation）的机会。

  • 延伸阅读：02 拍卖与开盘 §3

术语 一句话
拍卖（Auction） 价格离开价值区、去试探新价格的过程
公平价值（Fair Value） 大多数成交发生的价格，日内看就是 POC

阶段 1 · 没有人在盯着你#

目标：拆掉「有人专门针对我」这个念头。 学完你能：把注意力从「庄家想干什么」转到「流动性在哪、我该躲哪」。

U1.1 止损猎杀是个幻觉#

  • 一句话：没有人在专门等你的止损。
  • 为什么需要：这个念头会让你做出所有错误决策 —— 放大止损、不敢设止损、扛单。
  • 怎么看：真相不是「你不重要」，而是 —— 在这个尺度里，你的相关性非常小。
  • 你的仓位对价格的直接影响约等于零
  • 价格扫到你的止损，是因为那个位置本来就堆着大量相似的止损
  • 你不是被瞄准的，你是顺带被扫到的
  • 常见错误：因为「怕被扫」而把止损放得很远。结果单次亏损远超你的风控上限。
自测一下

问题如果你的止损被扫了，最可能的原因是什么？

答案你和其他很多人把止损放在了同一个位置。你的止损位置本身就是可预测的信息。

  • 延伸阅读：03 参与者与流动性 §1

U1.2 你是浮游生物#

  • 一句话：你可能会「意外」成为鲸鱼的食物，但鲸鱼就算想找你也看不见你。
  • 为什么需要：它把「被针对」的恐惧，换成了「闪避」的操作目标。
  • 怎么看：把市场想成海洋：
  • 鲸鱼不吃浮游生物，它只是游过去
  • 挡在它路线上的东西会被一起带走
  • 你要学的不是对抗，而是别坐在它的运行轨迹上
  • 常见错误：把「我被扫了」当成「有人要害我」。这让你从「找位置」滑向「找敌人」。
自测一下

问题你无法对抗流动性，那你能做哪三件事？

答案读它、避开它、或者顺着它。 这三条涵盖了所有正确动作。

  • 延伸阅读：03 参与者与流动性 §1

U1.3 谁在交易：流动性构成#

  • 一句话：绝大多数成交量来自算法机器人和散户，它们才是你真正在跟的东西。
  • 为什么需要：你默认的对手方是错的。搞错了对手，你的所有推断都会偏。
  • 怎么看：
  • 每天 >90% 的交易由算法机器人与散户完成，其中算法可能 >70%
  • 算法机器人：机构管理，几跳内开平，提供流动性，它们设定每日的 IB
  • 日内交易者：市场参与者里的主要成分
  • 波段交易者：持仓几天到几周
  • 鲸鱼 / 做市商：大额订单，罕见，但对应罕见的高时间框架事件
  • 常见错误：以为自己是和「主力」在博弈。你日常的对手方是算法 —— 它没有情绪，也没有针对你的意图。
自测一下

问题日内的 IB 主要由谁设定？

答案算法机器人。它们生成 IB，也制造我们赖以呼吸的流动性。

  • 延伸阅读：03 参与者与流动性 §2

U1.4 你。很。可。预。测。#

  • 一句话：只要你不是天才也不是蠢货，你就会和多数人做一样的动作 —— 包括止损。
  • 为什么需要：这是把「普通人谬误」变成可交易信息的关键一步。
  • 怎么看： 1. 你的猴子脑会识别模式 —— 和大家一样 2. 你画着和大家一样的支撑线 3. 线下方一点点就是「失效」，再下面一点就是你的止损 4. 价格扎一下、打掉止损、然后反转
  • 这叫做「千刀万剐式的死亡（Death by a thousand cuts）」
  • 常见错误：以为「我知道这个陷阱了」就能免疫。知道和做到是两回事 —— 要靠改变下单位置，不是靠意志力。

答案不要试图变聪明，要试图模仿大资金。 把剩下的脑力当成镜像神经元，去模仿那些巨脑在做什么。

阶段 2 · TPO 是怎么形成的#

目标：搞清 TPO 图到底在画什么，以及它是怎么被「堆」出来的。 学完你能：自己从零推出一张轮廓，而不是背形态。

U2.1 K 线丢了哪一维#

  • 一句话：K 线告诉你价格去过哪里，不告诉你它在哪停留。
  • 为什么需要：这是 TPO 存在的全部理由。不理解这一点，你会把轮廓图当 K 线看。
  • 怎么看：同一段行情，两种画法：
  • K 线：X 轴是时间 → 你看到的是顺序
  • TPO：X 轴是「该价位被成交的次数」→ 你看到的是分布
  • 停留时间 = 市场对那个价格的认可程度
  • 常见错误：在轮廓图上找「形态」（头肩顶、三角形）。它不是价格走势图，是分布图。
自测一下

问题某个价位被反复交易了很多次，说明什么？

答案市场反复认可这个价格 —— 它是共识区，价格容易在这里停留。

  • 延伸阅读：01 轮廓基础 §1–3

U2.2 时段与字母：TPO 的最小单位#

  • 一句话：每个字母代表一个时间单位（通常 30 分钟）—— 这叫一个「时段」。
  • 为什么需要：字母是 TPO 的原子。不理解字母，你就读不出「谁在什么时候参与了」。
  • 怎么看：
  • 一天被切成若干时段，按字母顺序命名：A、B、C、D…
  • 每个时段结束后，把它交易过的所有价位都打上一个该时段的字母
  • 同一个价位被两个时段访问过，那一行就有两个字母
  • 字母数量 = 访问次数，不是成交量
  • 常见错误：以为字母数量代表成交量。它代表时间：几个时段来过这个价位。
自测一下

问题某价位显示 "A B C"，说明什么？

答案A、B、C 三个时段都在这个价位成交过 —— 它被三次访问。

  • 延伸阅读：01 轮廓基础 §2–3

U2.3 X 轴 / Y 轴：把走势变成分布#

  • 一句话：Y 轴是价格，X 轴是「该价位被交易的次数」。
  • 为什么需要：坐标轴搞反了，整张图就读反了。
  • 怎么看：
  • Y 轴（纵）= 价格，从上到下由高到低
  • X 轴（横）= 次数，从左边起往右增长
  • 每一行是一根横向的柱子，柱子越长 = 这个价位被访问得越多
  • 开盘与收盘通常标在 Y 轴上
  • 常见错误：把 X 轴当时间。轮廓图没有时间轴 —— 时间已经被折叠进字母里了。
自测一下

问题轮廓图往右越长，代表什么？

答案那个价位被越多时段访问过 —— 是成交密集区。

  • 延伸阅读：01 轮廓基础 §3

U2.4 从一个时段长成一张轮廓#

  • 一句话：轮廓不是画出来的，是一个时段一个时段堆出来的。
  • 为什么需要：理解了生成过程，你就能反推：任何一个胖的地方，都是多个时段反复回来的结果。
  • 怎么看：
  • 时段 A 结束 → 只有 A 的价位有字母，轮廓还很瘦
  • 时段 B 结束 → B 覆盖的价位加上 B，轮廓变高
  • 时段 C、D 依次叠加 → 重叠越多的地方，柱子越长
  • 最后柱子最长的那一行，就是 POC
  • 常见错误：以为轮廓是「当天行情的样子」。它是当天所有时段行为的叠加结果。
自测一下

问题一个价位上出现了 4 个字母，最少需要几个时段？

答案4 个（如果每个时段只访问一次）。字母数不可能超过时段数。

  • 延伸阅读：01 轮廓基础 §2–3

本阶段需要关注的术语#

术语 一句话
TPO（Time Price Opportunity） 时间-价格机会：某时段在某价位成交过，记一个字母
时段（Period / TPO Period） 时间单位，通常 30 分钟，用 A、B、C… 命名
轮廓（Profile） 一天里所有时段叠加出来的横向分布图
X 轴 / Y 轴 Y = 价格，X = 该价位被访问的次数
价值区（VA） 成交最密集的那一段，约占 70%
POC 柱子最长的那一行，成交最密集的价位

阶段 3 · 读懂一张轮廓#

目标：能指着任意一张轮廓图，把每条线的名字和作用说出来。 学完你能：一眼看出「贵区」「便宜区」「磁铁」在哪。

U3.1 价值区间 VA / VAH / VAL#

  • 一句话：70% 的成交发生的那一段价格，就是价值区间。
  • 为什么需要：它定义了「贵」和「便宜」的基准线。没有它，你只能看单点价格，判断不了位置。
  • 怎么看：VA 的上边界叫 VAH，下边界叫 VAL，上下各留 15%。它的统计学含义是「均值 ±1 个标准差」。
  • 常见错误：把 VAH / VAL 当铁板支撑阻力。它们只是大多数人成交区的边界，被穿过去是常态。
自测一下

问题价格从 VAL 下方回到 VA 内部，你该想到哪条规则？

答案80% 规则 —— 开盘在昨日 VA 外、又被接受回 VA 内，有 80% 概率走到 VA 的另一端。（见 U8.4）

  • 延伸阅读：01 轮廓基础 §4

U3.2 控制点 POC#

  • 一句话：成交最密集的那一个价位。
  • 为什么需要：它是市场用真金白银投出来的「最公平价格」，像磁铁一样把价格吸回来。
  • 怎么看：图上通常是一根红线或红色带。价格偏离它越远、且没有成交量支撑，回归的概率越大。
  • 常见错误：以为 POC 一定是支撑。它是磁铁，不是墙 —— 价格可以穿过它，只是倾向于回来。
自测一下

问题价格从 POC 上方快速冲高，但成交量没跟上，大概率会怎样？

答案回到 POC 附近。这叫「过度延伸的拍卖」—— 参与者觉得太贵了，不干了。

  • 延伸阅读：01 轮廓基础 §5

U3.3 初始平衡 IB#

  • 一句话：开盘后第一个小时（前两个 30 分钟时段）的价格区间。
  • 为什么需要：它给全天定调，是后面所有「拍卖」判断的基准。IB 宽窄直接预示当天的波动性。
  • 怎么看：A + B 两个时段的最高价和最低价。突破 IBH（上沿）或 IBL（下沿），说明有长周期参与者开始行动。
  • 常见错误：IB 还没成形就急着下单。至少等 2–3 个时段，看清市场在做什么。
自测一下

问题IB 很窄意味着什么？

答案当天可能盘整，但也可能是「挤压」—— 参与者仓位很挤，随时可能来一段快速拉升或跳水。

  • 延伸阅读：01 轮廓基础 §6

U3.4 分布：单 / 双 / 三重#

  • 一句话：一天里形成几个「肚子」，就是几重分布。
  • 为什么需要：双重或三重分布意味着市场换了价值区，不能整体当一个 VA 处理。
  • 怎么看：轮廓上出现两个或三个分离的成交量密集区。
  • 常见错误：三重分布日还把整个轮廓当一个 VA 用，导致目标位算错。
自测一下

问题三重分布日，80% 规则的目标该怎么定？

答案把每个分布当作独立的「一天」，用相邻那个分布的 VA 来定目标，而不是整个轮廓的 VAH / VAL。

  • 延伸阅读：05 策略二 §2.3

U3.5 正态分布：轮廓的理想形状#

  • 一句话：理想状态下，轮廓长得像一条钟形曲线 —— 中间胖、两头细。
  • 为什么需要：它是判断「健康 / 不健康」的标尺。偏离钟形越远，市场越不平衡。
  • 怎么看：
  • 中间厚 = 大多数成交集中在公平价值附近
  • 两头薄 = 极端价格只有少数人接受
  • 两头突然伸出去一小截 = 尾巴，代表拒绝（见 U4.2）
  • 常见错误：以为真实轮廓就该是漂亮的钟形。真实市场很少这么清晰 —— 偏斜、双峰、缺口都是常态。
自测一下

问题一个明显偏斜的轮廓在提示什么？

答案一方在主导。偏斜说明某个方向的参与者更激进，属于不平衡状态。

  • 延伸阅读：01 轮廓基础 §1、§9

本阶段需要关注的术语#

术语 一句话
VA / VAH / VAL 价值区 / 其上沿 / 其下沿，各留 15%
POC 成交最密集的价位，磁铁
IB / IBH / IBL 初始平衡（开盘后前 2 个时段）及其上下沿
单分布 / 双分布 / 三重分布 一天里形成 1 / 2 / 3 个价值区
偏斜（Skew） 轮廓不对称，说明一方主导
钟形曲线 理想轮廓形状，衡量健康度的标尺

阶段 4 · 读出市场的形状#

目标：看到一张轮廓，能说出它「哪里有效率、哪里没有」。 学完你能：一眼判断哪些位置值得关注、哪些是噪音。

U4.1 单印#

  • 一句话：某个价位只出现过一次交易（只有一个字母）。
  • 为什么需要：它标记了「市场快速穿过、没有停留」的地方 —— 低效率区。价格以后回来时容易产生反应。
  • 怎么看：图上某个价位只有孤零零一个字母。连续多个价位都是这样，就是一条单印带。
  • 常见错误：把 1 个单印当确认信号。一个单印不算确认。 要等时间证据。
自测一下

问题单印区出现在一段快速上涨中，价格回落时它更可能起什么作用？

答案支撑。那是买方曾经激进介入、没有遇到对手的位置。

  • 延伸阅读：01 轮廓基础 §7

U4.2 买入尾 / 卖出尾#

  • 一句话：轮廓底部（买入尾）或顶部（卖出尾）的单印延伸，代表市场在极端位置「拒绝」。
  • 为什么需要：尾巴是大资金表态的痕迹 —— 有人在那个价格激进地接货或砸盘。
  • 怎么看：至少 2 个单印才算尾巴。买入尾 = 低位有激进买盘把价格顶回去；卖出尾 = 高位被卖方压下来。
  • 常见错误：把 1 个单印叫尾巴。数量不够，说明力度不够。
自测一下

问题伦敦时段出现一根卖出尾，下一个时段你应该偏向哪个方向？

答案偏空。典型链条是：卖出尾 → 随后形成弱低点（进一步确认）→ 下一时段回测卖出尾的价位。

  • 延伸阅读：01 轮廓基础 §10、03 参与者与流动性 §4

U4.3 弱高 / 弱低#

  • 一句话：轮廓顶部或底部收敛结束，既没有尾巴、也没有厚实的成交堆积。
  • 为什么需要：说明那一侧「决心不足」。它们是低效率，价格倾向回去看一眼。
  • 怎么看：顶部或底部平坦，字母数量没有明显衰减。多个弱高点叠在一起时，像磁铁一样吸引价格。
  • 常见错误：以为弱高点是强阻力。恰恰相反 —— 弱是它的名字，它容易被扫掉。
自测一下

问题出现 3 个未被触碰的弱高点，价格大概率会怎样？

答案被吸引过去「扫一下」。但注意 —— 被扫 ≠ 被接受，扫完经常就反向。

  • 延伸阅读：01 轮廓基础 §8、04 策略一 §5

U4.4 HVN / LVN#

  • 一句话：成交量密集的价格带（HVN）和稀疏的价格带（LVN）。
  • 为什么需要：价格在 HVN 容易停留，在 LVN 容易加速穿过。这直接决定你的止损该放哪。
  • 怎么看：HVN = 轮廓「胖」的地方；LVN = 轮廓「瘦」的地方，通常对应单印带。
  • 常见错误：在 LVN 里等回调。那里根本没有成交，价格不会回头。
自测一下

问题价格冲进一段 LVN，你该期待快速穿过还是慢慢磨？

答案快速穿过。LVN 是「加速带」。

  • 延伸阅读：01 轮廓基础 §11、03 参与者与流动性 §5

U4.5 形状总览：一眼分类#

  • 一句话：把所有形状放在一起看，你会发现它们只有几类。
  • 为什么需要：分类是判断的第一步。不知道「这是什么形状」，就没法决定「该做什么」。
  • 怎么看：记住四个基本类型：
  • 正常分布 → 钟形，区间日，做旋转
  • P 形 → 上方堆积，先跌后涨或逼空回补，必须结合语境（见 U6.1）
  • b 形 → 下方堆积，先涨后跌或挤压
  • 双 / 三重分布 → 换过价值区，分段处理
  • 常见错误：看到 P 形就做空。同一个形状在不同语境下结论完全相反 —— 这是下一阶段要解决的问题。
自测一下

问题为什么 P 形和 b 形不能单独使用？

答案因为它们只描述「堆积在哪一侧」，不描述市场处于什么背景。同一形状在趋势里和区间里含义相反。

  • 延伸阅读：01 轮廓基础 §11、06 语境与节奏 §2

本阶段需要关注的术语#

术语 一句话
单印（Single Print） 只有一个字母的价位，低效率区
买入尾 / 卖出尾（Buying / Selling Tail） 底部 / 顶部的单印延伸，至少 2 个单印
弱高 / 弱低（Poor High / Poor Low） 收敛结束、没有尾巴的顶部 / 底部，容易被扫
HVN / LVN 高成交量节点（停留）/ 低成交量节点（加速）
P 形 / b 形 上方堆积 / 下方堆积的轮廓形状
拒绝（Rejection） 极端价位被市场明确否定，留下尾巴

阶段 5 · 今天是哪种日子#

目标：开盘两小时内，说出今天是趋势日还是区间日。 学完你能：不再用同一种打法对付所有行情。

U5.1 四种开盘形态#

  • 一句话：开盘后两小时的价格行为，决定今天是趋势日还是区间日。
  • 为什么需要：选错「今天的性格」，后面所有操作都会拧着来。
  • 怎么看：按信念强度排序 ——
  • Open-Drive（直接走）→ 趋势日，禁止逆势淡出
  • Open-Test-Drive（先试一下再走）→ 趋势日，顺势为主
  • Open-Rejection-Reverse（先被拒绝再反向）→ 仍是趋势日，但形成更慢
  • Open-Auction（开盘就在区间里磨）→ 区间日，只适合旋转 / 剥头皮
  • 常见错误：在 Open-Drive 里逆势淡出。这是最容易亏大钱的动作。
自测一下

问题开盘先向下试了一下，然后迅速调头贯穿 IB 跑到另一侧，这是哪种？

答案Open-Test-Drive。趋势仍然清晰，不要逆势。

  • 延伸阅读：02 拍卖与开盘 §5

U5.2 拍卖成功 vs 拍卖失败#

  • 一句话：突破 IB 之后能不能在 IB 外面站住，决定拍卖是成功还是失败。
  • 为什么需要：这是最核心的分支判断 —— 决定你做延续还是做回归。
  • 怎么看：两个指标 ——
  • 短期：价格在 IB 外站住 ≥30 分钟（1 个完整时段）→ 确认；少于 30 分钟回到 IB 内 → 失败
  • 长期：当日收盘是否在 IB 外
  • 常见错误：突破就算成功。必须站住，一瞬间扎出去不算。
自测一下

问题C 时段突破 IB 向上，但 C 时段内就开始回落，D 时段回到 IB 内。成功还是失败？

答案失败。这时 D 时段就是做空的机会。

  • 延伸阅读：04 策略一 §1

U5.3 趋势日 vs 区间日#

  • 一句话：薄轮廓 + 单边踏步 = 趋势；矮胖均匀 = 区间。
  • 为什么需要：它决定你今天该顺势还是该做旋转 —— 用错打法比不做还糟。
  • 怎么看：看三点 —— 轮廓厚度、是否 one-timeframing（见 U7.2）、IB 的相对宽窄。
  • 常见错误：在区间日追趋势，在趋势日做淡出。这是最常见的两类亏损。
自测一下

问题IB 很窄 + 轮廓很薄 + 每个时段都创新高。这是什么日？

答案趋势日。而且是很强的那种。

  • 延伸阅读：07 动量与形态 §3②

U5.4 练习：给开盘两小时定性#

  • 一句话：把「猜今天是什么日」练成条件反射，靠的是重复，不是天赋。
  • 为什么需要：这个判断每天都要做一次。做不熟，你每天都在临场编。
  • 怎么看：一套可重复的练习法 —— 1. 回看前几天，识别开盘形态，推测当天会是哪种 IB 形态 2. 把闹钟设在开盘 2 小时后（30 分钟一个时段：A、B、C、D 共 4 个时段） 3. 尽量在这 2 小时内写下你的判断 4. 先不实盘，只训练眼睛和大脑 5. 统计一周能做对多少次
  • 常见错误：跳过练习直接实盘。你会用真钱交学费，而且不知道自己错在哪。
自测一下

问题为什么截止时间设在开盘后 2 小时？

答案那时 A、B、C、D 四个时段已经走完，IB 和开盘形态都已经成形 —— 再晚就错过可操作的窗口了。

  • 延伸阅读：02 拍卖与开盘 §7

本阶段需要关注的术语#

术语 一句话
Open-Drive 开盘直接单边走，最强趋势日
Open-Test-Drive 先试探再反向贯穿 IB，趋势日
Open-Rejection-Reverse 先被拒绝再反转，趋势形成更慢
Open-Auction 开盘即在区间内磨，区间日
拍卖确认（≥30 分钟） 在 IB 外站住一个完整时段
趋势日 / 区间日 薄轮廓单边 / 矮胖均匀

阶段 6 · 建立语境#

目标：养成「先看背景、再看形态」的习惯。 学完你能：不再孤立地解读任何一个形态。

U6.1 为什么语境优先#

  • 一句话：同一个形态，在不同背景下结论完全相反。
  • 为什么需要：这是整套体系里最重要的一条 —— 没有语境，所有形态都会把你带进陷阱。
  • 怎么看：固定顺序 —— 先定大方向 → 再定关键水平 → 最后才看形态。
  • 常见错误：看到 P 形就做空。P 形在下跌趋势里可能是「挤压的 D 形」，代表要涨，不是逼空回补。
自测一下

问题下跌趋势里出现 P 形，什么条件下它才代表「逼空回补」？

答案肚子最后形成的时候。如果先形成肚子、后形成 P 的腿，那是挤压形态，含义相反。

  • 延伸阅读：06 语境与节奏 §0、§2

U6.2 市场结构#

  • 一句话：先看周线 / 日线，确定现在是上涨、下跌还是震荡。
  • 为什么需要：顺趋势的交易胜率高得多。逆势很酷，但风险极高。
  • 怎么看：周线方向 + 关键高低点 + 是否在两个水平之间「框架化（bracketing）」。
  • 常见错误：在下跌趋势里抄底。2019 年以来趋势反转的概率只有 0.36%（2513 天里只有 9 天）。
自测一下

问题你不确定方向时，正确动作是什么？

答案不交易。 「如果你不确定，或者市场非常震荡，那就别做这一单，坐着看就好。」

  • 延伸阅读：06 语境与节奏 §A

U6.3 关键水平#

  • 一句话：年开盘、年高 / 低、区间线、SMA200、锚定 VWAP —— 价格会在这里产生反应。
  • 为什么需要：这些是心理障碍位。价格靠近时会减速、纠缠，有时会反转。
  • 怎么看：价格靠近关键水平时，找「延续」或「反转」的证据。多数情况是磨一阵再穿过去。
  • 常见错误：以为每个关键水平都会反转。更常见的是磨蹭后刺穿。
自测一下

问题价格「像长矛一样」直接穿过关键水平，说明什么？

答案某个大参与者（鲸鱼）决定在这些水平上砸盘或扫货。这很少见，是强信号。

  • 延伸阅读：06 语境与节奏 §B

U6.4 节奏（Tempo）#

  • 一句话：价格变化的速度，本质是市场的「信念强度」。
  • 为什么需要：节奏加速 = 确认；节奏衰竭 = 止盈信号。这是出场判断的核心工具。
  • 怎么看：价格接近已知水平时降速，穿越未知区域时加速。跟人走夜路一样 —— 到了熟悉的地方就慢下来。
  • 常见错误：把节奏当成波动率。它们是两回事 —— 节奏讲的是决心，不是振幅。
自测一下

问题价格接近年开盘时明显放慢，你该更激进还是更谨慎？

答案更谨慎。降速说明参与者在犹豫，突破失败的概率上升。

  • 延伸阅读：06 语境与节奏 §2

本阶段需要关注的术语#

术语 一句话
语境（Context） 形态所处的市场背景；脱离语境的形态没有意义
市场结构（Market Structure） 周线 / 日线的方向与关键高低点
框架化（Bracketing） 价格在两个水平之间来回，形成区间
关键水平（Key Level） 年开盘、年高低、SMA200、锚定 VWAP 等心理障碍位
节奏（Tempo） 价格变化速度，等价于信念强度
期望值（Expectancy） 长期每笔交易的平均结果，必须建立在自己的统计上

阶段 7 · 识别动量#

目标：能区分「真正有驱动力的动作」和「机械发生的噪音」。 学完你能：知道哪些形态值得跟，哪些必须无视。

U7.1 信念标记 vs 机械标记#

  • 一句话：有些形态是「被驱动的」（信念），有些只是「机械发生」（噪音）。
  • 为什么需要：机械标记脱离语境会把你坑死 —— 它们一直在发生，但不代表任何事。
  • 怎么看：
  • 信念标记 = 不平衡、区间延伸、one-timeframing、更大级别买方 / 卖方控制
  • 机械标记 = 过度（excess）、弱高 / 弱低、失败的区间延伸、回补
  • 常见错误：看到弱高点就做空。先问一句：「这么多弱高点，但一个都没被扫掉。为什么？」 —— 答案在语境里。
自测一下

问题一堆弱高点一个都没被扫掉，说明什么？

答案市场没有动力去回访它们，可能处于强趋势中（趋势日不会回头扫这些小结构）。

  • 延伸阅读：07 动量与形态 §2

U7.2 One-timeframing（单边踏步）#

  • 一句话：每个时段都只朝一个方向推进，不回头测试前一时段。
  • 为什么需要：这是最强的动量信号。它的终止往往是反转的第一警告。
  • 怎么看：逐时段看 —— 如果某个时段没有向前一时段的第一根 TPO 反向交易，就是 one-timeframing。
  • 常见错误：在 one-timeframing 里做逆势。方向性信念极强，别挡路。
自测一下

问题one-timeframing 突然终止（出现反向 TPO），意味着什么？

答案动量减弱或结束的第一警告。注意是「第一」警告，不是反转确认。

  • 延伸阅读：07 动量与形态 §3①

U7.3 Range Extension（区间延伸）#

  • 一句话：价格先在窄区间里磨，然后带着信念突破 IB 向外延伸。
  • 为什么需要：这是「拍卖启动」的明确信号 —— 动量来了。
  • 怎么看：先有一个窄区间（常与 VA 重叠），然后价格突破 IB 并继续走。
  • 常见错误：把区间内的假突破当延伸。关键是突破之后有没有延续。
自测一下

问题突破 IB 但成交量没跟上，算不算 range extension？

答案要警惕。关键是「带着信念突破」—— 没有成交量配合的突破更容易失败。

  • 延伸阅读：07 动量与形态 §3③

U7.4 Spike 与 POC 迁移#

  • 一句话：Spike 是极端位置的动量冲击（属于「过度」）；POC 迁移是价值中心在移动。
  • 为什么需要：Spike 常标志该方向动量结束；POC 迁移确认趋势正在构建。
  • 怎么看：
  • Spike：出现在时段的极端位置（开盘或收盘附近），是一种 excess
  • POC 迁移：连续多个交易日朝一个方向移动 → 中期动量确认
  • 常见错误：追 spike。市场讨厌过度，因为它们是低效率 —— 所以 spike 常是反向信号。
自测一下

问题POC 连续 3 天向上迁移，说明什么？

答案中期动量在构建，更大级别的一方在控制。但盘中（当日）的 POC 迁移不要过度依赖 —— 后续时段可能很快反向。

  • 延伸阅读：07 动量与形态 §3④⑤

本阶段需要关注的术语#

术语 一句话
信念标记（Conviction Marker） 由真实驱动力产生的形态，值得跟
机械标记（Mechanical Marker） 机械发生的形态，脱离语境没有意义
One-timeframing 每个时段都单向推进，最强动量信号
区间延伸（Range Extension） 窄区间后带信念突破 IB
尖刺（Spike） 极端位置的动量冲击，属「过度」
POC 迁移 价值中心连续向一个方向移动
过度（Excess） 价格冲过头的部分，通常会被回补

阶段 8 · 可交易的策略#

目标：把前面学的判断，变成可以下单的具体打法。 学完你能：手上有一套明确的 setup，而不是「感觉要涨」。

U8.1 拍卖交易#

  • 一句话：拍卖成功就顺势做延续，拍卖失败就淡出新尝试、做反向。
  • 为什么需要：这是把「判断」变成「操作」的第一条路径，也是最主线的一条。
  • 怎么看：确认拍卖点 → 看时段收盘相对拍卖点的位置 → 收盘在上方就预期继续上拍，反之亦然。
  • 常见错误：拍卖失败后还追同方向。失败意味着长周期参与者没成功，下次他们会在同一水平做反向。
自测一下

问题拍卖失败后，第一目标通常放在哪？

答案POC 下方。因为均值回归的第一站就是 POC。

  • 延伸阅读：04 策略一 §5-II

U8.2 弱高 / 弱低扫掠#

  • 一句话：多个未被触碰的弱高 / 弱低像磁铁，吸引价格去「扫一下」。
  • 为什么需要：这是相对高胜率的短打机会，逻辑清晰、目标明确。
  • 怎么看：找重复出现的、仍未被触碰的弱高 / 弱低 → 等价格过去扫。
  • 常见错误：扫到之后不走。原则是：除非这个动作有拍卖支持，否则扫掉之后就该走。
自测一下

问题扫掉弱低点之后，什么情况下可以继续持有？

答案出现了拍卖成功或被接受的证据（价格在下方站住、成交量配合）。否则扫完就反向。

  • 延伸阅读：04 策略一 §5-I

U8.3 旋转交易（Rotation）#

  • 一句话：在 VA 边缘或日内极端位置淡出，目标回到 POC。
  • 为什么需要：这是均值回归的标准打法，区间日的主力策略。
  • 怎么看：前提是没有强动量标记 —— 没有 one-timeframing、没有 range extension、POC 没有多日迁移。
  • 常见错误：在趋势日做旋转。趋势日里价格不会回到 POC，它会一路走。
自测一下

问题什么情况下绝对不能做旋转？

答案出现 one-timeframing、range extension 或 POC 多日同向迁移时 —— 这些说明动量在，价格不会回归。

  • 延伸阅读：04 策略一 §5-III

U8.4 80% 规则#

  • 一句话：开盘在昨日 VA 外，被接受回 VA 内后，有 80% 概率走到 VA 的另一端。
  • 为什么需要：这是最机械化、最容易验证的一条规则，适合作为第一个实战 setup。
  • 怎么看：等「被接受」的确认 —— 多根时间单位站稳，不是一个瞬间扎针。
  • 常见错误：不等确认就进场。「现实从不如理论顺滑，价格很少走直线」—— 不等确认，止损再宽也会被扫。
自测一下

问题三重分布日怎么用这个规则？

答案把每个分布当作独立的「一天」，用相邻分布的 VA 来定目标。

  • 延伸阅读：05 策略二 §2

U8.5 Tetris（俄罗斯方块）#

  • 一句话：把多个 profile 合并，找出未填补的缺口，价格会被吸引过去。
  • 为什么需要：它告诉你「哪里会被吸引」，是方向线索。
  • 怎么看：右键选中 profile →「Merge with previous profile section」→ 重复操作 → 看合并后哪里还有粗糙地形。
  • 常见错误：以为缺口一定会补。它不告诉你「什么时候」 —— 时机必须来自语境 + 节奏确认。
自测一下

问题Tetris 找到缺口后，还需要什么才能进场？

答案语境（大方向）+ 动量 / 节奏确认。不能只靠「缺口一定会补」入场。

  • 延伸阅读：05 策略二 §1

本阶段需要关注的术语#

术语 一句话
拍卖点（Auction Point） 第一个走出 IB 的那个点
拍卖确认 / 失败 在 IB 外站住 ≥1 个时段 / 未站住就回落
扫掠（Sweep） 价格去触碰未被打掉的弱高 / 弱低
旋转（Rotation） 在区间边缘淡出、目标回 POC
80% 规则 从 VA 外被接受回 VA 内 → 走到另一端
Tetris（合并轮廓） 多日 profile 合并找未填补缺口
Round-trip（来回打脸） 浮盈回吐成亏损，必须避免

阶段 9 · 用订单流确认#

目标：把「位置对了」升级成「位置对了 + 有人在动手」。 学完你能：过滤掉大量假突破。

U9.1 订单簿（DOM）#

  • 一句话：所有挂单的清单，告诉你流动性有多深。
  • 为什么需要：价格移动需要流动性。看懂簿子，才知道价格能走多快、哪里会减速。
  • 怎么看：中间是成交价；上方是卖单（ask），下方是买单（bid）。价格每移动一次，对应一侧会生成新的挂单 —— 价格上涨时下方生成新 bid，下跌时上方生成新 ask。
  • 常见错误：把「墙」当真实。大多数买墙卖墙在价格靠近时都会消失（诱骗挂单 / spoofing）。
自测一下

问题簿子很薄的时候，价格移动会更快还是更慢？

答案更快。薄簿子意味着更小的市价单就能推动更大的价格位移。

  • 延伸阅读：10 订单流三件套 §1、12 衍生品数据（上） §5

U9.2 足迹图（Footprint）#

  • 一句话：把每根 K 线的成交量拆成 bid / ask 两侧显示。
  • 为什么需要：让你看到一根 K 线内部发生了什么，而不只是开高低收四个数。
  • 怎么看：对角线读，它不是镜像。 空隙下方左侧 = 成交的 bid；空隙上方右侧 = 成交的 ask。简化记法：右胖 = 价格上冲；左胖 = 不上冲；两边都胖 = 平衡。
  • 常见错误：当成镜像读，把 bid 和 ask 看反。
自测一下

问题足迹图右侧明显更胖，说明什么？

答案主动性买盘占优，价格倾向向上。

  • 延伸阅读：10 订单流三件套 §2

U9.3 Delta 与 CVD#

  • 一句话：Delta 是单根 K 线的主动买卖差，CVD 是它的累计。
  • 为什么需要：它告诉你「谁在更主动」—— 这是判断真假突破的关键。
  • 怎么看：Delta 逐根重置（微观视角），CVD 跨 K 线累加（宏观视角）。用 HTF CVD（1H / 4H / 日）定方向，用 LTF CVD（1m / 5m / 15m）定执行。
  • 常见错误：单独用低周期 CVD。低周期 CVD 本身噪音很大，绝对不要单独使用。
自测一下

问题突破之前 CVD 是「先逐步堆起来」，还是「突破那一下才突然尖刺」—— 哪个是真需求？

答案「先堆起来」是真需求（build before the break）；「突破时尖刺」往往是假突破。

  • 延伸阅读：11 CVD 完全指南 §1、13 衍生品数据（下） §3

U9.4 吸收 vs 衰竭#

  • 一句话：CVD 和价格背离时，要么是有大单在承接（吸收），要么是主动方没力气了（衰竭）。
  • 为什么需要：这是订单流里最强的反转信号，也是区分「真推不动」和「假推不动」的关键。
  • 怎么看：
  • 吸收 = 有隐藏限价单在被动接（对手方强大）→ 结合热力图能看到墙
  • 衰竭 = 主动方自己没劲了（没有对手方）→ 成交量在萎缩
  • 常见错误：把衰竭点当绝对顶底。衰竭点往往不是绝对顶 / 底，而且经常会被再次回踩。
自测一下

问题CVD 上升但价格下跌，这是哪种？

答案买入吸收（Buying Absorption）—— 主动买单被隐藏的限价卖单吃掉了。

  • 延伸阅读：11 CVD 完全指南 §4

U9.5 现货 CVD vs 永续 CVD#

  • 一句话：现货 CVD 是真实需求，永续 CVD 是杠杆情绪。
  • 为什么需要：判断这波行情是可持续还是脆弱。
  • 怎么看：
  • 现货 CVD ↑ 而永续 CVD ↓ → 真实需求进入，杠杆还没参与 → 更可持续
  • 现货 CVD ↓ 而永续 CVD ↑ → 杠杆硬推，现货买家不支持 → 假突破 / 清算瀑布 / 陷阱
  • 常见错误：把杠杆推起来的行情当成趋势。
自测一下

问题哪一种组合更可能形成可持续的上行趋势？

答案现货 CVD 上升 + 永续 CVD 下降（或走平）。现货买家不会因资金费率或清算被强制踢出。

  • 延伸阅读：11 CVD 完全指南 §6.1、12 衍生品数据（上） §3.1

本阶段需要关注的术语#

术语 一句话
DOM（订单簿） 所有挂单清单，反映流动性深度
诱骗挂单（Spoofing） 挂出大单制造假深度，价格靠近就撤
足迹图（Footprint） 把 K 线成交量拆成 bid / ask 两侧
Delta 单根 K 线的主动买 − 主动卖
CVD Delta 的累计值，跨 K 线累加
吸收（Absorption） 主动单被隐藏限价单吃掉，反转信号
衰竭（Exhaustion） 主动方自己没力气了，成交量萎缩
堆叠不平衡（Stacked Imbalances） 连续多档出现单边不平衡，强信号

阶段 10 · 用衍生品判断脆弱性#

目标：知道当前持仓结构有多脆弱、哪里可能爆。 学完你能：避开「看起来很好但随时会崩」的位置。

U10.1 未平仓量（OI）#

  • 一句话：市场上还没平掉的合约总量，代表有多少杠杆在场。
  • 为什么需要：OI 告诉你行情背后有多少「潜在能量」—— 敞口越大，波动潜力越大。
  • 怎么看：必须和价格一起看 ——
  • 价格 ↑ + OI ↑ = 新多头进入，趋势更强
  • 价格 ↑ + OI ↓ = 空头回补，看起来强但更脆弱
  • 价格 ↓ + OI ↑ = 新空头进入，下跌更强
  • 价格 ↓ + OI ↓ = 多头平仓 / 被清算，恐慌出逃
  • 常见错误：以为 OI 能告诉你多空方向。每个多头必然对应一个空头，OI 只反映总敞口。
自测一下

问题价格上涨但 OI 下降，这个上涨健康吗？

答案不健康。这是空头回补推动的，一旦回补结束，上涨就失去动力。

  • 延伸阅读：12 衍生品数据（上） §2

U10.2 资金费率（Funding）#

  • 一句话：永续多空之间的周期性支付，用来把合约价格锚回现货。
  • 为什么需要：它衡量「持仓压力」—— 谁在付钱、付多少、能付多久。
  • 怎么看：正费率 = 多头拥挤（多头付给空头）；负费率 = 空头拥挤。关键是「极端 + 持续 + OI 上升」三者同时出现才危险。
  • 常见错误：以为极端费率会自动导致反转。高 / 低费率本身不会导致反转 —— 要看极端持续多久、OI 在升还是降。
自测一下

问题现货持续买入，同时资金费率为负，哪一边会被套？

答案空头。「现货趋势很强，而永续一侧出现极端资金费率的反向信号，永续那一侧通常会输。」

  • 延伸阅读：12 衍生品数据（上） §4

U10.3 清算（Liquidations）#

  • 一句话：保证金不足时的强制平仓，产生「非自愿」的市价单。
  • 为什么需要：清算驱动的行情又快又容易过冲 —— 知道它，才不会在瀑布里被卷走。
  • 怎么看：找清算簇（交易者倾向用相似杠杆、把止损放相似位置，所以会扎堆）。用 z-score 判断这次清算相对近期有多「猛」。
  • 常见错误：追清算瀑布的第一根。正确做法是降低仓位，或只做确认后的回踩 / 反转。
自测一下

问题清算瀑布需要哪五个条件同时具备？

答案深度低 + 点差扩大 + 高杠杆 + OI 上升 + 参与度低。

  • 延伸阅读：13 衍生品数据（下） §2

U10.4 多空比与 Taker Flow#

  • 一句话：多空比是散户情绪（弱信号），Taker Flow 是实际成交流（强信号）。
  • 为什么需要：区分「谁在说话」和「谁在动手」—— 前者噪音大，后者才是钱。
  • 怎么看：
  • 多空比只统计账户数量，不是仓位规模。单独用很弱，必须配合 OI
  • Taker Buy / Sell 是真实的主动买卖量，不绑定 K 线，是「最干净」的短窗主动性指标
  • 常见错误：单独用多空比做方向判断。它只是「温和的反向指标」。
自测一下

问题多空比极高，但 OI 走平。这个信号强吗？

答案弱。说明只是很多小散户在做多，规模不大。需要 OI 快速上升配合，才说明真有杠杆扎堆。

  • 延伸阅读：13 衍生品数据（下） §4–5

术语 一句话
OI（未平仓量） 未平掉的合约总量，反映总杠杆敞口
OI Delta OI 的变化量，配合价格判断新增 / 平仓
资金费率（Funding） 永续多空的周期性支付，衡量持仓压力

阶段 11 · VWAP#

目标：多一个稳定的价值锚点，用来判断「贵还是便宜」。 学完你能：把 VWAP 和订单流组合成一套确认流程。

U11.1 VWAP 与偏离带#

  • 一句话：按成交量加权的平均价，比普通均线更「黏」价格。
  • 为什么需要：它给出一个稳定的价值锚点，判断价格处于溢价区还是折价区。
  • 怎么看：价格在 VWAP 上方 = 溢价区（可能多头强势）；下方 = 折价区。第 1 / 2 / 3 个标准差带用来衡量「过度延伸」的程度。
  • 常见错误：以为市场一定会回到 VWAP。市场没有义务尊重 VWAP，也没有义务回到 VWAP。
自测一下

问题价格进入 3σ 偏离带，你该警惕什么？

答案过度延伸，警惕均值回归。但注意 —— 延伸本身不是反转信号，需要配合 CVD 背离或衰竭。

  • 延伸阅读：14 VWAP 指南 §3–4

U11.2 VWAP × 订单流#

  • 一句话：VWAP 定位置，订单流定时机。
  • 为什么需要：单用 VWAP 只知道「贵或便宜」，不知道「会不会继续」。
  • 怎么看：回踩 VWAP 时看 CVD 是否维持强势；观察 VWAP 附近有没有堆叠不平衡（stacked imbalances）作为入场信号。
  • 常见错误：VWAP 附近看到买入就进，不看 CVD 配合。
自测一下

问题价格上破 VWAP 时主动买很多，但价格就是不涨，说明什么？

答案买方需要付出明显更大的努力才能推动价格，说明卖方在吸收。这最终会导致下跌延续。

  • 延伸阅读：14 VWAP 指南 §5

本阶段需要关注的术语#

术语 一句话
VWAP 成交量加权平均价，比普通均线更黏价格
锚定 VWAP（Anchored VWAP） 从指定起点（月 / 季 / 事件）重算的 VWAP

阶段 12 · 组装起来#

目标：把前面所有零件拼成一套每天能重复执行的流程。 学完你能：开盘前 10 分钟做完准备，盘中不用临场编。

U12.1 三重确认#

  • 一句话：位置 × 时间 × 流，三个都满足才允许开仓。
  • 为什么需要：这是避免瞎猜的最低门槛。缺任何一条，你就是在赌。
  • 怎么看：
  • 位置：必须发生在结构 / 价值参考点附近（VAH / VAL / POC、单印边缘、tails、VWAP / 偏离带、清算簇、深度墙）
  • 时间：必须有 Profile 的时间确认（接受 / 拒绝 / 失败拍卖），≥1 个完整时段
  • 流：至少 1–2 个流动指标同向，或给出清晰的背离信号
  • 常见错误：只看位置就进。这是最常见的错误 —— 「位置对了」不等于「现在就该进」。
自测一下

问题缺了「时间」这一条会怎样？

答案你会被单根尖刺 K 线诱骗进去。时间确认的作用就是过滤掉这些瞬间假动作。

  • 延伸阅读：15 日内流程·全工具 §5

U12.2 情景剧本#

  • 一句话：开盘前写好 2–3 个「如果……那么……」，并明确写下不交易的条件。
  • 为什么需要：没有计划 = FOMO = 送钱。你没有计划，你就不交易。
  • 怎么看：每个剧本包含六项 —— 触发 / 确认 / 失效 / 止损 / 目标 / 管理。
  • 常见错误：盘中临时改剧本。不追单、不临时改剧本。
自测一下

问题市场走出了你没写进剧本的走势，正确动作是什么？

答案不交易。 你只是 FOMO 追进未知区域，根本不知道会发生什么。

  • 延伸阅读：08 策略蓝图、15 日内流程·全工具 §3

U12.3 每日执行清单#

  • 一句话：把上面所有东西压成一张可重复执行的清单。
  • 为什么需要：流程化的目的是减少临场决策 —— 决策越少，犯错越少。
  • 怎么看：三段 —— 开盘前 ≤10 分钟（定方向、标水平、写剧本）→ 盘中前 2 小时（等 IB、分类、三重确认后进场）→ 盘后 ≤15 分钟（记录、复盘、只改一个点）。
  • 常见错误：清单写了不做。建议先用极小仓位跑 2–4 周，把流程练成条件反射再上仓位。
自测一下

问题盘后复盘最少要记录哪几项？

答案日型（趋势 / 区间）、开盘型（四种之一）、动量标记、你的执行评分，以及下次只改的一个点。

三、核心原则（贯穿全部内容的 6 条）#

  1. 市场是拍卖场，不是赌场。 价格不是被谁「定」出来的，是被一次次竞价「拍」出来的。所有判读都从这个前提出发。
  2. 语境优先于形态。 任何形态（P 形、弱高点、单印）脱离语境都会把你带进陷阱。先定市场结构 → 再定关键水平 → 再看形态。
  3. 时间确认不可省。 Market Profile 的全部优势在于把「时间」显性化。没有时间确认（至少 1 个完整时段站稳），等于在猜。一个单印不算确认。
  4. 所有数据提供的是语境，不是信号。 OI、CVD、Funding、Depth、清算 —— 没有一个能单独作为开仓依据，必须共振 + 回测验证期望值。
  5. 节奏（Tempo）= 信念。 价格在已知水平附近降速、在未知区域加速。节奏加速配合方向 = 确认；节奏衰竭 = 止盈信号。
  6. 不交易也是决策。 市场横盘、看不懂、或出现没写进情景的走势 → 不交易。

一、Market Profile / TPO 核心#

缩写 英文全称 中文 定义与用法
TPO Time Price Opportunity 时间-价格机会 图上每个字母（A、B、C…）代表一个时间单位（通常 30 分钟），表示该时段内市场在某个价格档位发生过交易。价格再次回到同一价位时新增一个字母。
Profile Market Profile 轮廓 一个交易时段（session）内价格分布的整体形状。X 轴 = 某价格被交易的频次；Y 轴 = 价格 + 时间信息。
POC Point of Control 控制点 成交活动最密集的价位。相当于钟形曲线的"均值"。常像磁铁一样吸引价格，可作支撑/阻力。
VPOC Volume Point of Control 成交量控制点 严格按成交量计算的控制点（足迹图里用）。
Naked POC Naked Point of Control 裸 POC 前序时段产生、但至今未被价格回补/未解决的 POC。是潜在的回访目标。
VA Value Area 价值区间 成交最集中的价格带，通常设为总成交量的 70%。等价于"均值 ±1 个标准差"。
VAH Value Area High 价值区间上沿 VA 上边界（通常按 15% 切分）。
VAL Value Area Low 价值区间下沿 VA 下边界（通常按 15% 切分）。
IB Initial Balance（= Opening Balance） 初始平衡 开盘后前 2 个时段（一般 2×30 分钟 = 1 小时）的价格区间，即 A + B 时段。
IBH / IBL Initial Balance High / Low 初始平衡上下沿 IB 的上/下边界。突破 IBH/IBL 是"拍卖"的起点。
Auction Point — 拍卖点 第一个走出 IB 的那个时段。
Single Print Single Print 单印 Profile 中某些价位只出现一个 TPO 字母，说明市场快速穿过、几乎没回头交易。= 不平衡区，未来易成支撑/阻力。
Buying Tail Buying Tail 买入尾 Profile 底部的单印延伸（≥2 个单印才有意义）。表示低位有激进买盘拒绝更低价格，常暗示向上反转。
Selling Tail Selling Tail 卖出尾 Profile 顶部的单印延伸。表示卖方压倒买方把价格压下去，可能暗示下跌延续。

LVN Low Volume Node 低成交量节点 成交量稀疏的价格区，价格穿越速度快，未来易作支撑/阻力/加速带。
pdH / pdL previous day High / Low 前一日高/低点 亦写 pdHigh / pdLow。
pdVA / pdVAH / pdVAL / pdPOC previous day Value Area … 前一日的价值区/上下沿/POC 80% 规则的核心参照。
ONH / ONL Overnight High / Low 隔夜高/低点 隔夜时段形成的极值。
Excess Excess 过度 市场在极端位置留下的"多余"痕迹（尾巴、尖刺）。属低效率，市场讨厌过度 → 常标志该方向动量结束。
Bracketing Bracketing 框架化 / 箱体 价格在两个关键水平之间来回震荡，无趋势。

二、市场状态与动量#

术语 中文 定义
One-timeframing 单边踏步 市场向一个方向趋势运行时，某个时段没有先向前一时段的第一根 TPO 反向交易。方向性信念极强、动量很高。它的终止通常是动量减弱的第一警告。
Trend Day 趋势日 信念略弱于极致单边但依然很强。通常伴随 one-timeframing、很薄的 profile、常为单分布。
Range Extension 区间延伸 价格先在窄区间交易，随后带信念突破 IB 向外延伸。动量存在（参与者启动了拍卖）。
Spike 刺入 / 尖刺 一次动量冲击，常发生在时段极端位置（开盘/收盘附近）。是一种 excess → 常标志该方向动量结束。注意：尖刺不一定是单印，需要自己解释。
POC Migration POC 迁移 价格持续远离原 POC 交易，在别处形成更多 prints 超过原 POC → POC 迁移过去。短期（盘中）表示该方向在被巩固；中期（多日）确认动量在构建。
Value Migration 价值迁移 价值区间整体上移/下移，是趋势方向的核心证据。
Tempo 节奏 价格变化的速度。≠ 波动率，应理解为"信念/决心（conviction）"。价格接近已知水平时降速，穿越未知区域时加速。
Momentum 动量 市场里某件事正在发生的"是什么（what）"与"为什么（why）"。RSI 只给 what，给不了 why。
Conviction Marker 信念标记 被某种东西驱动的标记：不平衡、区间延伸、one-timeframing、更大级别买方/卖方控制。
Mechanical Marker 机械标记 更"机械"地发生、脱离语境会坑人的标记：excess、弱高/弱低、失败的区间延伸、回补等。
Distribution 分布 单分布（single）/ 双重分布（double）/ 三重分布（triple）。双重或三重分布日：把每个分布当作独立的"一天"/独立的 VA 处理。
Initiative / Reactive 主动 / 反应 价格在开盘价上方 → 主动性买入 + 反应性卖出；下方 → 主动性卖出 + 反应性买入。反应对抗主动。
Acceptance / Rejection 接受 / 拒绝 接受 = 需要时间确认（多根时间单位/多段 TPO 站稳），不是瞬间扎针。拒绝 = 尾巴、单印、失败拍卖。

三、订单流（Order Flow / Footprint）#

术语 中文 定义
Order Book / DOM 订单簿 / 市场深度 所有挂单（限价单）的清单。Depth Of Market。
Bid / Ask 买价 / 卖价 最高买价 / 最低卖价。市价买吃 ask，市价卖打 bid。
Footprint 足迹图 把每根 K 线的成交量拆成 bid / ask 两侧显示。对角线读（不是镜像）：空隙下方左侧 = 成交的 bid，空隙上方右侧 = 成交的 ask。
Delta (Δ) 成交量差 市价买 − 市价卖。正 = 主动买多；负 = 主动卖多。逐根 K 线计算。
CVD 累计成交量差 Cumulative Volume Delta。把 Delta 做滚动累加，形成"谁更主动"的运行曲线。
Imbalance 不平衡 某价位 bid 成交量与 ask 成交量之间的差异。默认通常按 10:1 判定。偏买方 = 绿，偏卖方 = 红。
Stacked Imbalance 堆叠不平衡 连续多个价位出现同向不平衡，表示主动性意图。
Absorption 吸收 主动方推不动：CVD 很强但价格位移很小；成交量在增加但价格位移在缩小。= 有隐藏限价单在吸收市价单。
Absorption Divergence 吸收背离（最强） CVD 朝某方向走，价格却无法同向延续。买入吸收：CVD↑ 价格↓（主动买被限价卖吸收）。卖出吸收：CVD↓ 价格↑。
Exhaustion Divergence 衰竭背离（更常见） 价格尝试突破但某侧没有足够力量。买入衰竭：CVD↓ 价格↑。卖出衰竭：CVD↑ 价格↓。注意：衰竭点往往不是绝对顶/底，且常被再次回踩。
Delta Trap Delta 陷阱（V 形反转） 主动方在极端位置疯狂抬价/砸价，撞上强被动挂单墙后立刻反转。CVD 出现巨大成交量柱但价格几乎不动。
Heatmap 热力图 把挂单量可视化到 K 线图上（颜色越热 = 挂单块越大）。颜色越热代表挂单块越大。
Spoofing 虚假挂单 / 诱骗 挂出巨量订单，价格接近时撤掉。大多数买卖墙在价格靠近时都会消失，不要在价格没靠近前假设墙是真的。
Delta Clustering Delta 簇 连续多根同向 Delta，代表主动性行为（initiative behavior）。簇体现"意图"，不只是结果。
Taker Buy / Sell 吃单买 / 卖量 窗口内成交量中来自市价买 vs 市价卖的部分。比 Delta 更"干净"（不受 K 线开收价影响）。

四、CVD 的类型与背离#

术语 中文 定义
Taker CVD 吃单方 CVD 最常见，实时追踪市价单的主动性。
Maker CVD 挂单方 CVD 更少见但很有价值：展示被动流动性（限价单）的行为——是在吸收价格，还是根本不感兴趣。
Spot CVD 现货 CVD 追踪现货交易所的主动成交量。更接近"真实需求"（需要真金白银），长周期更有意义。
Perp CVD 永续 CVD 追踪永续合约市场主动成交量。更偏短线投机、杠杆更高、更情绪化。
Aggregated CVD 聚合 CVD 消除单一交易所偏差，反映全球整体主动流向。
Spot-Perp Divergence 现货-永续背离 现货 CVD↑ 而永续 CVD↓ → 真实需求进入，杠杆尚未参与（更可持续的上行前兆）。现货 CVD↓ 而永续 CVD↑ → 杠杆硬推，长期现货买家不支持（假突破/清算瀑布/陷阱）。

术语 中文 定义
Perpetual Futures 永续合约 无到期日的期货合约，通过资金费率锚定现货。
Mark Price 标记价格 交易所用来计算清算的价格：外部预言机价格 + 资金费率与溢价 + 平滑机制。触发清算用的是 mark price，不是你看到的图表价。

Z-Score 标准分数 (value − mean) / std。把清算量变成"相对极端程度"，避免把正常行为误判为极端。
Long-Short Ratio 多空比 持多仓账户数 / 持空仓账户数。统计账户数而非仓位规模，主要反映散户情绪。只作"温和的反向指标"，绝不单独用。

1. 底层逻辑：正态分布#

正态分布是一条钟形曲线，描述数据点如何分布：大多数数值聚集在均值附近（峰顶），向两侧对称衰减形成"尾部"。

在 Market Profile 里的含义： - 平衡区 = 多数成交发生的地方（钟形曲线的肚子） - 不平衡区 = 极端位置（尾部） - 标准差衡量数据偏离均值的程度：约 68% 的数据落在均值 ±1 个标准差内 → 这个概念直接对应"价值区间（VA）"

核心心智模型：市场渴望钟形曲线。偏离钟形曲线的形态（缺口、单印、粗糙地形）= 低效率 = 迟早被回访修正。

2. TPO（时间-价格机会）#

  • 每一个 TPO（字母 A、B、C…）代表一个时间单位（通常 30 分钟）
  • 表示在那个时间段里，市场曾在某个价格档位发生交易
  • 价格在不同时间再次回到同一价位 → 该价位新增一个字母

关键：把它称为"足迹（footprint）"是理解它的关键。你要做的是沿着价格走过的路径去追踪足迹。

举例：A 时段（开盘后前 30 分钟）价格从 110,900 走到 110,700；B 时段价格从 110,600 走到 110,500；然后又回到开盘价 110,900……以此类推。

把 TPO 图旋转一下，会发现它和钟形曲线非常像。

3. X 轴 / Y 轴 与 Profile#

先回忆 K 线图怎么工作，然后暂时把它忘掉。

K 线图 TPO 图
X 轴 时间 某价格被交易的频次
Y 轴 价格 价格 + 时间信息
  • 每一个 TPO Profile 对应一个"交易时段（session）"：可以是一整天、某个市场时段，或一小时
  • 开盘与收盘标记也显示在 Y 轴上
  • X 轴上足迹越多 = 该价位成交活动越多
  • 区间中央的价格档位会有更多足迹（价格更频繁地在该处穿梭）

简化处理：这里暂时不考虑最小跳动单位（tick size）。

4. 价值区间（VA）#

VA 本质上就是均值 ±1 个标准差的范围。

元素 占比
VA（Value Area，价值区间） 70%
VAH（Value Area High，上沿） 15%
VAL（Value Area Low，下沿） 15%

5. 控制点（POC）#

  • POC = 成交活动最密集的价位。用钟形曲线比喻，它就是"均值"所在的位置
  • 在价格轴上以一条水平线标出，Profile 里对应一条带状区域
  • POC 经常像磁铁一样吸引价格，可能在后续时段充当潜在支撑或阻力
  • 因为这是市场基于成交量找到的"最公平价格"，交易者重点关注它——用来做旋转（rotation）或突破（breakout）的参考

6. 初始平衡（IB）#

  • IB = 前 2 个时段的价格区间（一般 2×30 分钟，共 1 小时），即 A + B 两个时段
  • 在 Profile 左侧以一条竖向带标出
  • 作用：为当日定调，显示买方或卖方早期的"信念/决心"
  • IB 很宽 → 后续波动可能更大；IB 很窄 → 可能盘整
  • 是判断日内方向的关键参考（后续所有"拍卖"策略都基于 IB）

7. 单印（Single Prints）#

  • Profile 里某些价位只出现一个 TPO（只有一个字母）
  • 说明市场快速穿过该区域，几乎没有回头反复交易
  • 提示"不平衡区域"：例如快速的买压或卖压
  • 价格以后回到这些区域时，可能成为未来的支撑/阻力

8. 弱高点 / 弱低点（Poor Highs / Poor Lows）#

  • Profile 顶部或底部结构收敛结束，但没有形成"尾巴（tail）"，也没有形成厚实的成交堆积
  • 含义：买方（在高点）或卖方（在低点）的决心不够强
  • 经常暗示潜在的反转或失败的突破——因为市场并没有"接受"这些极端价位

纽约时段的一个弱低点。注意后续时段把这个弱低点扫掉了。 → 弱低点会被扫掉，这是常态，不是例外。（策略部分「弱高/弱低扫掠」即基于此）

9. 峰度（Kurtosis）与"尾巴"#

峰度衡量分布尾巴的厚度。

峰度 特征 对应行情
高峰度 尾巴更肥、极端价格波动更多、峰值更尖锐 更波动 / 更趋势化的时段
低峰度 尾巴更薄、轮廓更扁平 更平衡 / 区间震荡的时段

Profile 里的"尾巴"代表价格曾经延伸过去、但没能停留的离群区域，往往揭示市场的拒绝点（rejection points）。

10. 买入尾 / 卖出尾（Buying / Selling Tails）#

  • 是 Profile 底部（买入尾）或顶部（卖出尾）的单印延伸
  • 买入尾：低位有激进买盘介入、拒绝更低的价格 → 常暗示潜在向上反转
  • 卖出尾：高位卖方压倒买方把价格压下去 → 可能暗示下跌延续

实操阈值：为了让尾巴"更有意义"，至少要有 2 个单印。

伦敦时段的卖出尾 → 卖压非常强形成不平衡 → 随后形成弱低点（进一步确认）→ 下一个时段回测了卖出尾所在的价位。

目标：理解"市场 = 拍卖"，并能识别四种开盘形态。

一、为什么要做日内#

  • Market Profile 在日内这个时间尺度上最能发挥光芒
  • 做"预测/推演"时，短期（短线）比中期、长期更容易做对
  • 日内交易可以基本忽略加密推特（CT）上的多空叙事

叙事为什么有害：它利用人类心智的弱点——偏见验证（validation of bias）。你的欲望越大，越需要别人来验证你的偏见。抽离出来，意识到你只需要在一个较小的偏见上（比如短期方向）做对，你就可以开始和市场一起呼吸。

行动准则： - 你不需要"祈祷/许愿/盼涨盼跌"，你需要读懂正在发生什么，理解"最可能的下一步"，并在合理情况下尽早把仓位摆好 - 理想情况下，当目标打到时你也要尽早离场 - 如果一笔交易预期能走 2% 对你有利，到了那个点就走，或者至少减仓 - 如果它继续走得更远，不要再追进去——那已经超出你的预测范围了，而且通常"它还能继续走"是有原因的

二、拍卖的三条底层定律#

要真正理解 Market Profile 交易，需要内化三句话：

  1. 价格是机会的广告机制（Price is an advertising mechanism for opportunity）
  2. 时间调节每一次机会（Time regulates each opportunity）
  3. 成交量衡量每次拍卖的成功程度（Volume measures the degree of success of each auction）

推论：价格与成交量告诉我们——在某个价值水平上，谁愿意/不愿意卖出或买入他们的"货"。

  • 大多数人会在接近同一个价值附近成交
  • 少数人则倾向于尽可能远离多数人认定的"公平价值"

三、公平价值（Fair Value）与拍卖的启动#

什么是公平价值？ 公平价值是基于共识的。从日内角度很容易识别：就是大多数成交发生的价格——往往在 VA（约 70% 成交）以内，更具体地说，就是 POC。

拍卖何时启动？ 当价格偏离公平价值 / POC 时，我们就具备了启动一次"拍卖"的条件。

  • 多头与空头进场，成交量（竞价活动）决定这次偏离是否能持续
  • 如果看到足够的成交量反应 → 参与者正在重新评估他们对公平价值的认知
  • 如果成交量没有反应 → 参与者不感兴趣，价格会很快回归均值

回归均值（Mean Reversion）：价格如果偏离它的平均值/公平价值太远，往往会随着时间回到平均值附近。

过度延伸的拍卖：价格从 POC 或价值区突然冲出去，但没有强成交量支撑 → 买方或卖方开始失去兴趣（"这东西太贵/太便宜了，我不干了"）→ 市场拉回大多数人认可的价值区域。

→ 这给了我们做"反向淡出（fade）"或"旋转（rotation）"的机会。

拍卖类比：参与者会希望价格更便宜才愿意接手；有时第一批出价者直接接受"标价"，旁边观望的人害怕公平价值其实更高，抢着出价把价格推上去。 这种事情在市场里每天发生上百万次。你只需要学会去"听懂"它。

四、形态识别的前提#

当你把市场视为拍卖师、把交易者视为竞价参与者，很多东西就会开始变得合理。这种模式经常重复出现，我们的猴子脑会识别它们。

⚠️ 在急着把形态套到图上、想抓"下一波大行情"之前，记住： 这些形态只有放进更大级别的市场环境里、被"语境化"使用时才有意义。

现实提醒： - 即便是精心挑选出来的"最清晰样本"，也已经是能找到的最"教科书"的样子 - 现实中的市场很少这么清晰 - 但只要练习，你就能在交易时段早期读出市场在干什么 - 这些形态是双向的：可以向上也可以向下

五、四种开盘形态（The Four Openings）#

指一些经常在日内早期形成的重复模式。

① Open, Drive（开盘-推动）#

拍卖师报出开盘价，参与者立刻冲进去竞价，价格一路单边走。

拍卖类比："开盘出价 250 万，有人要吗？" → "250 万，开盘价成交！" → "255 万！" → "有人 260 万吗？" → "265 万！"

  • 这是趋势日（trend day）
  • ⚠️ 不要逆势去做"淡出"（DO. NOT. FADE.）

② Open, Test, Drive（开盘-测试-推动）#

参与者先把价格往某个方向推一推，看看那边有没有生意能做；然后很快反向，再一路跑到 IB 的另一侧。

  • 价格会很快打出当日高/低，然后迅速调头，贯穿 IB 去到另一端
  • 通常轮廓很薄，所以价格波动很快
  • 信念比 open-drive 弱，但趋势依然清晰
  • ⚠️ 同样：不要试图逆势，顺着市场方向交易

拍卖类比："有人出 40 万吗？" → 第一排先生说"10 万" → "10 万 2,500！" → "15 万！" → "17 万！" → "有人 20 万吗？"

③ Open, Rejection, Reverse（开盘-拒绝-反转）#

看起来很像 open-test-drive，差别在"细微之处（nuance）"。

  • 相比前两种，信念更弱：尾巴更肥一点，价格波动更慢一点，轮廓更"松散"一点
  • 理解要点：第一次拒绝之后，趋势的形成可能需要一些时间
  • 一些信号（比如多次拒绝且低点抬高）可能让你比别人更早读出来
  • ⚠️ 但它仍然是趋势日。逆势淡出，后果自负。

④ Open, Auction（开盘-拍卖 / 区间）#

价格开盘后就在一个区间里来回交易——这就是盘整/震荡日的定义。

  • 价格整天都在范围内来回"旋转"
  • 这些 Profile 在 Y 轴上很矮（以 BTC 为例大概 1%–2%）
  • 价格会试图回归均值
  • 可能会有一点点向上或向下的小趋势
  • "蟹行时间（Crab time）"
  • 如果你是很熟练的剥头皮（scalper），这是你闪耀的时候。如果不是，那就远离这种行情。

六、四种开盘速查表#

七、练习方法#

  1. 回看前几天，看能否识别出这些开盘形态，并推测当天会是哪种 IB 形态
  2. 把闹钟设在开盘 2 小时后（30 分钟为一个时段：A、B、C、D 共 4 个时段）作为截止时间
  3. 尽量在这 2 小时内写下你的判断
  4. 先不要实盘交易，只是训练眼睛和大脑
  5. 看看你一周能做对多少次

  • 对每个交易日，记录：开盘形态 → 当日实际是趋势日还是区间日

目标：理解流动性的来源，以及为什么"大多数人的止损位置"本身就是可利用的信息。

一、没有人在"盯着你"#

常见误解：很多交易者相信存在"止损猎杀（stop loss hunt）"，相信做市商开着热成像追踪模式，铁了心要把单子挂在你那 150 美金仓位的止损下方。

真相： - 多数人高估了自己的重要性 - 不是你不重要，而是说：在市场这个大尺度里，你的相关性非常小 - 你是浮游生物（plankton）。你可能"意外"成为鲸鱼的食物，但鲸鱼就算想找你也看不见你——你只是挡在它们路上

结论：不要坐在"铲勺"的运行轨迹上。要学的是如何闪开，最好还能顺便和大型鲸类一起游。

这条不是安慰，是操作前提：你无法对抗流动性，只能读它、避开它、或顺着它。

二、流动性构成（Liquidity Composition）#

每天超过 90% 的交易由算法机器人与散户完成（其中算法可能 >70%）。

参与者 特征
算法机器人 主要由机构管理，生成成千上万笔高频交易：几跳以内开仓、几跳以内平仓，为市场提供流动性。它们设定每日的 IB，并制造我们赖以呼吸的空气：流动性。
日内交易者 市场参与者里的主要成分
波段交易者（swing traders） 持仓周期通常从几天到几周
鲸鱼 / 做市商 更高时间框架、更大体量的动作：大额买单或卖单。这种大额订单并不常见，通常对应罕见的高时间框架事件。

关键推论： - 当做市商一次性撮合/记账大额订单时，一定是有原因的 - 热力图可以展示大额订单（如 50–115 手 BTC）的集中区域（颜色由冷到暖） - 把关键订单的集中区以及其绝对位置画出来——这是可操作的动作

一根长下影线，往往就是一次彻底的爆仓清算。

三、你行为里的谬误（The Fallacy in Your Behaviour）#

大概率：大多数人的止损都设在那些"高流动性区域"。

推理链条： 1. 我们的猴子脑会识别模式 2. 如果你既不是完全的蠢货，也不是绝对的天才，那么你大概率会和多数人一样移动 3. 你。很。可。预。测。 4. 你画着同样的支撑线：线下方一点点就是"失效"，再下面一点就是你的止损 5. 蜡烛刚好向下扎一下，把你止损打掉，然后价格反转，把你甩在原地——你直接少了 1.5%（还不算杠杆）

这叫做"千刀万剐式的死亡（Death by a thousand cuts）"。

怎么破？

你不需要理解高智商是怎么思考的；你只要把你剩下不多的脑细胞当成镜像神经元，去模仿那些巨脑在做什么就行。

即：不要试图变聪明，要试图模仿真正的大资金。

四、尾巴（Tails）——用批发商类比理解#

类比故事：

一个批发商用 $1/瓶 进了 10,000 瓶汽水。 - 想以 $2 卖掉 → 没人买 - 降到 $1.5 → 还是卖不动 - 到 $1.2 时有人买了几瓶，但生意依然很慢 - 临近保质期，店主害怕亏损 → 降到 $0.90 - 这时一家大型连锁零售商的老板走进来，买走了剩余库存中的大部分——他会尝试以 $1 卖出（恰好是上一次大成交发生的价格，也就是人们认为的公平价格） - 小店老板把价格提回 $1，剩下的库存很快被小买家扫光

映射到市场： 1. 纽约时段在 IB 高点出现快速拒绝（卖出尾），打击买方信心，价格开始往 106,000 低位走 2. 然后大买家在那个区间强势介入，开始激进地吸收卖单，速度快到直接形成一个买入尾 3. （为了更有意义，至少要有 2 个单印） 4. 第二次回测前一时段低点时，买方反应更激烈

核心结论： - 尾巴 = 大资金在极端位置表态的痕迹 - 尾巴的意义在于"拒绝"——某个价格被市场拒绝 - 一个单印不算尾巴；至少 2 个单印才够看

五、核心方法论：模拟普通人，然后推翻他#

如果你在 Market Profile 图上识别出一些有意思的点位，试着模拟"普通人会怎么做"。 你要做的，是把他那套逻辑里每一个点都推翻/失效（invalidate）。 然后再据此把你的订单摆在更聪明的位置。

为什么有效： - 这里 90% 的人亏钱 - 如果你做得不一样，同时又基于"市场自己生成的信息"做决策，那么你大概率是对的

行动纲领：

忘掉价格行为（price action）。看价值（value）。

零、核心命题：语境是关键#

你到目前为止学的一切，如果你不能放进语境里理解，那都是没用的。

为什么： - 我们怎么知道一个 "P" 形是逼空回补（short covering），还是一个 "b" 形是多头爆仓（long liquidation），而不是别的鬼东西？ - 我们怎么知道一个弱低点会不会在当天后面被扫掉？ - 必须先理解语境。

执行方式：把这套步骤组织成流程，每个周末过一遍，为下一周做准备。 成本：不到 1 小时。收益：极大的优势。

三个步骤： 1. A) 市场条件（Market conditions） 2. B) 关键水平（Key levels） 3. C) 前一周（Previous week）

一、语境（Context）#

下面 A / B / C 三节，是构成「语境」的三个输入。 它们要一起看，不能只看其中一个。

A) 市场条件（Market Conditions）#

操作#

打开 K 线图，狠狠盯着周线看。

判读示例#

  • 市场往哪走？它在往下走（IT IS GOING DOWN）
  • 所以从统计上看，我们大概率还会继续往下

常见反驳："但如果市场反转呢？"

数据回答：

  • 自 2019 年以来，市场趋势反转了 9 次
  • 也就是说 2513 天里只有 9 天发生反转
  • 过去 6 年里反转概率 0.36%

结论：

别指望在下跌趋势里抓到"世纪级别的做多"。你抓不到底。

输出：现在我们知道趋势是下跌。

B) 关键水平（Key Levels）#

操作清单#

用画线工具找这些： - 年开盘（yearly open） - 年低（yearly low） - 年高（yearly high） - 最近的区间线（range line）

打开指标： - 设置一个"按年锚定的 WVAP / AVWAP（yearly anchored VWAP）" - 加 SMA、SMA 200、以及一条 EMA

可选进阶：把斐波那契回撤（Fibonacci retracement）从去年的顶部拉到之后的底部，再加更多关键水平，增加差异（diff）。

这些水平的性质#

每次价格靠近它们，都有反转的机会——0.36% 的机会。 但更高的概率是：价格会在这些水平附近来回折腾一阵子，因为它们是心理障碍位（psychological barriers）。

价格在这些水平附近会做两件事：

情景 表现 原因
情景 1 价格大概率会在附近弹一弹或者磨一阵子，然后才刺穿过去 通常很多参与者在到达这些水平时会持有空单，他们会把它当成机会来平衡仓位（rebalance inventory）；其他人也会趁机做多
情景 2 价格像长矛一样直接穿过去，仿佛这些水平不存在 这很少见，意味着某个大参与者（鲸鱼）决定在这些水平上砸盘卖出，以便之后在更低的位置买回

我们的动作：当我们接近这些水平时，我们寻找"延续（continuation）"。

水平的"硬度"#

有些水平是"硬"的（比如年开盘），有些是"软"的（比如 fib）。

C) 前一周（Previous Week）#

操作#

很简单：价值（value）看起来怎么样？在下移吗？ - 看价值区间（value areas），忽略周末 - 价值区间在变低 → 除非出现强烈反转信号，偏向（bias）不变

关键推论#

假设趋势未变。 这不意味着你不能做多，只是要知道：多单的风险回报比（RR）是有限的，你必须快进快出（通常在一个 session 内）。

示例：如果市场短期显示出一些强势信号，你可以用 80% 规则抓一个反弹，但要快。

得到什么#

  • 现在你有目标点位了
  • 在这些参考点之间，价格大概率会趋势化地运行
  • 原因：价格会在已知参考点之间移动（趋势），因为我们是猴子，我们喜欢模式。把心理学用在你自己这边。

二、节奏（Tempo）#

定义#

节奏 = 价格变化的速度。 它不等同于波动率（volatility）。你应该把它理解成"信念/决心（conviction）"。

基本规律#

价格往往在接近已知水平时降低节奏，在穿越未知区域时加速。

类比#

类比 1：你晚上一个人走在不熟悉的城区。你会不舒服，想尽快走到你熟悉的区域。一旦到了熟悉区域，你的步伐会慢下来。 价格也类似。

类比 2：在 ATH 上方也会发生类似的事，因为参与者会亢奋。想象你饿着肚子站在自助餐前：你会把平时不吃的东西也往盘子里装。但在家里你会更谨慎地选择吃什么。

P 形 / b 形的语境化解读#

在下跌趋势接近关键水平的语境下，b 形意味着什么？ - → 多头爆仓（long liquidations） - 如果是这样，要注意：市场需要喘口气才能继续跑。库存需要重新平衡，然后才能继续。

上升趋势里 P 形的情况相反：→ 逼空回补（short covering）

⚠️ 关键辨析：不要被迷惑#

有时候日线 profile 在下跌趋势里也会出现 P 形。 但那种情况下，先形成的是"肚子（belly）"，后形成的是"P 的腿"，所以它不适用于"逼空回补/爆仓"那套解释。

判断规则：

对于逼空回补 / 多头爆仓，肚子是最后形成的。

那么下跌趋势里的那个 P 形怎么解释？ → 一个不确定的市场、节奏很慢时，更像是"挤压的 D 形（squeezed D）"：没有尾巴。

三、到底发生了什么鬼？（What the Hell Is Going On?）#

你得从"市场与价值"的角度思考，而不是只盯着价格行为。

视角转换： - 市场仓位是怎么摆的？多头清算，其实就是给某个做空者的买单。 - 用这个视角，你对流动性的理解会更宽，也能理解"价值迁移（value migration）"的可能性

机制链条： 1. 多头清算会暂时放慢市场——我们需要把这些买单消化掉 2. 然后还需要有人再去开新的多头仓位，市场才能继续往下 3. 上升趋势同理反过来 4. 这就是节奏减慢 5. 当市场重新平衡后，我们才可以继续走得更远

收缩、扩张。市场在呼吸。

核心心法#

你们太执迷于"反转"了，好像那是某个神奇时刻让你赚钱。不是的。 趋势才是你的朋友。 如果你顺着趋势去摆仓，你已经站在正确方向上了。 用收缩（肚子/盘整）来摆仓，当节奏加速时顺势走。

基于你自己的经验建立"预期（expectancy）"，而不是基于我的经验。 否则很快就会变得非常离谱（very fucky）。

为什么：当你学习新东西时，你的大脑会寻找"预包装的信息"，用来当作指南针上的北。

类比： - 想象你刚在这个世界里凭空出现，天气多云 - 如果我告诉你"带把伞，今天会下雨"，结果那天真的下雨了，你就会把"多云 = 下雨"关联起来 - 但我的说法其实是基于：在这个世界生活多年后，大多数人能感受到气压与风的变化，并以较高概率判断是否会下雨

一、动量（Momentum）#

定义#

动量就是语境。 动量是市场里某件事正在发生的"是什么（what）"以及"为什么（why）"。

与 RSI 类指标的区别#

  • RSI 和类似指标能给你"是什么"（涨/跌），但给不了"为什么"
  • 问题在于：这些指标依赖的信息深度很有限，所以用于判断"延续"时并不可靠
  • 例：RSI 即使出现回撤/反弹，也能在超买或超卖区待很久
  • 如果我们想用好 Market Profile，必须发展一种更整体、更细腻的信息处理方式——用大脑去处理信息

市场结构（Market Structure）#

"市场结构"指的正是这个概念——市场结构是"是什么"。 - 趋势长什么样？总体动量是看跌的。简单。

但市场动量不止于总体趋势，我们还有价格与成交量等维度。在 profile 里，市场与成交量是绑定在一起的。

如果只想要相对收益，就买现货然后出去玩就好了。但我们想要绝对收益——所以躲在洞里交易永续。 那 Market Profile 怎么帮我们？通过展示动量，并把它变得可操作。

二、两类标记（核心分类）#

我们需要区分：

类型 性质 例子
信念标记（Conviction Markers） 被某种东西驱动的 不平衡（imbalances）、区间延伸（range extensions）、单边踏步（one-timeframing）、更大级别买方或卖方的控制（longer-timeframe control）
机械标记（Mechanical Markers） 更"机械"地发生 过度（excess）、弱高点/弱低点（poor highs/lows）、失败的区间延伸（failed range extension）、回补（short-covering）

⚠️ 机械标记一直都在发生，但脱离语境会把你坑死。 "这么多弱高点，但一个都没被扫掉。为什么？" ← 这就是语境问题的典型

三、六种动量形态（Patterns）#

① One-timeframing（单边踏步）#

定义：当市场向一个方向趋势运行，并且某个时段没有先向前一时段的第一根 TPO 反向交易（不回踩/不回抽）时，就形成 one-timeframing。

判读： - 如果出现任何"反向的 TPO"去到前一时段的开口之内，它的意义更大（说明可能在动摇） - 方向性信念非常强，因此动量很高 - one-timeframing 的终止，通常是动量减弱或结束的第一警告

从 F 时段开始 one-timeframing，一直到 O 时段才停止；第一个对前一时段（N）发生反向交易的是 O。

② Trend Day（趋势日）#

  • 信念略弱于极致单边，但仍然很强
  • 通常伴随：one-timeframing、很薄的 profile、常常是单分布（single distribution）

③ Range Extension（区间延伸）#

定义：当价格在一个窄区间里交易，但随后带着信念突破 IB 向外延伸，就发生区间延伸。

含义：这时动量存在，因为参与者启动了一场拍卖。

判读要点： - 先看 IB 是否在前一日的区间 / VA 内形成 - 若市场尝试向上突破 IB（更广义地说突破 pdVA）但失败 → 拒绝 → 反转 → 向下延伸 - 反向同理：向下突破失败 → 反转 → 向上延伸 - 若这段区间与 VA 重叠且出现衰竭（exhaustion），配合 P 形，是延伸方向的线索

④ Spike（刺入 / 尖刺）#

定义：spike 就是一次动量冲击（momentum thrust），通常对应 SP，常发生在时段的极端位置（开盘或收盘附近）。

性质： - spike 是一种"过度（EXCESS）" - 市场喜欢过度吗？不，市场讨厌过度，因为它们是低效率 - 因此 spike 往往标志着那个方向动量的结束

周一的 F 时段是一次过度，前一周周六的 A 时段也是。 ⚠️ 注意：尖刺不一定是单印，你需要自己解释。

⑤ POC Migration（POC 迁移）#

机制：如果价格持续远离原 POC 交易，并且在另一个位置形成更多 prints 超过原 POC，那么 POC 就会迁移过去。

POC 迁移本身就是一个指标，在两种场景下重要：

场景 含义 注意事项
短期（盘中） POC 在当日开发（developing）过程中向某个方向移动，说明该方向的价位正在被"巩固"（consolidation） ⚠️ 不要过度依赖它去做多时段的交易，因为后续时段（尤其 NY 到亚洲/伦敦）可能很快反向
中期（多日） POC 在多个交易日里快速向一个方向迁移，确认动量在构建（更大级别的一方在控制） —

⑥ Tempo（节奏）#

节奏也是动量的标记！

  • 快节奏是情绪化的：越快越危险
  • 当它快到极致（狂热、恐慌投降）时，可能会燃尽，然后反转整个市场趋势
  • 例：一个 ATH

形态 类别 核心特征 交易含义

一、订单簿（Order Book / DOM）#

定义#

订单簿 = 把所有挂单（limit orders）列出来的清单。

界面读法#

位置 内容
中间那条线 成交发生的位置 = 最新成交价（last price）
巨大箭头 告诉你上一跳（last tick）在当前价的上方还是下方。红 = 上一跳在当前价上方；绿 = 相反
下半部分 买单（buy orders）
上半部分 卖单（sell orders）
从中间往外看 绿色区域第一行 = 最高买价（highest bid）；红色区域第一行 = 最低卖价（lowest ask）
最左边那一列 挂单的"累计总量"（按 BTC 计价，也可选美元）。所谓累计 = 每个价位把当前价位的挂单量与更靠近中间价位的挂单量累加起来
彩色区域的那一列 每个价位（按 tick size 分组）对应的挂单量。彩色带子的"宽度"只是可视化：如果有明显的买墙/卖墙，会在这里突出得非常明显
最右边那一列 价位（同样按 tick size 分组）。示例中 tick size 是 250 美元

下单规则： - 下市价买单（market buy） → 你会吃到 ask - 下市价卖单（market sell） → 你会打到 bid

别称：这种工具一般叫 DOM（Depth Of Market，市场深度）。把它想成大海：你能看到水（流动性）到底有多深。

⭐ 最核心的一条机制#

当价格上涨时，最新成交价下方会"生成"新的 bid（买方挂单）； 反过来，当价格下跌时，最新成交价上方会"生成"新的 ask（卖方挂单）。 价格的每一次移动（几乎）总能找到流动性来完成成交。

这一点请刻进脑子里——你下一件工具会用到它。

练习建议#

  • 在设置里把"声音/成交提示（volume sound）"打开，试着"听"订单簿在打印成交
  • 为什么有用：我们现在是坐在屏幕前交易，而不是站在交易大厅地板上喊单
  • 可以调节订单大小来控制灵敏度
  • 尽量用更多感官去"读"订单流——这样当你只用眼睛看时，也能更快理解发生了什么
  • 你听到的就是 bid 和 ask 的成交

二、足迹图（Footprint）#

最简单的读法（"降智版"）#

  • 右边（ask）很胖：好，价格要 brrr（往上冲）
  • 左边（bid）很胖：不好，价格不 brrr（不往上冲/甚至往下）
  • 两边都胖：价格更平衡（均衡成交）

Delta#

  • 足迹图下面会显示该根 K 线的统计信息以及 delta
  • delta 为正 → 主动买（买方吃单）更多
  • delta 为负 → 主动卖（卖方吃单）更多

⚠️ 读法关键：对角线读#

你要"对角线"读足迹图。它不是镜像。

  • 足迹柱子里的小黑空隙代表价位
  • 空隙下方左侧 = 成交的 bid（打到买盘的成交）
  • 空隙上方右侧 = 成交的 ask（吃到卖盘的成交）

与 Market Profile 的对应#

足迹图里同样有： - POC（在轮廓上以边框标出） - 价值区（Value Area, VA） 以及 VAH / VAL

作用与 Market Profile 一样，只不过在足迹图里这些严格基于"成交量（volume）"计算。

不平衡（Imbalance）#

  • 定义：某个价位上 bid 成交量与 ask 成交量之间的差异
  • 默认设置通常是 10:1 的比例
  • 偏向买方的不平衡 → 高亮成绿色
  • 偏向卖方的不平衡 → 高亮成红色

三、热力图（Heatmap）#

定义#

可以直接在 K 线图上看到挂单（resting orders）在哪里。颜色越"热"（从黑到白），表示该价位的挂单块越大。

与订单簿的关系#

记得订单簿吗？本质上是同一个东西，只不过把它可视化到图表上了。 - 价格线之上的，是限价卖单 - 价格线之下的，是限价买单

交互细节#

把鼠标悬停在某个格子上，你会看到： - 该格子的挂单量 - 上下几个格子的挂单量 - 前几根 K 线时间里的挂单变化

⭐ 为什么这很重要#

因为你能看到有人挂了单又撤掉了。我们把这叫做 spoofing（虚假挂单/诱骗）。

经验规律： - 随着经验增加你会发现：大多数买墙和卖墙在价格靠近时都会消失 - 你甚至能通过固定的挂单尺寸识别某些玩家——这些机器人每次都用同样的尺寸 - 例：在 Binance 现货上，总有个 "82 手" 的家伙玩这套

四、局限性（Limitations）#

局限 说明
隐藏订单 订单簿只能看到"挂在簿子里"的限价单。市价单（market orders）不会提前告诉你
Spoofing 你永远无法 100% 确定哪些是诱骗、哪些是真挂单；经验能帮一点，但不能完全依赖

术语 一句话

目标：把 CVD 从"一条线"变成一套完整的判读体系。

一、CVD 衡量什么？#

累计成交量差（CVD）衡量的是"主动买方"和"主动卖方"的差异。 它会在每根 K 线里显示：哪一侧的主动成交量差更大，以及大多少。

CVD 状态 含义
上升 整体上主动买方（市价单）更多、更激进
下降 主动卖方更多、更激进
走平 代表犹豫/不决，双方都没有显著的主动性

CVD 追踪的是：在某个时间框架里，参与者付出了多少"努力（effort）"。

⚠️ CVD 看不到什么： - 冰山单（iceberg）或大体量的隐藏挂单 —— 看不到 - OTC（场外）交易 —— 不包含（大机构常用它降低冲击成本） - 买方是在开多还是在平空 —— 无法直接判断（卖方同理）

二、CVD 的类型#

CVD 有很多变体，每一种都从不同角度展示市场行为：

类型 中文 特征
Taker CVD 吃单方 CVD 最常见，实时追踪市价单的主动性
Maker CVD 挂单方 CVD 更少见，但很有价值。展示被动流动性（限价单）的行为：是在吸收价格，还是根本不感兴趣
Spot CVD 现货 CVD 追踪现货交易所的主动成交量（市价单）。这更像"真实需求"，因为它需要真金白银，因此在长周期里更有意义
Perpetual CVD 永续 CVD 追踪永续合约市场的主动成交量。更偏短线投机，杠杆更高
Aggregated CVD 聚合 CVD 王中王。可消除单一交易所的偏差，更能反映全球整体的主动流向

三、Maker vs Taker（挂单方 vs 吃单方）#

常见的 CVD 主要高亮的是 takers（吃单方/市价单） 的行为。但要真正把 CVD 用"到位"，你必须理解 makers（挂单方/限价单）如何回应。

主动方 / Taker（Initiative）#

只有当流动性足够薄（也就是 makers/限价单不够多）时，takers 才能真正推动价格继续走。 若挂单方很多，一个上升的 CVD 可能对蠢人来说是"幻觉"。

被动方 / Maker（Response）#

makers 通过限价单吸收市价单。 当市场存在吸收（absorption）时，CVD 可能在某个方向走得非常猛，但价格却几乎不朝那个方向移动。

⭐ 吸收（Absorption）的典型特征#

当吃单方开始"推不动"时，典型特征就是： - CVD 很强，但价格位移很小 - 成交量在增加，但价格位移在缩小

这就叫吸收。

四、两种最核心的背离#

4.1 吸收背离（Absorption Divergence）—— 最强#

定义：如果 CVD 朝某个方向走，但价格却无法随着 CVD 在同方向延续，那么说明有隐藏的限价单在吸收主动市价单（可以用热力图看到这些限价单）。

类型 现象 解读
买入吸收（Buying Absorption） CVD 上升，但价格下跌 大量主动市价买单被隐藏的限价卖单吸收
卖出吸收（Selling Absorption） CVD 下降，但价格上涨 大量主动市价卖单被隐藏的限价买单吸收

4.2 衰竭背离（Exhaustion Divergence）—— 更常见#

定义：当价格尝试突破，但某一侧没有足够"力量"支撑。这可能是因为市场过度单边、需要获利了结；或者主动方失去动力。

⚠️ 注意：衰竭点往往不是绝对顶/底，而且经常会被再次回踩。

类型 现象 解读
买入衰竭（Buying Exhaustion） CVD 下降，但价格上涨 买方兴趣不足（缺乏持续的主动买入）
卖出衰竭（Selling Exhaustion） CVD 上升，但价格下跌 卖方兴趣不足（缺乏持续的主动卖出）

⚠️ 两者最易混淆的地方#

吸收和衰竭的现象看起来一样（都是 CVD 与价格反向），区别在： - 吸收 = 有隐藏的大单在被动承接（对手方强大且主动） - 衰竭 = 主动方自己没力气了（没有对手方，只是推不动）

实操区分：结合热力图看是否有墙；结合成交量看是放大还是萎缩。

五、高时间框架 / 多周期（HTF / MTF）背离#

定义：多日/多交易时段的背离，往往表现为：价格在"搭结构"，但 CVD 却在相反方向趋势化。它揭示了大型被动玩家在一段时间内持续吸筹或派发。

这类信号对大级别的波段反转非常强。

低周期 CVD 提供"精度"，高周期 CVD 提供"结构性信念"。

低周期 CVD（1m / 5m / 15m）的作用#

  • 识别微观结构变化（microstructure shifts）
  • 在几根 K 线内识别吸收
  • 确认/验证高周期的突破尝试
  • 显示 delta 扫动（delta sweeps）及其反应
  • 揭示被套/被困的参与者（trapped participants）

更适合用于： - 执行（Execution） - 确认（Confirmation） - 抓反转时间点（Reversal timing） - 识别陷阱（Spotting traps）

⚠️ 注意：低周期 CVD 本身噪音很大，绝对不要单独使用。

高周期 CVD（1H / 4H / Daily）的作用#

  • 揭示跨交易时段的吸筹/派发
  • 暴露宏观级别背离
  • 平滑噪音

更适合用于： - 波段偏向（Swing Bias） - 识别趋势延续 - 识别机构吸筹/派发 - 识别高周期的失败拍卖（HTF failed auctions）

六、进阶 CVD 背离#

6.1 现货-永续 CVD 背离（Spot-Perp CVD）#

前提：现货代表真实需求进入市场——需要真金白银。

组合 含义
现货 CVD 下降，而永续 CVD 上升 杠杆交易者在强行把价格推上去，但长期的现货买家并不支持这次上涨 → 常常制造假突破、清算瀑布（liquidation cascades）和各种陷阱
现货 CVD 上升，而永续 CVD 下降 真实需求正在进入市场，而杠杆交易者尚未参与 → 这往往是更可持续的强上行趋势的前兆

一句话：现货 CVD 更像"真买家"，永续 CVD 更像"短线/投机/高杠杆"。

6.2 交易所之间的 CVD 背离（Exchange-to-Exchange）#

不同交易所服务不同的参与者：

交易所 参与者特征
Binance 杠杆/散户占比更高
Coinbase 美国现货资金流（更大体量的资本）

当 Coinbase 的 CVD 与 Binance 的 CVD 发生背离时，它在暗示：到底是"真实的大资金买卖"在参与，还是更偏杠杆/散户流在驱动。

例子：Coinbase CVD 强势上升，而 Binance CVD 走平 → 暗示有更高资本、更成熟的资金在流入。

这也是 Coinbase Premium Indicator 之类工具能派上用场的原因。

6.3 Delta Trap 背离（V 形反转）#

场景：在足迹/订单流交易里经常使用——当吃单方（市价单）在行情极端位置疯狂抬价（lift offers）或砸价（hit bids），但价格撞到一堵"墙"后立刻反转。

此时 CVD 往往会出现巨大的成交量柱，但价格却几乎不动。

它暗示： - 一串"堆叠不平衡（stacked imbalances）"撞上了强被动挂单墙 - FOMO / 主动方的入场位置很差 - 主动交易者被困（trapped）

七、"扫止损（Stop Hunts）"期间的 CVD 行为#

机制：当市场触发止损时，会迫使交易者以相反方向自动平仓，有时会进一步推动行情。

表现：清算（liquidations）会触发一波强制性的市价单洪水，CVD 会猛烈尖刺。随后往往是立刻反转。

⭐ 关键区分：强迫性流动 vs 有意图的走势#

关键是：区分"强迫性流动（force）"与"有意图的走势（intentional move）"。CVD 能告诉你这波动到底是不是"真"。

类型 CVD 特征
真需求 在突破之前，CVD 会先逐步堆起来（build before the break）
假需求 CVD 往往是在突破那一下才突然尖刺（spike at the break）

八、健康趋势 vs 糟糕趋势#

最简单地说：当 CVD 与价格同向配合，就是更健康的趋势。

不健康趋势：如果 CVD 与价格严重不一致（很多时候本质上就是吸收），那就不是健康的上行——说明很多参与者在找机会卖出。

九、CVD + 未平仓量（OI）#

CVD 告诉你"谁更主动"，OI 告诉你"谁在建仓/撤仓"。两者结合能揭示市场的"库存（inventory）"。

OI CVD 含义
上升 上升 新多头进入市场
上升 下降 新空头进入市场
下降 下降 多头平仓（Long covering）
下降 上升 空头回补（Short covering）

真正的趋势通常需要两者同时支持：OI 上升，并且 CVD 在趋势方向上持续增强。

十、CVD 判读总表#

价格 CVD 判读
↑ ↑ 主动买方控制，健康上涨
↑ 走平/↓ 走势偏弱：买方更被动，或卖方在吸收主动买
↓ ↓ 主动卖方控制，趋势下跌
↓ 走平/↑ 吸收或衰竭，常常是反转/挤压的前兆

一、加密衍生品基础#

1.1 什么是衍生品？#

衍生品是这样的合约：它跟踪某个资产的价格，但你并不真正持有这个资产本身。

市场中大多数交易发生在永续合约（perpetual futures）上。 它看起来像常规期货合约，但没有到期日。

永续合约通过一套机制让价格与现货保持一致，主要包含： - 合约的计价货币（quote currency） - 标记价格（mark price） - 通过资金费率（funding）强制执行的定价机制

1.2 计价资产 vs 保证金资产#

每个衍生品合约都有两面： 1. 被交易的资产：也就是标的，例如比特币（BTC） 2. 作为保证金的资产：也就是你用来开仓抵押的东西

多数交易所使用 USDT 或 USDC 作为保证金，因为这样保证金价值更稳定。有些平台提供"币本位合约（coin-margined）"，用标的本身作为保证金。

所以，BTCUSDT 永续合约意味着： - 你交易的是 BTC 的价格波动 - 盈亏（PnL）用 USDT 结算 - 保证金也以 USDT 持有

这很重要，因为合约的价格并不是只跟随现货价格本身，而是跟随交易所采用的那套定价机制。

1.3 标记价格（Mark Price）与预言机（Oracles）#

为了防止操纵，交易所不会用自己的"现货价格"来计算清算（liquidations），而是用标记价格（mark price），它包含： - 外部预言机价格（通常是多个大交易所现货价格的加权混合） - 合约的资金费率与溢价（premium） - 平滑机制（防止单个跳动或操纵造成的剧烈波动）

⚠️ 因此，你被触发清算时参考的是 mark price，而不是你看到的"图表价"。 这让跨交易所的清算机制更一致。

1.4 两种主要合约类型#

类型 保证金/结算 特点
线性合约（Linear） 用稳定币作为保证金与结算货币 PnL 相对更稳定、更直观；如今成交量占主导
反向合约（Inverse） 用标的币作为保证金 PnL 会随币价变化；保证金要求波动更大

1.5 衍生品会带来什么影响？#

如今市场大部分成交量都在衍生品上，这意味着衍生品的"机制"越来越重要。价格会更敏感地响应：

  • 杠杆进入/离开（Open Interest）
  • 激进的市价单（CVD）
  • 拥挤的持仓（Funding）
  • 流动性厚薄（Depth）

二、未平仓量（Open Interest, OI）#

2.0 定义#

OI 衡量的是：衍生品合约当前"尚未平掉"的总量。 它反映了市场在某一时刻有多少杠杆正在参与。

  • OI 上升：新的仓位正在被开出来
  • OI 下降：仓位在被平掉，或被强制平仓

⚠️ 但关键点是：OI 并不告诉你这些仓位是多还是空，因为每一个多头都必须对应一个空头。 OI 真正展示的是：市场的"总敞口（exposure）"有多大。

  • 敞口越大 → 行情背后的"潜在能量"越多
  • 敞口越小 → 市场正在去杠杆/去风险，整体更稳定

2.1 OI 会怎么变化？（只有三种情况）#

情况 OI 含义
双方都开新仓 上升 更多杠杆进入市场
双方都平仓 下降 杠杆退出市场
一方开仓、另一方平仓 大致走平 敞口在参与者之间"轮换"

因此，最好把 OI 与价格一起看：你关注的是 OI 相对价格变化的"关系"，而不只是 OI 的最终数值。

2.2 OI 与价格的组合解读#

价格 OI 含义
↑ ↑ 新的多头敞口进入，趋势通常更强
↑ ↓ 多为"空头回补"，走势看起来强但其实更脆弱
↓ ↑ 新的空头进入，下跌趋势通常更强
↓ ↓ 多头平仓或被清算；强制卖出/恐慌性出逃

这些模式在加密市场尤其适用，因为杠杆高、反应快。

2.3 OI Delta（未平仓量变化率）#

OI Delta 展示的是 OI"每根 K 线之间的变化速度"，而不仅是绝对值。

  • OI Delta 上升：杠杆在快速流入
  • OI Delta 下降：杠杆在快速出清/去杠杆

它有助于识别： - 追涨杀跌的冲动入场（Impulse entries） - 反转前的突然减仓 - 大规模清算事件 - 缓慢但持续的建仓（往往是突破前奏）

2.4 为什么 OI 重要？#

在加密市场里，OI 是最干净的领先指标之一，因为衍生品成交量占主导，而大行情通常伴随： - OI 大幅上升（新杠杆推动价格） - 或 OI 大幅下降（清算或大规模平仓）

OI 环境 特征
低 OI 通常更容易震荡、来回割
高 OI 要么趋势更明显，要么会出现剧烈的"机械式出清"（squeezes / 强制去杠杆）

三、资金费率（Funding Rates）#

4.0 定义#

资金费率是永续合约多空双方之间的周期性支付，用来让永续价格贴近现货。

  • 永续高于现货：多头付费给空头
  • 永续低于现货：空头付费给多头

⚠️ 资金费率本身不会"推动"市场。真正重要的是：谁在付、付多少、能付多久。

4.1 为什么需要资金费率？#

永续没有到期日，因此需要一个机制把价格锚回现货。资金费率通过经济压力让合约回到均衡： - 永续高于现货 → 多头付费给空头 → 激励多头减仓 - 永续低于现货 → 空头付费给多头 → 激励空头减仓

大多数交易所每 8 小时结算一次，足以把合约锚在现货附近。

4.2 正/负资金费率意味着什么？#

正费率（Positive Funding）： - 多头付费给空头 - 永续高于现货 - 市场偏多/多头拥挤 - 买盘更主动

负费率（Negative Funding）： - 空头付费给多头 - 永续低于现货 - 市场偏空/空头拥挤 - 卖盘更主动

⚠️ 注意：资金费率并不意味着多头或空头"人数更多"。每个多必有空。 资金费率衡量的是"主动性与失衡"，而不是方向。

4.3 把资金费率放进价格语境里#

价格 Funding 含义
↑ ↑ 多头在主导，通常趋势延续；除非拥挤度极端
↑ ↓ 多为"空头回补"，走势往往偏弱
↓ ↓ 空头在主导
↓ ↑ 多头被套，常出现被迫出清/清算针

4.4 极端资金费率#

高/低资金费率并不会自动导致反转。 真正重要的是： - 极端持续多久 - OI 在上升还是在下降 - 现货是否支持或否定永续流

  • 资金费率极端，但 OI 走平或下降 → 往往意义不大
  • 资金费率极端且 OI 上升 → 说明市场在极度单边地"装载仓位"，会形成不对称风险

4.5 资金费率的"预测性"用法#

资金费率本身不指向方向，它提供的是"持仓压力"的信息。 它更适合用来识别： - 多头/空头拥挤，可能被挤压 - 流动性很薄时，单边持仓更不稳定 - 永续流与现货流脱节的阶段

4.6 现货 vs 永续语境#

资金费率只适用于永续。现货交易者不付也不收。

如果现货趋势很强，而永续一侧出现极端资金费率的反向信号，永续那一侧通常会输。

  • 例：现货持续买入，同时资金费率为负（空头拥挤）→ 空头人群被套
  • 反之：现货持续卖出，同时资金费率为正（多头拥挤）→ 多头人群被套

四、订单簿深度（Orderbook Depth）#

5.0 定义#

订单簿深度展示的是：簿子两侧（bid 与 ask）有多少"静态挂单"在等待成交。

不同于 CVD（主动性），深度展示的是"被动流动性"——也就是有多少挂单愿意在附近价格接单。 你可以把它理解为：价格在当前环境里到底"稳不稳"。

  • 簿子厚（thick book） → 价格移动会更慢
  • 簿子薄（thin book） → 价格移动会更快

范围：订单簿深度通常显示到距离现价 +/-10% 的范围，意味着你能看到这一区间内所有可见挂单的堆叠情况。

5.1 深度到底告诉你什么？#

深度讲的是"流动性"，不是"方向"。

它回答的问题包括： - 推动价格到底有多容易？ - 大额挂单都在哪些价位？ - 新闻/事件前流动性是否在枯竭？ - 哪一侧的挂单更厚？ - 哪些区域可能让价格减速/加速？

当交易者讨论"稳定性"或"薄簿子"时，本质上说的就是深度环境。

5.2 两种主要显示模式#

1) Bid & Ask

展示簿子两侧的绝对流动性： - Bid 侧：价格下方等待买入的挂单 - Ask 侧：价格上方等待卖出的挂单

适合用来识别： - 大墙（walls） - 流动性集中在哪里 - 两侧是否明显失衡 - 哪些区域会让价格减速或加速

这是最直接、最简单的视图。

2) Delta（深度差）

展示的是：每个价位 bid 流动性与 ask 流动性的差值。 - Delta > 0：bid 更厚 - Delta < 0：ask 更厚

更适合快速看： - 压力区（pressure zones） - 流动性倾斜（liquidity skews） - 哪一侧在某个深度百分比上明显占优 - 簿子更像"支撑"还是"阻力"

它把大量信息压缩成单一渐变，让你一眼更容易看出流动性偏向。

5.3 如何读深度环境？（四种状态）#

状态 特征 影响
厚簿子（Thick Book） 两侧流动性都高 推动价格需要真主动性；波动会被压缩
薄簿子（Thin Book） 两侧流动性都轻 更小的市价单也能推动更大的价格位移；波动更容易扩张，尤其在新闻/高波动催化剂附近
Bid 更厚（Bid-Heavy） 价格下方挂单多于上方 下跌时更像"缓冲垫"；有助于识别吸收或吸筹区域
Ask 更厚（Ask-Heavy） 价格上方挂单更多 上涨时更像"摩擦力"；常与派发/抛压一致

5.4 墙与流动性簇（Walls and Liquidity Clusters）#

大额挂单会形成"墙（walls）"。它们可能表现为： - 磁铁（magnets）：价格会慢慢漂向它 - 屏障（barriers）：价格靠近时会停滞 - 假流动性（fake liquidity）：诱骗单（spoofs），价格靠近就撤

⚠️ 你永远不要在价格还没靠近时就"假设"某个墙是真的。 在加密市场里诱骗（spoofing）非常常见：有人挂出巨量订单，等价格接近就撤掉，用来误导市场参与者对真实供需的判断。

5.5 深度如何与其他指标配合？#

组合 能看出什么
Depth + CVD 主动订单是在被吸收，还是在切穿流动性
Depth + OI 在 OI 上升时，如果簿子很薄，容易形成"机械式出清"的条件：挤压与大规模清算
Depth + Funding 如果某一侧在薄簿子里支付高资金费率，走势可能会很快反向出清

五、结语#

以上就是要点。所有这些指标都会让你更深入地理解市场的持仓与脆弱性——但它仍然不是全部。还有很多其他因素也很重要，比如清算、基差（basis）、成交量等。

它们都不是"信号"。即使组合起来，它们也只是提供语境（context）。

把洞察转化为优势（edge）的唯一方式，是构建一个结构清晰、并且经过回测的系统，这样你才知道自己决策背后的期望值（expected value）。

一、清算（Liquidations）#

1.0 机制#

清算发生在：交易者的保证金不足以支撑其杠杆仓位时。 一旦触发阈值，交易所会用市价单强制平仓。

这会产生"强制性流动（forced flow）"，而不是交易者自主选择的流动（discretionary flow）。 因此，由清算驱动的行情往往发生得很快，并且容易过冲关键水平。

1.1 清算数据能让你洞察三件事#

  • 市场哪一侧更拥挤（crowded）
  • 持仓到底有多脆弱（fragile）
  • 强制流动可能在哪里加速或让行情停滞

在行情运动中，如果 OI 出现大幅下降，通常意味着：若价格在下跌，那多为多头清算；若价格在上涨，那多为空头清算。 这也是为什么 OI 不能孤立地看。

1.2 清算簇（Liquidation Clusters）#

清算常常会"扎堆"，因为交易者倾向于： - 使用相似的杠杆 - 把止损放在类似的位置（例如摆动高点/低点）

当价格进入这些"清算簇区域"时，可能出现：

现象 说明
瀑布（cascades） 强制卖出/买入会推动行情沿该方向继续扩张
回弹（snap-backs） 强制流动被清掉后，可能出现迅猛反转
磁铁效应（magnets） 价格会"漂向"流动性，以便让买卖双方都能成交

加密市场尤其容易出现这类事件：杠杆高、波动大、订单簿薄。

1.3 为什么薄簿子会放大清算行情？#

机制：清算是用市价单执行的。当订单簿很薄时，附近没有足够的挂单来吸收这些市价单。 于是，强制订单必须沿着簿子更远地"走"（walk the book）才能成交，从而造成过大的价格位移。

薄簿子会放大清算事件，因为： - 市价单需要走更远的流动性 → K 线更大 - 每一次清算都会触发新的清算 → 形成连锁反应 - 滑点变大 → 即使小订单也会不成比例地推动价格 - 点差扩大 → 波动加速 - 被动流动性消失 → 做市商在波动尖刺时撤单

因此，清算瀑布几乎总发生在以下环境中： - 深度低（low depth） - 点差扩大（widening spreads） - 高杠杆（high leverage） - OI 上升（rising OI） - 参与度低（low participation）

一句话：强制市价单 + 薄流动性 = 夸张行情。这就是清算瀑布的核心机制。

1.4 Z-Score 变换（标准分数）#

问题：原始时间序列会跳得很厉害。不同资产本来就会有不同的清算规模（成交量更大、参与者更多、OI 更高等）。高波动环境也会进一步扭曲数据。

标准化方法：

zscore = (value - mean) / standard deviation

它把指标变成"相对极端程度"的度量，而不是绝对数值。

1.5 为什么要用 Z-Score 看清算？#

  • 它能高亮清算量异常高（或异常低）的时刻
  • 它会根据近期环境与波动做调整，避免把"正常行为"误判成极端
  • 它能更早识别"压力事件（stress events）"，甚至在价格完全反应之前
  • 过滤噪音，让尖刺更清晰、更可比

特别有用的场景： - 识别正在形成的清算瀑布 - 区分普通止损出局 vs 真正恐慌 - 量化"投降式"出清（capitulation） - 给系统加入统计结构（statistical structure）

本质上，它告诉你：这次清算相对最近 N 个周期到底有多"猛"，即便原始数值看起来不大。

1.6 交易者实际怎么用？#

  • 高 z-score 的清算尖刺，常与"末端衰竭"相关（end-of-move exhaustion）
  • 突破但清算 z-score 很低，往往意味着持仓压力不大，更可能延续
  • 极端读数 + OI 下降 → 常意味着强制行情快结束了
  • 极端读数 + OI 上升 → 说明新的杠杆还在进入，趋势可能被延续

二、成交量 Delta（Volume Delta）#

2.0 定义#

成交量 Delta 衡量的是：单根 K 线内"市价买"和"市价卖"的净差值。

与 CVD 不同，CVD 是把差值随时间累加；而 Volume Delta 是逐 K 重置的"当根净差"。

它让你看到：每根 K 线是谁赢了、主动性如何在短期内切换——这种切换往往发生在更大级别行情推进时。

  • Delta 为正 → 市价买多于市价卖
  • Delta 为负 → 市价卖多于市价买

2.1 Volume Delta 与 CVD 的区别（易混淆）#

指标 累加方式 视角
CVD 把买/卖主动性随时间累加 宏观视角（macro view），展示"主动性趋势"
Volume Delta 每根 K 线重置 微观视角（micro view），展示"这一根谁更主动"

两者服务不同目的。

2.2 把 Volume Delta 与价格一起读#

价格 Delta 含义
↑ 正 健康上涨：主动买确实在驱动行情
↑ 负 弱突破：卖方在吸收，突破可能失败
↓ 负 受控下跌：主动卖在主导
↓ 正 吸收或卖方被困：常见反转或挤压信号

2.3 Delta 背离#

现象 含义
价格创新高，但 Delta 的高点更低 主动买在减弱，上行可能接近衰竭
价格创新低，但 Delta 的低点更高 主动卖在减弱，下跌可能放缓或反转

2.4 Delta 簇（Delta Clustering）#

把 Delta 当"连续片段"来看，会更有用，而不是只看单根 K 线。

连续多根正 Delta 或负 Delta，往往代表主动性行为（initiative behavior）。

例子： - VWAP 上方连续正 Delta → 买方有意图地进场 - 价格失败 VWAP 后连续负 Delta → 卖方主导 - 关键水平附近的 Delta 簇 → 突破/跌破前的蓄力

簇体现的是"意图（intent）"，不只是结果。

三、多空比（Long-Short Ratio）#

3.0 定义#

多空比展示的是：某交易所里，持有多仓的账户数量与持有空仓的账户数量的比例。

⚠️ 它常被当作情绪指标，但限制很大，绝不应当被当作方向信号。

  • Ratio > 1 → 更多账户是多
  • Ratio < 1 → 更多账户是空

仅此而已。它统计的是"账户数量"，不是仓位规模、不是信念、也不是杠杆。

3.1 这个比率真正反映了什么？#

因为它统计的是账户数而非名义金额，多空比主要反映散户情绪。

高比率往往意味着： - 很多小账户在做多 - 群体偏向一侧 - 一旦价格反向，可能形成陷阱

低比率则相反：群体更偏空。

但再次强调：这是账户数，不是风险规模。

3.2 为什么它不太可靠？#

交易者把它当背景噪音，主要因为： - 一个大户的仓位能抵得上成千上万个小账户 - 它忽略杠杆与仓位大小 - 它无法捕捉跨多个交易所的持仓 - 它不显示现货敞口 - 它经常反映的是散户过度站队，而非真实流动

因此，它更多被当作"温和的反向指标"（soft contrarian），而不是预测工具。

3.3 交易者实际怎么用？#

即便有这些限制，它仍有一些实用用途： - 极端读数：提示散户明显偏向一侧 - 拥挤持仓：常与挤压（squeezes）对应 - 搭配资金费率：识别"群体在付费去做错方向" - 搭配 OI：判断这群体是否真的"重要"（有没有规模）

例子： - 多空比极高，但 OI 走平 → 可能只是很多小散户多单，规模不大，信号弱 - 多空比极高 + OI 快速上升 + 资金费率为正 → 说明散户在用杠杆扎堆做多，陷阱更容易出现

3.4 多空比在什么时候才更有用？#

只有少数情景能提供真正增量信息： - 低成交量周末（散户更主导） - 小交易所/小币种（参与者更集中） - 拥挤叙事下，作为反向参考 - 极端读数与其他 flow 指标形成共振时

单独使用很弱；结合语境，能帮助你描述"群体偏向"。

四、吃单买/卖量（Taker Buy/Sell Volume）#

4.0 定义#

Taker Buy/Sell 衡量的是：在一段窗口内，成交量中有多少来自"买方跨价差成交"（市价买）vs "卖方跨价差成交"（市价卖）。

这是观察"谁在主动进攻"的最干净方式之一。

与其他指标的区别： - 和多空比不同：它是实际成交流（executed flow），不是情绪 - 和 CVD 不同：它不做累加——只是展示所选窗口内的主动买/卖拆分

  • Taker Buy Volume = 市价买
  • Taker Sell Volume = 市价卖

哪边更高，哪边就控制了当下的主动流。

4.1 它揭示的是什么？#

因为 takers 会推动市场，这个数据能告诉你： - 哪一侧在主动推动价格 - 流动是否平衡或失衡 - 行情是被主动性推动，还是只是薄流动性"滑过去" - 上涨是否"真实"，还是主要被动吸收

它比多空比或资金费率更直接，因为它基于实际成交量。

4.2 把 Taker Flow 与价格一起读#

价格 Taker 含义
↑ buy 占优 主动买驱动，强势
↑ sell 占优 吸收：被动卖很强，突破可能失败
↓ sell 占优 卖方控制，趋势下跌
↓ buy 占优 低位吸收，可能反转或挤压

把它当作：比 delta 更干净、时间更短的版本，不一定需要完整 footprint 图也能用。

4.3 Taker 比率（Buy/Sell Ratio）#

Ratio = Taker Buy Volume / Taker Sell Volume
  • = 1 → 中性、平衡
  • > 1 → 买方主动
  • < 1 → 卖方主动

这个比率反应很快，因此对突破、新闻驱动的行情、开盘早段波动很有用。

4.4 实战怎么用？#

Taker flow 最有效的用法，是配合结构与关键参考点：

场景 判读
VWAP 附近 VWAP 上方 taker-buy 占优 → 确认接受（acceptance）；VWAP 上方 taker-sell 占优 → 提示拒绝（rejection）
区间边缘 强 taker flow 穿越水平 → 更像真突破；弱 taker flow 穿越水平 → 更像假突破
高 OI 环境 taker flow 告诉你：杠杆高的时候到底是谁在"按住油门"
清算事件 你能看到：强制流动是在被吸收，还是在延伸

短线交易者很常用 taker 数据，但如果做平滑/平均，它也能扩展到更高时间框架。

4.5 Taker Flow vs Volume Delta vs CVD（三者区分）#

指标 定义
CVD 跨多根 K 线累计的买卖主动性差
Volume Delta 单根 K 线内部的买卖主动性差
Taker Volume 主动买量 vs 主动卖量的"原始成交量"，不绑定 K 线

Taker flow 是最"干净"的，因为它不受 K 线开收价的影响。

五、结语#

这些工具能帮助你理解：持仓如何建立、如何出清、在压力下如何反应。 但它们仍然只是语境（context）。

清算、Volume Delta、taker flow、多空比能让你看到行情背后的机制，但并不"预测"行情本身。 和第一部分一样，它们都不应该被孤立交易。

真正把它们变成价值的方式，是把它们纳入一个系统，并回测，真正理解你的策略机制，知道它是否确实是正期望（+EV）。

目标：理解 VWAP 的机制、锚定用法，以及如何与订单流工具结合。

一、引言：为什么需要 VWAP#

  • 市场里的每一次微小波动，背后都由成百上千笔成交驱动
  • 移动平均线已被证明是一种经得起检验的方法：它能过滤"噪音"，并在时间维度上推导出一个平均价格
  • VWAP（Volume Weighted Average Price，成交量加权平均价） 也是另一种有效的"去噪"方式

关键区别：

它不是对某个固定时间窗口的价格做平均，而是按"成交量"对价格做加权平均。 参与度更大（成交量更高）的价位更重要；成交量更低的价位在 VWAP 计算中的权重更小。

二、VWAP vs SMA vs EMA#

对比：VWAP（成交量加权）vs SMA（简单均线）vs EMA（指数均线，回看 26 根 K 线）

观察结论： - VWAP 往往更"黏"着价格走 - 当出现高成交量的冲动 K 线时，VWAP 的斜率变化更陡 - 低成交量区域往往会把 VWAP 推成横向走平

三、为什么 VWAP 重要？#

3.1 过滤噪音并可视化"价值"#

  • 市场混乱且充满随机性——这是人性情绪与系统化执行共同作用的结果
  • VWAP 通过高亮"成交量主要发生在哪些价位"，把你拉回现实
  • 它能可视化哪些价格更接近市场参与者认为的"公允价值（fair value）"，而这种"公允"来自参与者展现的信念强弱（成交量）

类比：

如果你只随机抽几辆车测速度，可能得到当天平均车速 100 km/h； 但如果你按每个速度区间的车流量（volume）加权，你就会得到更贴近真实交通流的平均速度——也许更接近 95 km/h，因为高流量的高峰期会拉低整体速度。 VWAP 本质上就是把这个思路应用到价格上。

用途：帮助你识别市场是否"过度延伸"（价格远离 VWAP）或是否在"价值附近盘整"。

⚠️ 注意：市场没有义务尊重 VWAP，也没有义务回到 VWAP。 它只是记录了过去参与者在哪些价位大量交易。

3.2 锚定 VWAP（Anchored VWAP）以提升精度#

做法：在市场的关键节点"重置/锚定" VWAP。这样的定制化能让它适配不同资产、不同周期以及不同交易风格。

一些常见的锚点： - 交易时段开盘（例如纽约时段） - UTC 开盘 - 关键的市场结构水平（关键高低点、结构拐点等）

四、交易应用#

4.1 识别市场状态切换（Identifying Market Shifts）#

研究 VWAP 与价格行为的关系，可以让交易者洞察市场可能发生的重要状态切换，这类切换可能会引发趋势的持续。

典型形态：价格此前在 VWAP 附近横盘，随后向远离 VWAP 的方向扩张，并最终引发趋势延伸。

价格位置 含义 后续预期
VWAP 上方 相对"主要成交发生的区域"而言，市场在溢价区交易 可能表明多头强势；若成交量持续跟进，往往可以期待多头延续
VWAP 下方 市场在折价区交易 若卖方足够持续，可以期待下行延续

⚠️ 没有任何单一工具能给交易者所有答案。它们必须与相关数据形成共振（confluence），用来构建能把胜率向你倾斜的策略。

4.2 VWAP 偏离（VWAP Deviations）#

除了标准 VWAP 之外，VWAP 的第 1 / 第 2 / 第 3 个标准差带（standard deviations）也很常用：

  • 用来可视化价格相对 VWAP 可能"过度延伸"的程度
  • 观察价格是否可能开始向均值回归（mean reversion）

4.3 策略生成（Strategy Generation）#

当你动手实验时，请记住：VWAP 的力量在与其他工具结合时会被放大——没有任何一个指标"统治一切"。

把多个订单流工具叠加起来尤其实用，因为它能帮助你理解价格波动背后的"为什么"，并形成对下一步价格可能去向的合理预期。

五、VWAP × 订单流的两种组合#

5.1 VWAP + CVD（累计成交量差）#

基础逻辑：

当价格贴着 VWAP 上方运行，而 CVD 同时上升时，它确认了多头的信念（bullish conviction）。

可执行用法（趋势跟随）： 1. 在回踩 VWAP 时做多 2. 要求 CVD 出现正向背离/维持强势，以此确认买方主动性 3. 止损放在 VWAP 下方，用于风险控制

案例： - 价格在下破 VWAP 后进入下跌趋势 - 随后价格强势反弹回到 VWAP - 此时分析订单流会很有用，用来形成对"下一步可能怎么走"的预期 - 价格开始掉头并再次从 VWAP 向下延伸 - 与此同时，CVD 创出更低低点，说明卖方主动性再次增强，价格继续延续下跌趋势

5.2 VWAP + 成交量足迹图（Volume Footprints）#

基础逻辑：

足迹图把每根 K 线的成交量拆解为 bid/ask 的不平衡（imbalances）。 你可以观察 VWAP 附近的"堆叠不平衡（stacked imbalances）"作为入场信号。

可执行用法： - 在加密市场，可以把 VWAP 锚定到 UTC 开盘 - 观察价格回调时，在该水平附近是否出现主动买入的足迹信号 - 再叠加一个"交易时段开盘"的锚定，做多周期确认

案例： - 当价格尝试上破 VWAP 的同一时刻，可以看到大量买方主动性进场，但价格却不太愿意"尊重"这些买入主动性 - 对比：在穿越 VWAP 的那些 K 线低点附近，卖方主动性相对更低，但价格却更愿意向 VWAP 下方延伸 - 结论：买方需要付出明显更大的努力才能把市场推高；最终他们让步于卖方，导致下跌趋势继续延伸

⚠️ 当然，这些例子都是站在"事后视角（hindsight）"选出来的，我们因此能更容易识别反复出现的线索。 基于交易风格与个性，最终由交易者自己决定：哪些信息共振能构成优势（edge）。

六、结语#

VWAP 是一个简单工具，但当你正确使用时，它能让你清晰看到：有意义的成交主要发生在哪里，以及价格相对"价值"是如何运动的。

它不预测未来，也不保证市场一定会对它产生反应；但在充满噪音的市场里，它提供了一个稳定参考点。

把它与扎实的执行工具与明确的系统结合，它就能成为你更大流程中的可靠组件。

一、拍卖（Auctions）——最核心的判断#

1. 拍卖何时开始#

  • IB（初始平衡）是当天的关键参考
  • 当长周期参与者进场，通过把价格推高或压低，分别突破 IBH 或 IBL 时，我们就进入了一次"拍卖"
  • 拍卖点（Auction Point） = 第一个走出开盘平衡（IB）的时段

2. 拍卖点作为支撑/阻力#

拍卖点位置 后续通常表现为
位于 IB 上方的"确认拍卖点" 支撑
位于 IB 下方的"确认拍卖点" 阻力

3. 拍卖成功 / 失败的判定（两个指标）#

短期指标（30 分钟规则）： - 价格在 IB 外站住至少 30 分钟（= 1 个时段）→ 拍卖确认 - 在少于 30 分钟内回到 IB 内（即拍卖点之后的一个时段内回归）→ 拍卖失败 - 有些交易者只看第一根单印（first print） - 更保守的版本（走势较慢时用）：忽略拍卖刚开始的那个完整时段——即拍卖点所在的那个时段不计入 30 分钟

长期指标（收盘规则）： - 价格向外延伸并且当天收盘在 IB 外 → 拍卖确认 - 价格虽然延伸到 IB 外，但回归并且当天收盘回到 IB 内 → 拍卖失败

4. 为什么这个判定重要#

想想看：长周期参与者在某个价格水平出手成交。 - 如果他们成功，他们会把该水平当作未来交易的参考点 - 如果不成功，下次他们会在同一水平做反向淡出（fade）

5. 用拍卖点做延续判断（简单法则）#

看时段收盘相对拍卖点的位置： - 时段收盘在拍卖点上方 → 可以预期市场继续往上拍卖 - 时段收盘在拍卖点下方 → 可以预期市场继续往下拍卖

目的：追求延续（continuation），这样才不会"来回坐过山车（round-tripping）"。

二、单印（Single Prints）#

形成条件#

当市场放弃横向平衡、突然变得"垂直"（快速单边），并且某一类订单（买或卖）几乎没有对手方时，就可能出现单印。

命名#

位置 名称
出现在轮廓顶部 卖出尾（selling tail）
出现在轮廓底部 买入尾（buying tail）

推动力（Impetus）从哪来#

  • 尾巴和任何市场运动一样，背后有推动力
  • 这种推动力通常来自长周期参与者：他们决定"现在该动了"

主动 vs 反应（认知推理框架）#

任何市场运动都可能是"主动（initiative）"或"反应（reaction）"的结果。反应会对抗主动。

价格位置 你会看到
走到开盘价上方 主动性买入（initiative buying）+ 反应性卖出（reactive selling）
走到开盘价下方 主动性卖出（initiative selling）+ 反应性买入（reactive buying）

它们不一定同时发生： - 有时反应性买家会等一波大幅下跌后才开始挂单（→ 长尾巴） - 有时一点点下跌就足够触发他们反应（→ 短尾巴）

尾巴的长度 = 反应方等待的耐心程度。

一、Tetris（俄罗斯方块）#

1. 理论基础#

  • 价格会在一个区间内分布，"自然状态"下这种分布就是钟形曲线
  • 但不是所有 Market Profile 都长得像钟形曲线，因为：
  • 我们必须设定一个区间并在某处结束一个 session，否则会得到巨大到无法阅读的轮廓
  • 人类的生活与行为（大多数情况下）围绕日周期
  • 结论：人为的 session 切割会造成未完成的结构——这些结构就是 Tetris 要填补的"缺口"

2. 形态识别#

案例 A：一个 "P" 形轮廓 + 一个"肚子非常拉长"的轮廓 - 第一个轮廓显示了不平衡，最后卖方把买方平衡回来，但留下了很多粗糙地形（rough terrain） - 第二个轮廓回头下去检查那里有没有"未了的生意"，结果发现还有很多事情要做

案例 B（跨 3 个轮廓，没那么清晰） - 第一个轮廓里有好几个不平衡，后面几天的交易把这些不平衡大多"填补"了 - 就好像市场想把它修成一个钟形曲线一样

案例 C（10/10 事件后） - 从 100k 暴力反弹到 116k → 准备见血 - 因为我们会下去检查地下室里是不是还藏着怪物（即：回去测试/填补）

3. 核心操作：合并 Profile#

操作步骤： 1. 右键选中一个 profile 2. 选择 "Merge with previous profile section"（与前一个 profile 合并） 3. 点按钮 4. 选中新形成的 profile，再点一次，重复操作 5. 最终你会得到一个干净得多、更像钟形曲线的合并轮廓

合并后的判读：

当你看到一个合并后的 profile 长这样时，我们大概率在为某个方向上的"大动作"做准备。

4. 策略要点#

  • 故事寓意：你可以推断价格会被"吸引"到哪里
  • 也就是 Tetris 里所谓的"缺口"——价格会去把这些缺口填上
  • 你要做的是：结合你学到的其他东西，去判断"什么时候（WHEN）"某个缺口会被填补，然后据此摆好仓位

⚠️ 注意：Tetris 只告诉你"哪里会被吸引"，不告诉你"什么时候"。时机必须来自语境 + 动量/节奏确认。

二、"80% 规则"（The 80% Rule）#

1. 规则#

当某一天开盘在"前一日价值区间（pdVA）"之外，随后价格重新被"接受（accepted）"回到价值区间内，那么有 80% 的概率，价格会交易到前一日价值区间的另一侧。

2. 风险提醒#

在你用退化的高杠杆永续（degenerate leverage perp）搞事之前，先用很小的资金把这两套策略跑熟。

为什么重要：因为市场会对关键水平产生反应。

情形 后续可能
关键水平被拒绝（rejected） 市场可能会在相反方向上趋势化地走很远
关键水平被接受（accepted） 市场会试图用信念来确认这个方向（通常需要几天）

当水平被接受后，市场趋势向下。反之亦然。

c. 最近的 profiles 长什么样？（How Do the Recent Profiles Look?）#

案例： - 近期持续下跌，跌破 0.236 fib（约 82.5k） - 当前在尝试重新站上它并夺回 0.382 - 这个水平大致对应上周五的 VAH

d. 上一个交易日（Last Trading Day）#

注意：因为周末成交量低，把周五当作上一个交易日。

能提出什么假设？ - 看起来像一个可能的"80% 规则"设置：目标是回到周四的 POC - 市场在周五 VAH 内开盘，并尝试向上交易

二、三个 Setup 的完整写法（模板示范）#

Setup 1（低概率做多）#

  • 触发：如果价格能守住周五 VAH / 周四 VAL，并且节奏加速
  • 预期：可能会看到价格重新夺回 92–93k
  • ⚠️ 但这是低概率设置，因为总体是下跌趋势
  • 要不要做多？看你自己——这是低概率，取决于你有多厌恶风险
  • 失效条件（Invalidation）：周五 VAH 被拒绝
  • 止损（Stops）：VAH 的下边界

Setup 2（等 POC 附近找做空）#

  • 触发：等待价格接近周四的 POC，并寻找节奏与动量的丢失（loss of tempo/momentum），比如出现一个 P 形 session
  • 入场：如果价格随后下破，我们就可以在向下节奏加速时自信做空
  • 目标：回到周五 VAH
  • 失效条件：节奏向上构建（说明要更高），或者纽约开盘后价格在周四 POC 附近盘整并站稳
  • 止损：周四 POC

Setup 3（顺趋势做空，优先级最高）#

  • 触发：市场拒绝周五 VAH 并开始向下趋势化
  • 入场：在节奏构建时做空
  • 为什么好：因为通往 75k 的路上只有 84.7k 和 83k 两个阻挡——这是一个线条清晰、顺趋势的好设置
  • 失效条件：价格一直保持在周五 VAL 上方
  • 止损：周五 VAL 的下边界

三、统一的入场条件（Conditions for Entry）#

对所有交易：

a) 你希望在上述 profile 水平之上/之下看到 1 个或更多的 TPO 确认（confirmations） b) 你希望看到节奏加速：比如快速趋势运行，并可能伴随清算（liquidations）

关于清算的作用：清算为何能作为局部趋势确认，见 13 衍生品数据（下）。

⚠️ 最重要的纪律#

晚一点但对，比早一点但错强得多。 盈利就是盈利。 你越早意识到"完美入场"是个愚蠢概念，你越早开始稳定盈利。

四、理由与心理（Rationale & Psychology）#

核心认知#

从来不是简单的"上或下"。 关键在于：为最可能的情景做好准备。

  • 只列 3 个，因为"已经够你消化了"
  • 但你能合理预判并计划的情景越多，你当天就会有越多的选择

不交易的明确条件#

情形 动作
市场走出了你没有计划的动作 不要交易它——你只是 FOMO 追进未知区域，根本不知道会发生什么
市场横盘 别交易
价格在周四 VA 内来回震荡 别交易
你没有计划 你。就。不。交。易。

当然，你可以把它当学费交给市场。但从别人的错误里学习，远胜于从自己的错误里学习。

关于"完美"#

接受"完美不存在"。只有正 PnL 和负 PnL 两种结果。决定你想站在哪一边。 你需要做几百笔、甚至上千笔交易才能真正成型。 一次亏损不是世界末日，只要别被爆仓，活下来，明天还能交易。 在排除不太可能的情景后，为尽可能多的走势做准备。

"你的大脑让它变得真实（Your mind makes it real）。"

本章需要关注的术语#

术语 一句话
情景剧本（Scenario） 开盘前写好的「如果……那么……」计划，含六项要素

确认（Confirmation） 什么证据证明这次动作是真的

性质：不是机械照抄的"圣杯"，而是一套每天都能重复执行的工作流。

主链条：先定语境 → 再定关键水平 → 再做情景推演 → 盘中分类与确认 → 执行与风控 → 复盘迭代

一、你每天要用到的核心参考#

1) TPO / Market Profile 核心水平#

VA、VAH、VAL、POC、IB（A+B 两个时段）、拍卖点（Auction Point）、单印（Single Prints）、尾巴（Buying/Selling Tails）、弱高点/弱低点（Poor High/Low）、HVN/LVN、Naked POC、pdH/pdL、ONH/ONL

2) 盘面"状态"指标#

是否 one-timeframing、是否 range extension、是否 spike（早/晚盘动量尖刺）、POC migration、value migration、tempo（节奏 = 价格变化速度 = 信念）

3) 可选强化工具（若你有）#

成交量足迹 / Delta、订单簿热力图、保证金多空比、聚合清算等（用于判断"市场仓位是否过多/过空"、以及局部趋势确认）

提示：你不需要一次把所有工具用满，但你必须把"术语与概念"内化；否则你只是换了个更复杂的图表来瞎猜。

二、周末 / 日内开盘前：建立"语境"（Context）#

这一步贯穿全部流程：没有语境，所有形态都会把你带进陷阱。

步骤 1：看周线/日线市场结构（Market Structure）#

  • 先在更高时间框架（周线优先，其次日线）确定大方向：上升 / 下降 / 震荡（bracketing）
  • 原则：顺趋势优先；逆势很酷但风险极高
  • 市场不确定 / 极度震荡时，选择"不交易"也是交易决策

步骤 2：标出关键水平（Key Levels）#

  • 年开盘 / 年高 / 年低、最近的大区间上沿/下沿
  • 重要均线（如 SMA200）、锚定 VWAP（如按年锚定的 AVWAP/WVAP）、关键 Fib（可选）
  • 逻辑：价格在已知水平附近会"降速/纠缠"，在未知区域会"加速"；有时会被大体量参与者直接刺穿（"长矛"式通过）

步骤 3：看上一周 / 最近几天的 Profile#

  • 观察 value area 是上移还是下移（价值迁移）
  • 观察 POC 是否多日持续迁移（中期动量确认）
  • 记录：
  • 是否存在明显不平衡
  • 单印缺口
  • 多个弱高/弱低
  • 尚未回补的 Naked POC
  • 多重分布（double/triple distribution）

输出（写在你的交易计划里）#

  • 今日大方向偏向（Bias）：顺趋势（优先）/ 中性 / 仅做短线逆势（低概率）
  • 今日"最可能的驱动力"：趋势延续？关键水平附近的反应？还是均值回归？
  • 今日允许做的"交易类型"：跟随拍卖？80% 规则？旋转？只做其中 1–2 种，避免什么都想抓

三、当日关键水平清单（开盘前 5–10 分钟完成）#

把"昨日 + 隔夜"的关键信息一口气画好。越少越强，宁缺毋滥。

  • 昨日 VAH / VAL / POC（pdVAH / pdVAL / pdPOC）
  • 昨日高低点（pdH / pdL）、隔夜高低点（ONH / ONL）
  • 昨日 / 近几日的弱高 / 弱低与尾巴
  • 昨日 IBH / IBL（或你交易的主要时段的 IB）
  • Naked POC（未回补/未解决的 POC）
  • 明显的单印区与 LVN（穿越速度快、未来容易当作支撑/阻力/加速带）

同时做两个快速判断#

  1. 昨日更像趋势日还是区间日？ - 薄轮廓 + one-timeframing = 趋势 - 矮胖、均匀 = 区间
  2. 今日开盘相对昨日 VA 的位置：在 VA 内？在 VA 外？（为 80% 规则做准备）

四、把"策略"写成 2–3 个情景（Scenario Plan）#

不是"涨或跌"，而是"最可能的几种情景 + 触发条件 + 失效条件 + 目标"。

情景模板（每个情景都用同样格式写）#

字段 内容
情景名称 例：「80% 规则回补」「IB 拍卖延续」「失败拍卖淡出」「区间旋转」「弱高/弱低扫掠」「Tetris 缺口回补」
条件（Context） 必须满足什么大背景？顺趋势？关键水平附近？市场是否过多/过空？
触发（Trigger） 盘中要看到什么才进场？至少 1 个时段/TPO 的确认 + 节奏加速/动量标记
失效（Invalidation） 什么发生就承认错并退出？回到 IB 内？关键水平被重新站稳/跌破？
止损（Stop） 放在失效条件之外（你能接受的风险额度内）
目标（Targets） 优先用 Market Profile 的"参考点"：POC、VAH/VAL、Naked POC、下一关键水平、单印缺口的另一端
管理（Management） 到目标如何处理？减仓/全平？是否允许再入场？（默认不允许追单）

建议#

  • 最开始只写 2–3 个情景
  • 并且明确写出"哪些情况不交易"：
  • 市场极度横盘 / 开盘后明显 open-auction（除非你专做旋转剥头皮）
  • 出现了你没有写进计划的走势（FOMO 追进去通常是送钱）
  • 关键水平附近没有确认、没有节奏与动量的配合

五、盘中执行：先"分类"，再"确认"，最后"入场"#

这一步把开盘形态、拍卖点确认/失败、动量标记、确认与节奏合在一起。

1) 先等 IB 成形（前两段 A+B），不要急#

  • 尤其在亚洲/伦敦/纽约开盘与收盘附近这些"kill zone"，至少等 2-3 个时段看清楚：今天是趋势还是震荡

2) 给今天的开盘"定性"（四种开盘）#

形态 判断 操作
Open-Drive 趋势强 不要逆势淡出
Open-Test-Drive 趋势仍强 顺势为主
Open-Rejection-Reverse 趋势可能更慢形成 仍偏趋势，但要更重视确认
Open-Auction 震荡为主 只适合旋转/剥头皮，不熟就空手

3) 判断：是否出现"拍卖"（Auction）#

  • 当价格突破 IBH/IBL，标记第一个走出 IB 的时段为"拍卖点（Auction Point）"
  • 短期确认：价格在 IB 外至少站住 30 分钟（可更保守：拍卖点时段不计入，等下一时段再确认）
  • 长期确认：当日收盘是否在 IB 外？

4) 交易决策（核心分支）#

分支 A：拍卖成功（价格确认在 IB 外）→ 顺势做延续

  • 用拍卖点当作回撤参考：拍卖点上方的成功上拍卖 = 支撑；下方成功下拍卖 = 阻力
  • 追求"延续"，不要在趋势日做反向淡出

分支 B：拍卖失败（很快回到 IB 内）→ 失败拍卖淡出（回归均值）

  • 典型特征：冲出 IB 后又回到 IB；顶部/底部留下低信念痕迹（如单印、尾巴、成交量/Delta 衰竭）
  • 策略：淡出新的同向尝试，做向 IB 另一侧的回归；第一目标通常是 POC（均值磁铁）

分支 C：明显区间日 → 旋转交易（Rotation）

  • 在 VA 边缘 / 日内极端淡出，目标 POC（均值回归）
  • 前提：没有强动量标记（one-timeframing、range extension、POC 多日迁移等）

分支 D：80% 规则

  • 条件：开盘在前一日 VA 外 → 价格被接受回 VA 内
  • 目标：前一日 VA 的另一端（理论 80% 概率）
  • ⚠️ 重点：要等"接受"确认，不要用 1 个单印就冲（一个单印不算确认）
  • 多重分布日：把每个分布当作"独立的一天/独立的 VA"来处理

分支 E：弱高/弱低扫掠

  • 多个重复的弱高/弱低未被触碰时，它们像磁铁一样吸引价格去"扫一下"
  • 原则：扫到就走，除非出现拍卖成功/被接受的证据（否则很容易扫完就反向）

分支 F：Tetris 缺口回补

  • 用合并 profiles 的方式找"缺口/粗糙地形/不平衡"，把"哪里会被吸引"当作方向与目标线索
  • ⚠️ 但入场仍要依赖：语境 + 动量/节奏确认，不要只靠"缺口一定会补"

六、统一的入场"硬条件"（避免瞎猜）#

这是一个最低门槛。

硬条件 1：你必须知道自己在交易哪个"参考点"#

  • 入场必须围绕某个 Profile 水平：VAH / VAL / POC / IBH / IBL / 拍卖点 / 单印区边界 / 弱高弱低 / 关键水平

硬条件 2：至少 1 个"时间确认"（TPO / Period Confirmation）#

  • 你希望看到：关键水平之上/之下至少出现 1 个完整时段的确认
  • 更稳健：2 个时段，或"站住 30 分钟 + 下一时段不立刻回去"
  • 解释：Market Profile 的优势在于把"时间"显性化；没有时间确认，就等于你在用猜的

硬条件 3：节奏/动量必须与方向一致#

  • 你希望看到：节奏加速（tempo up）、出现 range extension、one-timeframing、POC 向交易方向迁移，或（可选）清算/Delta 配合
  • 反例：接近关键水平时节奏明显放慢、尖刺（spike/excess）出现、或动量标记终止 → 先不追，考虑止盈/等待再确认

硬条件 4：先写好失效条件，再允许自己按下开仓键#

  • 没有失效条件 = 没有交易计划 = 不交易
  • 止损要放在失效条件之外
  • 仓位大小要保证"止损触发也不会伤筋动骨，更不会爆仓"

七、仓位管理与退出（把"赚到的"带走）#

这些原则：达到目标就走、避免 round-trip、完美入场是幻想。

1) 目标到位就执行，不要临场改信仰#

  • 你的目标通常是下一个 Market Profile 参考点：POC、VAH/VAL、IB 边界、Naked POC、下一关键水平等
  • 到位后：全平或分批止盈（至少减仓），把确定性利润锁住

2) 不做"事后英雄"#

  • 你预测的是 2% 的空间，走到就收
  • 别因为它后来又多走了 1% 就回去追——那已经超出你的计划范围

3) 观察节奏：到关键水平附近节奏下降时，优先考虑止盈#

  • 价格靠近已知水平往往降速
  • 尖刺/过度经常意味着动量耗尽

4) 不交易的纪律#

  • 市场横盘、你看不懂、或出现你没有写进情景的走势：不交易
  • "不交易"是为了把你的子弹留给高概率场景

八、盘后复盘：把经验变成"可复制的预期"#

你的预期（expectancy）必须建立在自己的经验上，而经验来自复盘与记录。

复盘最小闭环（15 分钟版本）#

  1. 截图：当日 session profile + 关键水平标注
  2. 写一句话：今天属于哪类日？（趋势/区间/双分布/三分布）开盘是哪种？（四种开盘之一）
  3. 记录动量标记：是否 one-timeframing？是否 range extension？是否 spike？POC 是否迁移？
  4. 如果你交易了： - 你交易的是哪个情景？触发与确认是什么？ - 失效条件是否被破坏？你是否按计划退出？ - 你是否在"kill zone"里冲动开仓？是否 FOMO？
  5. 给自己一个评分：计划执行（0–10）
  6. 下次只优化 1 件事（例如：更耐心等确认、减少追单、缩小交易类型）

一、图表与数据面板（开盘前固定好）#

你不需要把所有工具一次性用满，但建议把"语境层 → 价值层 → 执行层 → 风控层"分开摆放：

层级 内容
语境层（Higher TF） 周线 / 日线 / 4H 结构线、关键高低点、重要开盘价（周开 / 日开 / UTC 开盘等）
Profile 价值层 TPO / Market Profile（当日与前一日/前几日），至少包括：VA、VAH、VAL、POC、IB、single prints、tails、poor high/low、value/POC migration
VWAP 价值层 当日会话 VWAP（建议 UTC 或你交易的主要会话开盘），以及 VWAP 的 1/2/3 标准差带；必要时使用 Anchored VWAP 锚定到关键结构点或开盘点
执行层（Order Flow） Footprint（足迹图：Bid/Ask、Delta、Imbalances、Stacked imbalances），以及 CVD（最好能区分 Spot CVD 与 Perp CVD）
衍生品与流动性面板 OI 与 OI Delta、Funding、Orderbook Depth/DOM、Heatmap、Liquidations（含 clusters / z-score）、Taker Buy/Sell Ratio、Long-Short Ratio（仅作情绪背景）

⚠️ 提醒：反复强调——任何单一指标都不是"信号"。你要用它们做语境与确认，而不是机械开仓。

二、开盘前 15–30 分钟：建立"语境"#

步骤 1：先定大级别结构（周/日/4H）#

  • 你现在处于趋势（trend）还是箱体/括号（bracketing）？
  • 关键结构水平：最近的 swing high/low、关键突破位/回踩位、前高前低、明显的供需拐点

步骤 2：读"前一日/前几日"的 Market Profile（价值与拍卖）#

  • 昨日是趋势日、震荡日还是中性日？
  • Value 是否上移/下移（value migration）？POC 是否迁移（POC migration）？
  • 昨日极值是否"干净"：有无 tails？有没有 single prints？高点/低点是否贫穷（poor high/low）？
  • 把今天最可能被测试的参考点提前标出来：pdVAH / pdVAL / pdPOC、single print 边缘、tails 的起点/终点、缺口与不平衡区（如果你做多日"拼图/tetris"）

步骤 3：读 VWAP（价值锚）#

  • 价格当前在 VWAP 上方还是下方？距离 VWAP 有多远（是否进入 2σ/3σ 偏离带）？
  • 若价格远离 VWAP：要更警惕"过度延伸"与均值回归（mean reversion）
  • 若价格围绕 VWAP 盘整：要警惕从价值区向外扩张引发的趋势延伸
  • 需要更精细时，锚定 VWAP 到关键点（Anchored VWAP）：UTC 开盘、主要会话开盘、结构拐点、关键高低点等

步骤 4：读衍生品持仓与流动性（告诉你行情"脆不脆"）#

  • OI：现在是高 OI 还是低 OI？OI 在上升（加杠杆）还是下降（去杠杆）？
  • Funding：是否极端？极端是否"持续"且伴随 OI 上升（更危险、更容易出挤压/清算）？
  • Liquidations：清算簇在哪里？如果价格走进去，可能出现瀑布（cascade）还是清掉后回弹（snap-back）？
  • Depth / Heatmap：簿子厚还是薄？是否出现明显墙/流动性簇？注意 spoofing——不要在价格没靠近前就假设墙是真的
  • Long-Short Ratio：只当作"散户情绪背景"，只有当它与 OI、Funding 同时极端共振时才更有参考价值

步骤 5：读 CVD（谁在更主动）#

  • 用 HTF CVD（1H/4H/D）给方向偏向，用 LTF CVD（1m/5m/15m）找执行精度
  • 重点观察两类背离：
  • 吸收（CVD 强但价格不走）
  • 衰竭（价格想走但 CVD 跟不上）
  • 如果能看 Spot vs Perp CVD：用它判断"真实需求"是否支持杠杆流

三、写出当天 2–3 个"情景剧本"（Scenario Planning）#

把所有信息压缩成可执行的"如果……那么……"剧本。 每个剧本至少写清：触发条件、入场确认、无效条件、目标位、止损逻辑。

剧本 A：趋势延续（Trend Continuation）#

字段 内容
典型语境 Value/POC 持续向一个方向迁移；价格稳定在 VWAP 同侧；OI 上升且 CVD 与价格同向；簿子不至于极薄（或即便薄也有明确主动流穿透）
触发 回踩到 VWAP / VAH / VAL / 关键结构位并出现接受（acceptance）
确认 Footprint 出现连续主动性（delta / stacked imbalances）、Taker Buy/Sell 同向占优、CVD 重新转强；OI 不出现快速掉头出清
目标 下一处 profile 参考点（POC / VAH / VAL / 单印边缘）或 VWAP 偏离带；也可参考清算簇 / 深度墙作为"磁铁"
无效 跌回 VWAP 与价值区并形成反向接受，或出现明显吸收背离（CVD 很强但价格不再推进）

剧本 B：均值回归（Mean Reversion / 价值回归）#

字段 内容
典型语境 开盘在前一日价值区外，但缺乏后续接受；价格在 2σ/3σ 偏离带出现衰竭；CVD 与价格出现背离；taker 流与价格方向不一致（吸收）
触发 关键水平被"失败拍卖（failed auction）"或出现 tails / 单印拒绝；或价格在偏离带上出现反转结构
确认 CVD / Delta 出现衰竭或吸收信号；Footprint 显示堆叠不平衡撞墙（delta trap）；OI 开始下降（强制流动被清掉）
目标 先看 VWAP；进一步看 pdPOC / 当日 POC 与价值区另一侧边界
无效 价格重新在偏离带外形成持续接受（多根时间单位站稳）且 OI / CVD 同向增强

剧本 C：流动性事件（Stop Hunt / 清算瀑布 / 假突破）#

字段 内容
典型语境 高 OI + 薄簿子；清算簇贴近区间边缘；Funding 极端；容易出现"强制性流动"尖刺
两种分支 1) 真突破：突破前 CVD 先逐步堆起来（build before break），突破时 taker 流持续跟进，价格位移与 CVD 匹配
2) 假突破/扫止损：突破点出现 CVD 尖刺但价格推进不足（吸收），随后快速反向（常见 V 形）
处理 这种情景要么降低仓位，要么只做"确认后的回踩/反转"，不要追第一根尖刺 K 线

四、开盘到前 2 小时：执行框架（Profile 先分类，Order Flow 再确认）#

步骤 1：用前一日价值区定义"开盘位置"（Open Location）#

开盘位置 偏向 动作
在价值区内 更偏双向 优先等边界测试与失败/接受
在价值区上方 — 观察是否接受（强势趋势日可能直接扩张）；否则容易回到价值区
在价值区下方 — 同理，观察是否接受；否则容易回归

步骤 2：等 IB（Initial Balance，A+B 时段）形成#

  • 不要在 IB 没形成就把自己当先知。先看市场给出的"初始框架"。
  • 观察是否出现 range extension、one-timeframing、spike，以及 POC / value 是否开始迁移

步骤 3：在关键参考点上区分"接受 vs 拒绝"#

  • 接受（acceptance）：需要时间确认——多根时间单位/多段 TPO 站稳，不是一个瞬间扎针
  • 拒绝（rejection）：看 tails、single prints、失败拍卖；结合 VWAP 位置与偏离带判断是否属于"过度延伸"

步骤 4：用 Order Flow 只做两件事：确认与定风险#

  • Footprint：看不平衡（imbalances）、堆叠不平衡（stacked imbalances）、成交量是否在关键位放大但位移不跟（吸收）
  • CVD：看价格与 CVD 是否匹配；看吸收/衰竭背离；必要时对比 Spot vs Perp，判断是真需求还是杠杆在硬推
  • Taker Buy/Sell：把它当作更"干净的短窗主动性"，尤其适合在 VWAP、区间边缘、突破点做快速判断
  • OI / Funding：用来判断这波动是"加杠杆推进"还是"出清推进"。出清推进容易 V 形；加杠杆推进更可能延续，但也更容易在拥挤时被挤压

五、入场规则：三重确认（位置 × 时间 × 流）#

把入场门槛写死：缺一不可。

维度 要求
位置（Location） 必须发生在"结构/价值"参考点附近（VAH / VAL / POC、single prints 边缘、tails、VWAP / 偏离带、清算簇、深度墙等）
时间（Time） 必须出现 Profile 的时间确认（接受 / 拒绝 / 失败拍卖），避免被单根尖刺 K 线诱骗
流（Flow） 至少 1–2 个流动指标与你的方向一致，或给出清晰的背离信号（吸收 / 衰竭）支持你的反向交易

常见的"加分项"（不是必需项，但能提高质量）： - OI 与 CVD 同向增强 - taker 流在突破后持续跟进 - spot CVD 支持趋势方向

六、风控与仓位：先把"你最多亏多少"写出来#

  • 单笔风险：固定为账户权益的一个小比例（例如 0.25%–1%，具体看你策略回撤与胜率）
  • 日内最大亏损：达到即停止交易（例如 2–3 笔连续亏损或当日 −X%）
  • 止损放在哪里：放在"结构无效点"，而不是随便一个固定点数
  • 趋势延续：止损通常放在 VWAP / 价值边界的另一侧，或关键 tail / single print 的外侧
  • 均值回归：止损放在偏离带外的"再次接受"位置，或扫止损尖刺的外侧
  • 高风险环境降杠杆：高 OI + 薄簿子 + 极端 Funding + 清算簇临近 → 要么减仓，要么不做
  • ⚠️ 不要因为"看起来很确定"就放大仓位：多次强调——市场机制会让你在最自信的时候被挤压

七、出场与管理：让结构替你做决定#

  • 目标位优先用 Profile / VWAP：当日 POC、前一日 POC、VAH / VAL、VWAP、VWAP 偏离带、单印边缘、清算簇 / 深度墙
  • 分批止盈：在 POC / 价值边界 / VWAP 处减仓，让你在不确定性里把期望值做大
  • 趋势持仓的"健康度"检查：
  • 价格推进是否仍与 CVD 匹配？
  • OI 是否继续增加（而不是快速掉头出清）？
  • Footprint 是否仍能在回踩处出现主动性簇？
  • 如果出现明显吸收背离（CVD 很强但价格不再推进）或 taker 流转向 → 考虑收缩仓位或退出
  • 均值回归交易：第一目标通常是 VWAP；若回到 VWAP 后出现接受/拒绝，再决定是否继续持有到价值区另一侧

八、复盘：把"工具"变成"系统"#

最重要的一句话之一：这些数据提供的是语境，不是信号。把语境变成优势，需要系统与回测/统计。

每天至少做 10–15 分钟复盘：

  • 截图：当日 Profile（含开盘类型 / IB / 日型）、VWAP（含偏离带）、Footprint、CVD、OI / Funding / Depth / Liquidations 面板
  • 记录：你做的是哪个剧本（A/B/C）？入场满足了"位置 × 时间 × 流"吗？止损是否放在结构无效点？
  • 给执行打分：计划内执行 / 计划外冲动各占多少？
  • 只改 1 个点：下一交易日只优化一个环节（例如：更严格的时间确认、更少追单、更明确的止损位置）

⚠️ 最后提醒：如果你还没有一个经过统计验证的策略（哪怕是极简的 1–2 个 setup），先用极小仓位跑 2–4 周，把流程练成条件反射，再考虑提高频率和仓位。

C. 三条永不妥协的规则#

最高优先级纪律。

  1. 没有时间确认 = 不交易。

    "一个单印不算确认。" —— 至少要 1 个完整时段站稳，更稳健是 2 个。

  2. 没有失效条件 = 不交易。

    没有失效条件 = 没有交易计划 = 不交易。止损必须放在失效条件之外。

  3. 没有写进剧本的走势 = 不交易。

    FOMO 追进未知区域 = 送钱。"你没有计划，你就不交易。"
