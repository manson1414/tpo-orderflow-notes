## 这是什么

把一份 66 页的英文材料（TPO / Market Profile / 订单流 / 衍生品 / VWAP）重组成四条线：

| | 内容 | 面向 |
|---|---|---|
| **学习路径** | 54 个单元 / 13 个阶段，每单元只讲**一个**概念 | 有一点基础、想系统化的人 |
| **理论篇** | 10 篇：市场**怎么运作** | 想先搞懂机制的人 |
| **实战篇** | 7 篇：具体**怎么用**（含 `00 交易心态与铁律`） | 想直接找打法的人 |
| **实盘图鉴** | 12 篇 / **34 张真实行情截图** | 概念懂了，想看真实盘面长什么样的人 |

> ⚠️ **建议第一篇读 `17_交易心态与铁律.md`。**
> 它讲这套体系里唯一无法被技术分析替代的东西：
> **系统给的是概率与 EV 上的优势，不是「一定赢」；交易是付费试错；胜率不重要、盈亏比重要；只有赚大亏小能活下来。**

学习路径的**顺序是刻意排的**：

```
阶段 0  拍卖理论：一切的地基        ← 不先接受"市场是拍卖场"，后面所有名词都没有根
阶段 1  没有人在盯着你              ← 先认清自己在食物链的哪一层
阶段 2  TPO 是怎么形成的            ← 到这里才讲轮廓怎么长出来
阶段 3–5 读懂轮廓 → 读出形状 → 今天是哪种日子
阶段 6–7 建立语境 → 识别动量
阶段 8–10 可交易的策略 → 订单流确认 → 衍生品判断脆弱性
阶段 11–12 VWAP → 组装起来
```

每个单元 7 段固定结构：**一句话 / 为什么需要 / 怎么看 / 常见错误 / 自测 / 答案 / 延伸阅读**。
自测默认折叠 —— 先自己想，再点开对答案。

## 网页功能

- **左侧常驻边栏**，分「学习路径 / 总览 / 理论篇 / 实战篇 / 实盘图鉴」五区，滚动自动高亮当前章节
- **全文搜索**：按 `/` 聚焦；支持多词（空格 / 逗号 / 顿号分隔），先要求全部命中，无结果再放宽
- **45 张矢量图解**：全部手写 SVG，可无损放大，深色主题配色统一
- **34 张真实行情截图**：内联 base64 webp，保持单文件、零外链
- **学习进度**：每个单元标题右侧有勾选按钮，顶部 sticky 进度条，存 `localStorage`
- **29 个术语表**：13 个阶段 + 16 章，各自末尾一张「需要关注的术语」
- **深链接**：每个标题都有锚点，鼠标悬停显示 `#`
- 手机自适应（≤560px 侧栏变抽屉）、打印样式

### 从源码重新构建

```bash
python _build/_build_site.py      # 构建 + 同步 index.html 与 source/*.md
python _build/_verify_all.py      # 四项校验，任一失败返回非 0
```

校验覆盖：占位符残留 / id 唯一与锚点可达 / 跨文件重复长句 / SVG 溢出 / 侧栏分区、
图鉴配图数（声明 vs 实际）、章节指针（`xx.md` §N 是否真实存在）、小节编号错位。

## 关于内容

- **45 张矢量图解**是按文字描述重绘的，不是行情截图。

  已删除该站全部**平台操作说明**（`Using X in MMT` / `Layer Settings` / `Templates`），只保留概念正文与截图，并译为中文。

- 本文档是**知识整理**，不构成任何交易建议。
