## 这是什么

把一份 66 页的英文材料（TPO / Market Profile / 订单流 / 衍生品 / VWAP）重组成两条线：

| | 内容 | 面向 |
|---|---|---|
| **学习路径** | 54 个单元 / 13 个阶段，每单元只讲**一个**概念 | 有一点基础、想系统化的人 |
| **参考手册** | 19 篇，按主题查阅 | 已经懂、要查具体规则的人 |

学习路径的**顺序是刻意排的**：

```
阶段 0  拍卖理论：一切的地基        ← 不先接受"市场是拍卖场"，后面所有名词都没有根
阶段 1  没有人在盯着你              ← 先认清自己在食物链的哪一层
阶段 2  TPO 是怎么形成的            ← 到这里才讲轮廓怎么长出来
阶段 3–5 读懂轮廓 → 读出形状 → 今天是哪种日子
阶段 6–7 建立语境 → 识别动量
阶段 8–10 可交易的策略 → 订单流确认 → 衍生品判断脆弱性
阶段 11–12 VWAP → 组装起来
```

每个单元 7 段固定结构：**一句话 / 为什么需要 / 怎么看 / 常见错误 / 自测 / 答案 / 延伸阅读**。
自测默认折叠 —— 先自己想，再点开对答案。

## 网页功能

- **左侧常驻边栏**，分「学习路径 / 参考手册」两区，滚动自动高亮当前章节
- **全文搜索**：按 `/` 聚焦；支持多词（空格 / 逗号 / 顿号分隔），先要求全部命中，无结果再放宽
- **21 张矢量图解**：全部手写 SVG，可无损放大，深色主题配色统一
- **学习进度**：每个单元标题右侧有勾选按钮，顶部 sticky 进度条，存 `localStorage`
- **30 个术语表**：13 个阶段 + 17 章，各自末尾一张「需要关注的术语」
- **深链接**：每个标题都有锚点，鼠标悬停显示 `#`
- 手机自适应（≤560px 侧栏变抽屉）、打印样式
