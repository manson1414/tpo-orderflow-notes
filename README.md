## 这是什么

把一份 66 页的英文材料（TPO / Market Profile / 订单流 / 衍生品 / VWAP）重组成三块：

| | 内容 | 面向 |
|---|---|---|
| **学习路径** | **入口 · 15 阶段的阅读顺序**（1 篇指引，不是教材） | 有一点基础、想系统化的人 |
| **理论篇** | 13 篇：市场**怎么运作** | 想先搞懂机制的人 |
| **实战篇** | 7 篇：具体**怎么用**（含 `01 交易心态与铁律`） | 想直接找打法的人 |

**学习路径不再重复正文。** 它只回答「按什么顺序读、为什么这么排、读完该做什么」，
原先 54 个单元的内容按阶段并入理论篇／实战篇对应章节 ——
两处并存只会互相漂移。单元里唯一没有替代品的两部分保留了下来：

- **`⚠️ 常见错误`** 与 **`自测 + 答案`** → 落到各章末尾的 **`## 自测`** 块（答案默认折叠）
- **`延伸阅读`** → 指向别章的交叉引用，留作指路牌

**39 张真实行情截图不单独成篇**，而是并入理论篇里它真正讲解的那一节末尾 ——
图只是概念的真实形态，拆开放会让两边都读不完整。

> ⚠️ **建议第一篇读 实战篇 `01 交易心态与铁律`。**
> 它讲这套体系里唯一无法被技术分析替代的东西：
> **系统给的是概率与 EV 上的优势，不是「一定赢」；交易是付费试错；胜率不重要、盈亏比重要；只有赚大亏小能活下来。**

阅读顺序是**刻意排的**（详见 `source/学习路径.md`）：

```
阶段 0   拍卖理论：一切的地基        ← 不先接受"市场是拍卖场"，后面所有名词都没有根
阶段 1   没有人在盯着你              ← 先认清自己在食物链的哪一层
阶段 2–4 TPO 是怎么形成的 → 读懂轮廓 → 读出形状
阶段 5   换一把尺子：成交量轮廓        ← TPO 量时间、成交量轮廓量成交量；两个 POC 对不上是正常的，位置的漂移是结果不是原因
阶段 6   今天是哪种日子
阶段 7–8 建立语境 → 识别动量
阶段 9–11 可交易的策略 → 订单流确认 → 衍生品判断脆弱性
阶段 12–14 期权做市商的对冲流 → VWAP → 组装起来
```

每个自测单元 4 段固定结构：**常见错误 / 自测 / 答案 / 延伸阅读**。

## 网页功能

- **左侧常驻边栏**，分「学习路径 / 理论篇 / 实战篇」三区，滚动自动高亮当前章节
- **全文搜索**：按 `/` 聚焦；支持多词（空格 / 逗号 / 顿号分隔），先要求全部命中，无结果再放宽
- **29 张矢量图解**：全部手写 SVG，可无损放大，深色主题配色统一
- **39 张真实行情截图**：内联 base64 webp，保持单文件、零外链
- **8 张可交互实时行情图**：K 线 + TPO 轮廓 / 足迹图 / 订单簿流动性热力图 / CVD / OI 与资金费率 /
  强平量 / VWAP 轨道 / 成交量热力图。数据是**构建时的真实快照**（不是实时行情），
  取自 OpenMarket API 并内联进 HTML；支持拖拽平移、滚轮缩放、双击复位、悬停读数
- **66 道自测**：分布在 20 章末尾的「自测」块，答案默认折叠
- **学习进度**：每个单元标题右侧有勾选按钮，顶部 sticky 进度条，存 `localStorage`
- **20 张术语表**：理论篇 13 章 + 实战篇 7 章，各自末尾一张「需要关注的术语」
- **深链接**：每个标题都有锚点，鼠标悬停显示 `#`
- 手机自适应（≤560px 侧栏变抽屉）、打印样式

### 从源码重新构建

```bash
python _build/_build_site.py      # 构建 + 同步 index.html 与 source/*.md
python _build/_verify_all.py      # 五项校验，任一失败返回非 0
```

校验覆盖：占位符残留 / id 唯一与锚点可达 / 跨文件重复长句 / SVG 溢出 / 侧栏分区、
实图分布（39 张是否全部落地、有无重复引用或孤儿图）、章节指针（`xx.md` §N 是否真实存在）、
小节编号错位、Markdown 渲染语义（浅缩进嵌套 / 列表被吞进段落）。

## 关于内容

- **29 张矢量图解**是按文字描述重绘的，不是行情截图。
- **38 张真实行情截图**来自 [mmt.gg/learn](https://mmt.gg/learn) 系列页面，
  已按讲解内容并入理论篇各章末尾；
  已删除该站全部**平台操作说明**（`Using X in MMT` / `Layer Settings` / `Templates`），只保留概念正文与截图，并译为中文。
  另有 1 张 GEX 价位图为**自备截图**（`11 Gamma 与 GEX`），非 mmt.gg 来源。
- ⚠️ 这 38 张截图**带有原平台 UI 与水印**。自用无碍；**如需公开传播，请先确认授权**。
- 原 PDF 中依赖行情截图才能看懂的**复盘案例**已整段删除（2025/11/11 亚洲时段、
  挤压轮廓案例、普通人 vs Profile 交易者案例等）。没有配图时这些内容只会让初学者更困惑。
- 文中的经验数字（70% / 80% / 0.36% / 5–6 天 / >75% 等）是**原作者的经验值或历史统计值，未做独立验证**。用之前请按自己的标的与周期重新验证。
- VWAP 的「**±2 / ±3σ 是反转高发区**」同样来自经验观察，**未做统计验证** —— 要算数得按自己的标的统计触及 ±2σ / ±3σ 后的实际反转率。
- 本文档是**知识整理**，不构成任何交易建议。
